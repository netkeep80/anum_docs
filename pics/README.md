# Исторические изображения МТС — НЕ УДАЛЯТЬ

**Статус: исторические исследовательские оригиналы, бессрочное сохранение.**

Все **29 изображений** этого каталога обозначены Автором МТС как исторические материалы.
Их нельзя считать мусором по отсутствию ссылок в текущей документации, давности создания,
качеству оформления, имени файла или наличию новой красивой схемы.

**Запрещено:** удалять, переименовывать, перезаписывать, сжимать исходные файлы
с потерей исходных байтов либо заменять их автоматически сгенерированными аналогами.
Допустимо создавать новые производные изображения **отдельно** с явной ссылкой на исходник.

**Машинный список, размер каждого файла и Git blob SHA-1:**
`profiles/mts-historical-images.json` (от корня репозитория).
Проверка сохранности: `ts/test/historical-images-protection.test.ts`.

Это сохранённая историческая исследовательская коллекция. Текущая МТС v0.15
не обязана считать содержание каждого изображения нормативным или актуальным:
**историческая ценность не означает семантической authority**.

Принятая v0.15 остаётся неизменной. Эта метка не превращает старые схемы
в действующие формулы, доказательства или нормативные определения.

Перед любой будущей реорганизацией нужны отдельное авторское решение,
исследование provenance и подтверждение отсутствия потери исторического содержания.
В обычных cleanup-PR любые изменения этих 29 оригиналов запрещены.

Владелец решения: [anum_docs #2080](https://github.com/netkeep80/anum_docs/issues/2080).
