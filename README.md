# Метатеория связей (МТС)

**Метатеория связей (МТС)** исследует системы, в которых единственным первичным видом сущности является **связь**.

Главный постулат:

```text
всё есть связь
```

МТС начинается не с программного типа и не с графической стрелки. Её исходная наглядность — **остенсивная форма связи**: сама запись показывает, какие полюса различены, а какие самозамкнуты.

## Краткий словарь

Приставка **«а-»** в собственных терминах МТС означает **«ассоциативный»**. Она подчёркивает, что понятие определяется через связи и их ассоциативное окружение, а не через отдельную внешнюю структуру данных.

**Связь** — первичная сущность МТС. В направленной форме имеет начало и конец:

```text
A ⟼ B
```

При этом `A` и `B` сами являются связями, а не объектами другой онтологии.

**Асеть** — ассоциативная сеть связей. Связи могут быть полюсами других связей, поэтому отдельный первичный слой «узлов» не требуется:

```text
P = A ⟼ B
Q = P ⟼ C
```

**Акорень** — ассоциативный корень `∞`, **единственная полностью самозамкнутая связь**:

```text
∞ = ∞ ⟼ ∞
```

Акорень является исходной точкой корневых различений, но не является абитом.

**Абит** — одно из четырёх корневых различений, используемых как алфавит четверичного ачисла:

```text
[ ] 1 0
```

Их корневые значения задаются связями `O`, `C`, `L`, `U`.

**Ачисло** — конечная структурная запись через корневые различения. Ачисло описывает структуру; чтение само по себе не обязано материализовать описанные связи.

**Четверичное ачисло** состоит ровно из четырёх абитов:

```text
[ ] 1 0
```

Акорень `∞` не является пятым состоянием передачи: каждый новый контекст десериализации уже начинается относительно него.

**Апамять** — ассоциативная память: поиск, чтение, явная материализация и долговременное хранение конкретной асети. Физический адрес записи не является смысловым тождеством связи.

## 1. Остенсивный корень МТС

Акорень:

```text
∞ = ∞ ⟼ ∞
```

Для начала `b` и конца `e` различаются четыре остенсивные формы:

```text
∞        оба полюса самозамкнуты
♂e       начало самозамкнуто, конец e различён
b♀       начало b различено, конец самозамкнут
b ⟼ e    оба полюса различены
```

Структурно:

```text
R = R ⟼ R      # ∞
S = S ⟼ e      # ♂e
E = b ⟼ E      # b♀
X = b ⟼ e      # b ⟼ e
```

Знаки `♂` и `♀` **не являются командами взять начало или конец**. Они остенсивно показывают самозамыкание соответствующего полюса:

```text
♂e = S = S ⟼ e
b♀ = E = b ⟼ E
```

Операция поиска, проверки или построения определяется конкретным актом и связями контекста, а не скрытым вторым значением знака.

Полностью самозамкнутая форма канонически одна:

```text
X = X ⟼ X
=>
X = R = ∞
```

Нельзя ввести `Q = Q ⟼ Q`, затем объявить `Q ≠ R` только потому, что технические ссылки `Q` и `R` различны. Это было бы круговым обоснованием: скрытая экземплярная ссылка сначала создаёт различие, а затем сама же используется как «различие полюсов».

## 2. Пять корневых связей

Текущий кандидат основания использует пятисвязное корневое ядро:

```text
R = ∞
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

Корневой четверичный словарь:

```text
[ → O
] → C
1 → L
0 → U
```

Остенсивно:

```text
O = O ⟼ R ≡ ♂∞
C = R ⟼ C ≡ ∞♀
```

Поэтому необходимо различать:

```text
семантический корневой базис: R/O/C/L/U — 5 связей
транспортный алфавит:        [ ] 1 0   — 4 абита
```

## 3. Машинное представление вторично

После остенсивного определения связь можно представить машинной структурой:

```text
Link(start, end)
```

В самой связи нет обязательных полей «контекст», «теория», «правило», «смысл» или «тип». Если роль существенна, она выражается другими связями сети.

## 4. Тождество связи определяется началом и концом

Фундаментальная аксиома:

```text
(A ⟼ B) = (C ⟼ D)
⇔
A = C ∧ B = D
```

Следовательно:

```text
P1 = A ⟼ B
P2 = A ⟼ B
=> P1 = P2
```

В МТС не существует двух разных связей с одной и той же упорядоченной парой полюсов.

Адрес памяти, номер записи, номер операции или позиция в последовательности могут различаться, но они не создают второе смысловое тождество связи.

Для рекурсивной формы технический `ref` также не может быть исходным различителем самого себя. В частности, полное самозамыкание имеет единственное решение в смысловой системе МТС — акорень.

## 5. Различимость укоренена в самозамыкании

Тождество по полюсам становится содержательным только тогда, когда сами полюса уже различимы. Первичный источник различимости даёт рисунок самозамыкания, а дальнейшее различение распространяется через связанность с уже различёнными корневыми связями.

Корневая последовательность различения:

```text
R = R ⟼ R

O = O ⟼ R
C = R ⟼ C

L = O ⟼ C
U = C ⟼ O
```

Здесь:

- `R` различён полным самозамыканием;
- `O` отличается от `R` тем, что только начало самозамкнуто, а конец связан с уже различённым `R`;
- `C` отличается ориентацией: начало связано с `R`, а конец самозамкнут;
- `L` и `U` различаются порядком уже различённых `O` и `C`.

Общий принцип:

```text
самозамыкание полюсов
→ различение корневых связей
→ связанность с уже различёнными связями
→ дальнейшее структурное различение
```

Техническая нумерация в эту цепочку не входит.

## 6. Повтор связи и повтор позиции — разные вещи

Последовательность может несколько раз ссылаться на одну связь:

```text
[L, L, L, U]
```

Так представляется, например, ачисло:

```text
1110
```

Три позиции `1` различаются своим положением, но не создают три экземпляра `L`.

Если нужно различать события, акты или происхождение, различие должно выражаться отдельной связевой структурой истории.

## 7. Контекст является частью сети связей

Контекст не обязан существовать как скрытый стек среды исполнения:

```text
P = parent ⟼ current
K = K ⟼ P
```

Запись:

```text
↑ = current(K)
```

означает получение текущей связи из явно указанного `K`, а не обращение к глобальной переменной.

Если связевая форма двух состояний полностью совпадает относительно уже различённых полюсов, это одна и та же связь. Чтобы различать последовательные события перехода, их происхождение должно храниться самой историей актов.

## 8. Исходная запись, словарь и теория различаются

Одна последовательность байтов может участвовать во многих местах и актах чтения. Различаются:

```text
содержимое исходной записи
позиция или связевая история употребления
выбранное разбиение
словарь D
форма F
допуск формы теорией T
```

Словарь также представляется сетью:

```text
D = D ⟼ (parentScope ⟼ localHistory)
```

Если два объявления действительно должны различаться, различие выражается структурой истории, а не вторым экземпляром одной и той же пары полюсов.

## 9. Наблюдение отделено от изменения

Критическая граница апамяти:

```text
читать / искать / разрешать / проверять
                    ≠
создавать / удалять / изменять
```

Поиск отсутствующей физической записи не создаёт её.

```text
не найдено ≠ не существует
find ≠ materialize
```

Явное получение связи с возможной материализацией должно вести себя канонически:

```text
ensureLink(A,B):
    если A ⟼ B уже записана -> вернуть её
    иначе -> материализовать её
```

Повторный вызов для той же структурно различённой пары возвращает ту же связь.

## 10. Локальное равенство и правила вывода

Текущий кандидат локального равенства использует явного представителя в контексте:

```text
Pair    = member ⟼ representative
Binding = K ⟼ Pair
```

Это дополнительный контекстный механизм и он не переопределяет фундаментальное тождество связи по её полюсам.

Из локального отношения не следуют автоматически глобальная подстановка, транзитивное замыкание или переписывание всей сети.

Дополнительное правило вывода должно быть отдельно допущено теорией:

```text
T ⟼ Rule
```

## 11. Ачисла и пустой контекст

Ачисла используют ровно четыре корневых абита:

```text
[ ] 1 0
```

Каждый контекст десериализации начинается от `R`.

Поэтому:

```text
des(ε) = R
des([]) = R
```

Пустая группа `[]` допустима и является способом записать акорень внутри четверичного ачисла без пятого абита.

Для уже разрешённых значений:

```text
des(a)     = a
des(a,b)   = a ⟼ b
des(a,b,c) = (a ⟼ b) ⟼ c
```

При материализации каждый требуемый шаг переиспользует уже имеющуюся связь той же структурно различённой пары либо явно создаёт её, если физической записи ещё нет.

Подробнее: [Ачисла и сериализация](docs/specs/Ачисла%20и%20сериализация.md).

## 12. Апамять

Апамять должна сохранять:

- единственность полностью самозамкнутого акорня;
- тождество связи по структурно различённым упорядоченным полюсам;
- укоренённость различимости в самозамыкании и корневой связанности;
- циклы и петли;
- совместное использование одной связи несколькими структурами;
- повтор ссылок в последовательностях;
- различие чтения и изменения;
- независимость смыслового тождества от физического адреса.

Если внешний артефакт содержит несколько технических записей, которые не имеют структурного различия относительно корня, они не должны становиться несколькими смысловыми связями МТС.

Подробнее: [Апамять и управление сетью связей](docs/specs/Апамять%20и%20управление%20сетью%20связей.md).

## Главный инвариант

```text
полное самозамыкание ∞
→ различение ориентации самозамыкания
→ корневые R/O/C/L/U
→ структурная связанность с уже различёнными связями
→ тождество по различённым полюсам
→ явный контекст и свидетельства
→ ассоциативный поиск
→ детерминированная проверка
→ явное изменение апамяти
```

`∞`, `♂`, `♀` и `⟼` — не украшение поверх машинной модели. Они делают источник различимости связи видимым в самой записи.
