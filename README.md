# Метатеория связей (МТС)

**Метатеория связей (МТС)** исследует системы, в которых единственным первичным видом сущности является **связь**.

Исходная онтологическая посылка:

```text
всё есть связь
связь связывает связи
```

Начало и конец связи сами являются связями. Смысловое различие не вводится техническим именем или адресом:

```text
различима только рекурсия
```

Короткая зависимость основания:

```text
∞ как остенсивное полное самозамыкание
→ ROOT как нулевая форма укоренения
→ теорема единственности полного самозамыкания
→ акорень и техническое имя R
→ конечные START / END / PAIR
→ рекурсивное тождество
→ теорема тождества по упорядоченным полюсам
```

Стрелки здесь обозначают зависимость **обоснования различимости**, а не временной порядок возникновения связей. Уравнения МТС могут задаваться одновременно.

## Краткий словарь

Приставка **«а-»** в собственных терминах МТС означает **«ассоциативный»**.

**Связь** — первичная сущность МТС. В направленной форме имеет начало и конец:

```text
A ⟼ B
```

`A` и `B` сами являются связями.

**Асеть** — ассоциативная сеть связей. Связи могут быть полюсами других связей, поэтому отдельный первичный слой «узлов» не требуется.

**Акорень** — значение полной рекурсии, остенсивно предъявляемое `∞`. Единственность этой формы выводится; только после этого для неё используется техническое имя `R`.

**Абит** — одно из четырёх корневых различений четверичного ачисла:

```text
[ ] 1 0
```

**Ачисло** — конечная структурная запись через корневые различения.

**Апамять** — ассоциативная память для поиска, чтения, явной материализации и долговременного хранения конкретной асети. Физический адрес записи не является смысловым тождеством связи.

## 1. От полной рекурсии к акорню

МТС не начинает с отдельно постулированного объекта `R`. Первая форма, не требующая ни одного уже различённого внешнего полюса, предъявляется остенсивно:

```text
∞
```

`∞` непосредственно показывает полное самозамыкание. Во внешней F2-метанотации нулевая форма укоренения записывается так:

```text
x = x ⟼ x
───────────
x ⇓ ROOT
```

Если одновременно заданы:

```text
x = x ⟼ x
y = y ⟼ y
```

обе записи имеют одну нейтральную к именам форму `ROOT`. Имена `x` и `y` не выражают рекурсивного различия, поэтому единственность полного самозамыкания является **производной теоремой**, а не отдельным предположением.

Эту единственную смысловую форму называем **акорнем**. После её различения вводится техническое имя:

```text
R := смысловая форма, предъявленная ∞
R = ∞
R = R ⟼ R
```

**Полная рекурсия и есть значение акорня в МТС** — не свойство, позже назначенное заранее существующему объекту.

После `ROOT` могут быть конечно укоренены остальные остенсивные формы:

```text
♂e       начало самозамкнуто, конец e уже различён
b♀       начало b уже различен, конец самозамкнут
b ⟼ e    оба полюса уже различены
```

Структурно:

```text
S = S ⟼ e
E = b ⟼ E
X = b ⟼ e
```

`♂e` и `b♀` здесь — остенсивная теоретическая запись, а не команды получения полюсов. Знаки `♂` и `♀` не входят во внутренний минимальный реестр F1 и остаются отложенными.

Важная граница F2: рекурсия различает только при **конечном укоренении**. Чистая взаимная рекурсия, в которой предполагаемые различия ссылаются только друг на друга и не имеют конечного пути к `ROOT`, остаётся `UNDERGROUNDED`, даже если внешняя запись асимметрична.

```text
одновременность уравнений != временной порядок создания связей
```

Это зависимость доказательства основания различия, а не космогония «сначала R, потом остальные связи».

## 2. Пять корневых связей

МТС v0.11 сохраняет принятое в МТС v0.10 пятисвязное ядро:

```text
R = ∞
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

Корневой четверичный словарь:

```text
[ → O
] → C
1 → L
0 → U
```

В теоретической метанотации:

```text
O = O ⟼ R   # ♂∞
C = R ⟼ C   # ∞♀
```

Нужно различать:

```text
семантический корневой базис: R/O/C/L/U — 5 связей
транспортный алфавит:        [ ] 1 0   — 4 абита
```

Акорень `∞` не является пятым абитом.

## 3. Внутренние знаки F1

Минимальный внутренний алфавит F1 МТС v0.11 содержит ровно:

```text
∞ [ ] 1 0 ( ) ⟼ : = .
```

Отложены:

```text
≡ ♂ ♀ ↑ { } ¬ ↛
```

`↑` сохраняется только как исторический исследовательский кандидат; его роль текущего контекстного целого покрыта принятой точкой `.`.

Только в метаязыке используются:

```text
∧ ⇔ ⇒ ≠ →
```

## 4. Машинное представление вторично

После определения смысла связь можно представить машинной структурой:

```text
Link(start, end)
```

Техническая ссылка не является источником смыслового различия. Если роль существенна, она выражается другими связями сети.

## 5. Тождество связи — производный результат

После единственности `ROOT` и конечного укоренения остальных форм тождество рекурсивно сводится к соответствующим упорядоченным полюсам:

```text
unique ROOT
→ однополюсные укоренённые формы
→ обычные PAIR-формы
→ рекурсивное тождество
→ тождество по упорядоченным полюсам
```

Отсюда для уже структурно различённых полюсов выводится теорема:

```text
(A ⟼ B) = (C ⟼ D)
⇔
A = C ∧ B = D
```

Следовательно:

```text
P1 = A ⟼ B
P2 = A ⟼ B
=> P1 = P2
```

Адрес памяти, номер записи, номер операции или позиция в последовательности не создают второе смысловое тождество. Тождество по полюсам не используется для доказательства единственности акорня, поэтому круг `identity → unique R → identity` не возникает.

## 6. Повтор значения и повтор позиции

Последовательность может несколько раз ссылаться на одну связь:

```text
[L, L, L, U]
```

Три позиции `1` — три вхождения одной связи `L`, а не три экземпляра `L`.

Если нужно различать события, происхождение или историю, различие хранится отдельной связевой структурой вхождений и происхождения.

## 7. Контекст — часть асети

Контекст среды исполнения не определяется скрытым стеком:

```text
P = parent ⟼ current
K = K ⟼ P
I ⟼ K
```

МТС v0.11 сохраняет принятую в v0.10 контекстную форму:

```text
A : E
```

`:` обозначает переход от внешнего единства `A` к внутренней ориентированной дуальности. Точка `.` внутри `E` возвращает связанную контекстную связь как целое:

```text
resolve_A(.) = A
```

МТС v0.11 дополнительно принимает верхнеуровневое структурное связывание:

```text
TopBind(R,S)
resolve_top(.) = R
```

При этом верхнеуровневое контекстное целое и frame исполнения различны:

```text
A₀ = R
K₀ = START(R) = O
A₀ != K₀
```

Корень не подставляется скрытым исходным префиксом и не берётся из неявного текущего состояния среды исполнения: верхнеуровневая точка разрешается через явное структурное связывание.

Основные рекурсивные формы:

```text
∞ : . ⟼ .   -> ∞ = ∞ ⟼ ∞
O : . ⟼ ∞   -> O = O ⟼ R
C : ∞ ⟼ .   -> C = R ⟼ C
A : . ⟼ B   -> A = A ⟼ B
A : B ⟼ .   -> A = B ⟼ A
```

Полное `A:.⟼.` укоренённо совпадает с самим `A` только для акорня `∞`. Вложенный `B:E` связывает свои точки ближайшим лексическим контекстом.

Собственный смысл знака точки отличается от её контекстного употребления:

```text
m: = m∞ ⟼ m⟼
m. = m⟼ ⟼ m∞ = Inv(m:)
```

Точка не является переходом к родителю, скрытым текущим объектом среды исполнения, чтением начала/конца или обращением к хранилищу.

Открытие и закрытие контекстов `Q` и `FORMAL`, возврат результата родителю и временной порядок по-прежнему выражаются явными `K`, `Run` и `Act`.

## 8. Источник, словарь и теория различаются

Нужно различать:

```text
точные байты исходной записи
позицию / историю употребления
словарь D
грамматику G
теорию T
интерпретатор I = D ⟼ (G ⟼ T)
контекст K
форму
результат
```

МТС v0.11 сохраняет каноническое представление `STRING→QUATERNARY`: каждый физический байт кодируется одним конвертом `[8 bits]`. Нормализация `Unicode` не выполняется скрыто, а технический идентификатор байта не становится смысловым тождеством.

## 9. Наблюдение отделено от изменения

Критическая граница апамяти:

```text
читать / искать / разрешать / проверять / воспроизводить
                    ≠
создавать / удалять / изменять
```

И:

```text
не найдено ≠ не существует
find ≠ materialize
```

Явная материализация должна переиспользовать уже существующую связь той же пары.

## 10. Формальное равенство и правила

Формальное `=` использует явное контекстно-локальное свидетельство представителя. В метанотации:

```text
Pair    = member ⟼ representative
Binding = K ⟼ Pair
```

Это не переопределяет фундаментальное тождество связи по полюсам и не вводит автоматически глобальную подстановку или транзитивное замыкание.

Правило должно быть структурно объявлено и допущено теорией:

```text
Rule = DR ⟼ Body
T ⟼ Rule
```

Наличие правила как данных не означает его автоматического исполнения.

## 11. Ачисла и пустой контекст

Ачисла используют ровно четыре абита:

```text
[ ] 1 0
```

Каждый контекст `Q` начинается относительно `R`. Состояние «пусто/непусто» представлено структурно, а не скрытым флагом среды исполнения.

Поэтому:

```text
des(ε) = R
des([]) = R
```

Для результата уже разрешённых значений используется левая свёртка:

```text
des(a)     = a
des(a,b)   = a ⟼ b
des(a,b,c) = (a ⟼ b) ⟼ c
```

Но результат свёртки не является универсальным тождеством исходной последовательности. Там, где нужно сохранить явную позицию `R`, используется `ExactSequence`.

Подробнее: [Ачисла и сериализация](docs/specs/Ачисла%20и%20сериализация.md).

## 12. Апамять

Апамять должна сохранять одновременно:

- тождество связи по упорядоченным различённым полюсам;
- единственность акорня;
- укоренённые циклы и петли;
- совместное использование одной связи несколькими структурами;
- повтор ссылок в последовательностях;
- различие чтения и изменения;
- независимость смысла от физического адреса.

Если внешний артефакт содержит две физические записи одной структурно неразличимой связи, они канонизируются либо артефакт отклоняется.

Подробнее: [Апамять и управление сетью связей](docs/specs/Апамять%20и%20управление%20сетью%20связей.md).

## 13. Производные результаты F2–F8

Завершённые исследовательские циклы вывели поверх основания, не добавляя новые корневые виды сущностей:

- конечную нормализацию и отсутствие смысловых экземпляров без структурного различия;
- рекурсивную реверсию `J`, отдельную от перестановки полюсов;
- счёт по степеням связности и производную структуру Пеано;
- конечные коллекции, функции как данные и относительную навигацию;
- структурное исчисление записи и чтения полюсов;
- исполнение через явные `K`, роли, акты и последовательности без скрытой власти стека среды исполнения.

Эти конструкции остаются производными и не становятся новыми примитивами связи.

