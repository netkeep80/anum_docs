# Словарь терминов МТС
<!-- версия документа МТС; mts-doc-version: v0.15 -->
> **Версия МТС: v0.15**

Словарь — индекс `current-`терминов, `profile-`терминов, `historical` `aliases` и сохранённых `research-`кандидатов. Он **не является вторым нормативным контрактом**: смысл принадлежит указанному владельцу в поле «Подробнее».

Статусы:
- `accepted/current` — действующая терминология;
- `current profile` — принадлежит отдельно `governed` `execution` `profile`;
- `historical alias` — сохраняется для чтения истории, но не рекомендуется как `current` `name`;
- `research/deferred` — идея сохранена, но не является принятым законом.

## А

### Абит

Элемент последовательностного/кодового представления; не `structural` `aspect` `Link`.

**Слой:** representations-codecs  
**Статус:** current  
**Подробнее:** [канонический владелец](specs/%D0%90%D1%87%D0%B8%D1%81%D0%BB%D0%B0%20%D0%B8%20%D1%81%D0%B5%D1%80%D0%B8%D0%B0%D0%BB%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F.md)

**Статус:** current  
**Подробнее:** [канонический владелец](theory/%D0%9E%D1%81%D0%BD%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F%20%D0%9C%D0%A2%D0%A1.md)

## Правило употребления терминов

1. `Current` `name` выбирается по `terminology` `projection` в `requirements/mts-v0.14.json`.
2. `Historical` `alias` допустим при обсуждении истории, но не должен возвращаться как `current` `definition`.
3. `Research`/`deferred` термин сохраняется до отдельного решения: `DEFERRED != REJECTED`.
4. Одинаковый glyph в разных слоях не означает тождество смысла.
5. Новое определение должно иметь одного `human-owner` и `machine` `authority`; словарь только индексирует их.
