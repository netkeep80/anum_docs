## 1. Назначение

FORMAL — универсальная метанотация над одной асетью связей. Она описывает исходную асеть, имена, контексты, последовательности, правила и исполняемые структуры, не вводя второй онтологии поверх `Link`.

Текст FORMAL и канонический JSON — две проекции **одной и той же исходной асети**. JSON является хранением и транспортом, а не отдельным семантическим языком.

## 2. Основные формы

```text
:A ≡ R:A
A->B->C = (A->B)->C
Den([]) = ExactSequence([]) = R
Den([e1,...,en]) = ExactSequence([Den(e1),...,Den(en)])
∞      = ROOT
♂S     = START(S)
S♀     = END(S)
A->B   = PAIR(A,B)
```

Двоеточие квалифицирует имя в явном контексте; стрелка создаёт связь над уже разрешёнными связями. Прямая последовательная ассоциация относится к разбору исходного текста и не является алгебраической ассоциативностью.

## 3. Контексты, объявления и JSON

```text
{ A }        — объявление без локальной правой части
A:{}         — явно пустой именованный пучок
A:X          — связывание имени с выражением
[A,B,...]    — только ExactSequence; порядок и кратность сохраняются
```

В канонической JSON-проекции `null` у члена объекта означает bare-entry, а не особую сущность МТС. Дубли локальных имён отклоняются до потери информации обычным JSON-парсером. Служебные поля, типовые теги и host-имена не получают семантического authority.

## 5. Правило и универсальная реакция

```text
Rule = V -> (Antecedent -> ExactSequence(Image...))
Theory -> Rule ∈ M_t
|roles(V,M_t)| = 0  -> grounded exact refinement

M_t -> Γ(M_t) -> M_(t+1)
snapshot -> S1 match/bind -> S2 construct -> 0/1/N image -> atomic publication
J0 = selected
J1 = NOT_REQUIRED
```

Одна и та же `Γ` используется для обычных исполняемых асетей и мета-интерпретационных асетей. `S1` является фазой чтения и связывания, `S2` — подстановкой и каноническим построением. Отдельная host-команда grounder, логический opcode и второй исполнитель запрещены.

## 6. Метакомпилятор и границы репозиториев

На текущем этапе bootstrap-метакомпилятор находится в `anum_docs`. Он преобразует FORMAL/JSON через общую денотацию в семантическую асеть и детерминированное представление `8/9/6/1`.

```text
anum_docs = MTS + FORMAL/JSON + bootstrap metacompiler
amemory   = generic execution / Γ
aprover   = proofs over the same FORMAL/ANet model
```

Перенос самого метакомпилятора в FORMAL и его исполнение внутри A-memory является более поздней миграцией и не входит в текущую границу v0.15.
