# Формальная нотация МТС

Статус: актуальное, нормативное.

## Назначение

Формальная нотация МТС фиксирует способы различения связей и смысловых ролей связей. Она не вводит внешний источник смысла. Нормативные формулы находятся в `tests/mtc_formulas.mtc`.

## Скобочные нотации

```text
(...) — круглая формальная нотация
[...] — квадратная ачисловая нотация
{...} — пучковая нотация
```

```text
[] — минимальная завершённая форма одной связи
() — минимальная формальная форма смысла
{} — пустой пучок связей
```

Три пустые формы различимы:

```text
[] != ()
() != {}
{} != []
```

## Базовый словарь акорня

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞

() : ♀() ⟼ ()♂

([) : (♀∞)
(]) : (∞♂)

(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)

[1] : (⟼)
[0] : (↛)

♀[] : ♀[] = ♀[] ⟼ []
[]♂ : []♂ = [] ⟼ []♂

(=) : {♀[] = ♀[], []♂ = []♂}
(!=) : ¬(=)
```

Полюса формы записываются в актуальной ориентации: `♀F` — начало, `F♂` — конец. Старая ориентация `[]♀` и `♂[]` не используется.

Несвязь не существует в натуре. Смысл несвязи выражается связью. `0` — абит связи, несущей смысл несвязи; он не означает отсутствие связи в натуре.

## Роли вхождений

Видимый знак не равен вхождению знака. Один символ может иметь разные роли в зависимости от нотации и позиции:

| Роль | Пример | Чтение |
|---|---|---|
| `container-boundary` | `[1]`, `{[]}`, `(A)` | граница контейнера |
| `literal-abit` | `([)`, `(])` | буквальный квадратный абит внутри круглой формы |
| `one-link-form` | `[]` | форма одной связи |
| `link-pole-form` | `♀[]`, `[]♂` | начало или конец формы связи |
| `abit-form` | `[1]`, `[0]` | квадратная форма абита |
| `formal-form` | `(⟼)`, `(↛)` | формальная форма смысла |
| `empty-formal-form` | `()` | минимальная формальная форма смысла |
| `grouped-form` | `(A)` | группировка уже заданной формы |
| `bundle-form` | `{}`, `{[]}` | форма пучка связей |

Поэтому `([)` нельзя читать как незакрытый квадратный контейнер, `(])` — как лишнее закрытие, `[1]` — как список, `[0]` — как пустоту, `{}` — как форму одной связи.

## Локальный контекст

Формула `A : F` вводит различие `A` через локальную форму `F`. Повторные видимые знаки в правой части являются позиционными вхождениями, а не одной текстовой переменной.

```text
∞ : [] = [] ⟼ []
(=) : {♀[] = ♀[], []♂ = []♂}
```

В формуле равенства начала сравниваются с началами, а концы — с концами. Равенство фиксирует совпадение форм связей и не требует бесконечного раскрытия рекурсивных связей.

## Пучки

Пучок удерживает несколько форм связей как одну пучковую форму. Он не является формой одной связи и не обозначает отсутствие связи.

```text
{} != []
{[]} != []
{[], []} = {[]}
```

В `{[]}` фигурные скобки являются границами пучковой формы, а `[]` внутри — формой одной связи.

## Требования к reader

Reader должен сохранять строковый носитель, source span и различать роли вхождений. Источник смысла задаётся корневой библиотекой формул, а не внешней грамматикой Python.
