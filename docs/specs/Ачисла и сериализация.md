# Ачисла и сериализация

Ачисло — корневое последовательное описание связей через четыре абита:

```text
[ ] 1 0
```

Акорень `∞` не является пятым абитом: он уже присутствует как основание корневого чтения.

```text
носитель ачисла ≠ денотат ≠ материализованная сеть
```

Связь поэтому можно описывать и искать, не создавая её скрыто.

См. также [Основания МТС](../theory/Основания%20МТС.md), [Формальную нотацию МТС](Формальная%20нотация%20МТС.md) и [Апамять](Апамять%20и%20управление%20сетью%20связей.md).

## 1. Корневое ядро

```text
R = ∞ = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O

∞ → R
[ → O
] → C
1 → L
0 → U
```

Остенсивно:

```text
O ≡ ♂∞
C ≡ ∞♀
```

Нужно различать пятисвязное ядро `R/O/C/L/U` и передаваемые абиты `[ ] 1 0`. `R` — основание интерпретации, а не передаваемый абит. `♂/♀` — знаки форм самозамыкания.

```text
1 → L = O ⟼ C
0 → U = C ⟼ O
```

`1` несёт корневой смысл связи, `0` — несвязи, но `L` и `U` сами являются существующими точными связями. Поэтому возможно:

```text
описание X существует
X в апамяти не существует
```

Здесь описание само является связевой структурой, но не тождественно своему денотату.

```text
0 ≠ DELETE_LINK
```

## 2. Метанотация и физические скобки

В формулах:

```text
[a]  = des('a')
[ab] = des('ab')
```

внешние скобки слева — метанотация результата `des`, а не абиты источника. Поэтому:

```text
[ab]       = des('ab')
[[ab]]     = des('[ab]')
[[[ab]]]   = des('[[ab]]')
[[[ab]]ab] = des('[[ab]]ab')
```

Например:

```text
des('a')   = a
des('[a]') = R ⟼ a

des(ε)    = R
des('[]') = R
```

В последнем случае пустое тело даёт `R`, а закрывающая корневая форма снова приводит к `R=R⟼R`.

## 3. Форма не является командой

Физическое `[01]` не означает:

```text
[ = PUSH
] = POP
1 = CREATE_LINK
0 = DELETE_LINK
```

Роль формы определяется конкретным чтением. Точные `O/C` могут быть выбраны границами вложенности, но из этого не следуют универсальные команды:

```text
[ → start(current)
] → end(current)
```

Число скобок также не является скрытым состоянием интерпретатора.

## 4. Историческая версия 0.2 и аксиома начала

Foundation v2 не переписывает версию 0.2 задним числом. В ней была принята проекция:

```text
[  → ♀∞
]  → ∞♂
[] → 1
][ → 0
```

а `[[` и `]]` оставались граничными формами. Историческая ориентация не меняет текущую:

```text
♂e = S = S ⟼ e
b♀ = E = b ⟼ E
```

В исторической конечной рекурсивной области использовалось `D(A B)=D(A)⟼D(B)`. Сейчас `D` означает **словарь**, поэтому текущая денотация последовательности называется `des`.

Аксиома начала допускает восстановление:

```text
(O,U,L,C,L,C,U)
→ (O,O,U,L,C,L,C,U)
```

Второй `O` — повторное употребление **того же точного O**, а не новая связь той же формы. Восстановление ничего не материализует.

## 5. Источник, словарь и подвыборка

Проверяемый путь:

```text
исходная запись
→ каноническое содержимое
→ выбранное разбиение
→ D
→ точные формы
```

Словарь может разрешить фрагмент непосредственно в любое существующее точное вхождение. Отдельный тип «ссылка на связь» не нужен; скрытого правила самого длинного совпадения нет.

Каждый сегмент уже имеет точные `span`, `slice-content`, `lexeme`, `resolution`, `selection`. Поэтому вложенному чтению не нужна сущность `NestedSource`.

Непрерывная подвыборка представляется обычными связями:

```text
source-selection = fold(R, selection₁, ..., selectionₙ)
form-sequence    = fold(R, form₁, ..., formₙ)
G ⟼ form-sequence
T ⟼ form-sequence
```

Доверенная проверка сначала воспроизводит полный источник, затем подвыборку. Номера сегментов — лишь координаты проверяющей программы; пустая подвыборка использует точный `R`.

## 6. Свёртки и продолжение

Носитель включает `R` как начальное значение:

```text
carrier(ε)     = R
carrier(a)     = R ⟼ a
carrier(a,b)   = (R ⟼ a) ⟼ b
carrier(a,b,c) = ((R ⟼ a) ⟼ b) ⟼ c
```

Десериализация не использует `R` как операнд непустой свёртки:

```text
des(ε)     = R
des(a)     = a
des(a,b)   = a ⟼ b
des(a,b,c) = (a ⟼ b) ⟼ c
```

Поэтому:

```text
C_ab = carrier(a,b) = (R ⟼ a) ⟼ b
X    = des(a,b)     = a ⟼ b
C_ab ≠ X
```

Каждый шаг явной материализации создаёт новое точное вхождение, даже если такие полюса уже существуют.

Ранние лабораторные `pass/enc` не нужны:

```text
des(v) = v
C = R ⟼ C
C(v) → R ⟼ v
```

Если `K.current=P`, хвост продолжает ту же левую свёртку:

```text
continuation(P; a,b) = (P ⟼ a) ⟼ b
```

Доверенная проверка только подтверждает уже существующую цепочку от точного `K.current`.

## 7. Глубина сохраняется до интерпретации

```text
[ab]   → Group(a,b)
[[ab]] → Group(Group(a,b))
```

Скрытый счётчик глубины не нужен: вложенность уже засвидетельствована последовательностью точных `O/C`. Граница определяется **точным тождеством O/C**; связь с теми же полюсами остаётся обычным значением.

Группировка сама не устанавливает, какие закрывающие `C` должны стать актами отношения. Это задаётся выбранной цепочкой актов.

## 8. Проверенные физические чтения

Все следующие случаи проверены через точные подвыборки и акты **одного физического источника**.

### Первый уровень

```text
'[ab]'
→ (O,a,b,C)
→ Group(a,b)

A₁: des(a,b) = X = a ⟼ b
A₂: C(X) = R ⟼ X

des('[ab]') = R ⟼ (a ⟼ b)
```

### Второй уровень

Пусть `D` разрешает `ab` в существующий носитель:

```text
C_ab = carrier(a,b) = (R ⟼ a) ⟼ b
```

Тогда:

```text
'[[ab]]'
→ (O,O,C_ab,C,C)
→ Group(Group(C_ab))

A₁: des(C_ab) = C_ab
A₂: внешний C(C_ab) = P = R ⟼ C_ab

des('[[ab]]') = R ⟼ carrier(a,b)
```

Два закрывающих сегмента имеют разные точные `selection`, хотя оба разрешаются в один `C`. Применение обоих как актов отношения дало бы другую точную структуру `R⟼P`; она не смешивается с выбранной цепочкой актов.

### Внешний хвост

Для:

```text
'[[ab]]ab'
→ Group(Group(C_ab)), a, b
```

та же цепочка продолжается третьим актом:

```text
A₁: des(C_ab) = C_ab
A₂: C(C_ab) = P
A₃: continuation(P; a,b) = (P ⟼ a) ⟼ b

des('[[ab]]ab') = (P ⟼ a) ⟼ b
```

Это соответствует пользовательской метанотации `[[[ab]]ab]`.

## 9. Смешанная вложенность и точные дубликаты

Для `ab[ab]`, если внутреннему телу выбран `des`:

```text
X_inner = a ⟼ b
X_outer = a ⟼ b
X_inner ≠ X_outer
result = X_outer ⟼ X_inner
```

Совпадение полюсов не означает точного тождества. Интернирование пар не является семантическим законом.

Вложенная цепочка актов возвращает точное значение, после чего внешний уровень работает с ним как с любым другим `K.current`.

## 10. Относительное чтение как точный акт

Один источник может участвовать в разных актах `A`:

```text
source
source-selection
form-sequence
D / G / T
K_before
form / binding
result
K_after
```

Акты могут иметь общий источник, но разные подвыборки, `G/T`, формы и результаты. Доверенная проверка требует ровно одно ожидаемое точное значение каждой обязательной роли.

Относительность находится в **отношении источник ↔ конкретный засвидетельствованный акт чтения**, а не в скрытом режиме. Поиск может предложить акт; доверенная часть только воспроизводит предъявленные свидетельства.

## 11. Поиск и хранение

```text
не найдено ≠ не существует
find ≠ materialize
```

Существующий носитель может описывать искомую связь без её появления в апамяти.

При долговременном хранении различаются оперативная ссылка, логический идентификатор, номер в снимке и физический адрес. Физический адрес не является смысловым тождеством связи. Подробнее: [Апамять](Апамять%20и%20управление%20сетью%20связей.md).

## 12. Текущая граница

Проверенная лестница:

```text
сырой носитель
→ полный точный источник
→ D и сегменты
→ точные формы / O-C группировка
→ точные подвыборки
→ конкретные акты
→ des / шаг отношения / продолжение
→ точная цепочка актов
```

`SequenceAtom`, `SequenceGroup`, `SequenceDescription` и `OccurrenceRef` — машинные носители проверки, а не новые онтологические типы.

Не требуются как новые сущности или операции:

```text
NestedSource
RelativeContext
Quote
pass
enc
PUSH / POP
скрытый счётчик глубины
интернирование пар
```

Конкретные `ε`, `a`, `ab`, `[ab]`, `ab[ab]`, `[[ab]]` и `[[ab]]ab` уже согласованы с этим каркасом.

Следующая граница — **общий рекурсивный закон построения выбранной цепочки актов из произвольной вложенной группировки**. Он должен из точных свидетельств определять внутренние подвыборки, выбранные закрывающие акты, возврат вложенного результата и продолжение внешней свёртки — без скрытого состояния и встроенных команд скобок.

Пока такой общий способ построения не принят, проверенные примеры нельзя превращать в контекстно-независимое правило квадратных скобок.

Также остаются открыты общий канонический обратный путь за пределами принятой рекурсивной области и граница представимости произвольных циклических/разделяемых асетей одним ачислом.

## Итог

```text
carrier(v₁...vₙ) = левая свёртка от R
des(v₁...vₙ)     = левая свёртка без R как операнда непустого случая

носитель ≠ денотат
поиск ≠ создание
форма скобок ≠ встроенная команда
```

Вложенная цепочка актов возвращает точное значение. Внешняя последовательность продолжает работу от него как от обычного `K.current`.

```text
описать связь ≠ создать связь
описать несвязь ≠ сделать несвязь сущностью
```
