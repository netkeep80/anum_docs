# Ачисла и сериализация

Статус: актуальное, нормативное для квадратной записи и формата `*.anum`.

## Ачисло

Ачисло — последовательность абитов, интерпретируемая в ассоциативном контексте. Квадратная нотация используется для формы одной связи и квадратных форм абитов.

```text
([) : (♀∞)
(]) : (∞♂)
[1] : (⟼)
[0] : (↛)
```

`0` — абит связи, несущей смысл несвязи. Он не означает отсутствия связи в натуре.

Рабочая стрелочная проекция абитов определяется отдельно в [Протоколе абитов ачисел](<Протокол абитов ачисел.md>). Она не заменяет корневой fixture и не переносится в него автоматически.

## Формат `*.anum`

Контейнерный формат поддерживает два явно различённых режима:

```text
# anum-format: quaternary
# anum-format: string
```

Без заголовка файл читается как `quaternary`.

### Quaternary

Значащими являются только четыре абита:

```text
[ ] 1 0
```

Пробелы, переводы строк и комментарии `# ...` игнорируются. Любой другой символ является ошибкой. Обычная балансировка скобок не применяется: `][`, `[[`, `]]` и `[]` являются допустимыми последовательностями абитов.

### String

`# anum-format: string` сохраняет человекочитаемый символический носитель как `AnumSource`. Он не передаётся strict quaternary parser и не считается уже скомпилированным четверичным ачислом.

## UTF-8 payload codec

`converters/text_to_anum.py` и `converters/anum_to_text.py` кодируют и декодируют UTF-8 payload:

```text
hello -> [01101000][01100101][01101100][01101100][01101111]
```

Этот codec не является десериализатором связей и не смешивается со string symbolic anum.

## Актуальные модули

```text
core/anum_model.py        модели абитов и источников
core/anum_parser.py       parser и нормализация *.anum
core/anum_projector.py    проекция двухабитных форм
core/anum_memory.py       тестовая symbolic-модель load/find/realize
converters/anum_cli.py    CLI
```

Проекция двух квадратных абитов:

```text
[[ := α ⟼ α
[] := α ⟼ β -> 0
][ := β ⟼ α -> 1
]] := β ⟼ β
```

Модель материализации сохраняет инвариант:

```text
load(A)    не создаёт den(A)
find(A)    проверяет den(A), но не создаёт den(A)
realize(A) создаёт den(A), если den(A) является связью
```

`AnumMemory` является тестовой symbolic-моделью протокольных инвариантов и не считается реализацией полноценной апамяти.

## CLI

```bash
python -m converters.anum_cli parse examples/anum/two_abit_forms.anum
python -m converters.anum_cli project examples/anum/two_abit_forms.anum

```
