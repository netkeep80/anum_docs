# Ачисла и сериализация

Статус: актуальное, нормативное для контейнера и raw-слоя `*.anum`; root boundary subset согласован с принятой МТС v0.2. Принят минимальный structural-denoting subset для `0/1` и двух direct protocol atoms; recursive denotation остаётся задачей #95, общий gate — #89.

Уровень: **L3 — сериализация**.

Граница L2/L3/L4 задаётся [Reference model МТС v0.2](Reference%20model%20МТС%20v0.2.md).

## 1. Ачисло и raw carrier

Ачисло хранится/передаётся как raw-последовательность базовых абитов:

```text
[ ] 1 0
```

Raw carrier и его denotation различаются:

```text
raw(A) != den(A)
```

Raw parser отвечает только за чтение четырёх абитов. Он не выполняет materialization, не выбирает context и не применяет обычную балансировку программных скобок.

Поэтому допустимы raw-последовательности:

```text
][
[[
]]
[]
```

## 2. Канонический pipeline L3

```text
parse_raw_quaternary
→ validate_anum(context)
→ project_anum(context)
→ denotation subset
```

Это разные операции.

`parse_raw_quaternary` не знает семантики. `validate_anum` не меняет raw carrier. `project_anum` всегда получает явный `ProjectionContext`. Denotation layer выдаёт storage-neutral `AnumDenotation` и не обращается к L4-памяти.

Контексты протокола:

```text
root
quote
relative
```

Отсутствие явного контекста в protocol API не допускается.

## 3. Формат `*.anum`

Контейнер поддерживает два режима:

```text
# anum-format: quaternary
# anum-format: string
```

Без заголовка используется `quaternary`.

### Quaternary

Значащие символы:

```text
[ ] 1 0
```

Пробелы и переводы строк игнорируются. `#` начинает комментарий до конца строки.

Любой другой значащий символ является синтаксической ошибкой.

### String

String mode хранит **имена**, а не дополнительные абиты:

```text
# anum-format: string
window position x int
```

Имя не преобразуется в UTF-8 автоматически и не является пятым видом абита.

Канонический механизм:

```text
name
→ AnumDictionary entry
→ quaternary raw carrier
```

`AnumDictionary` требует явной регистрации каждого имени. Неизвестное или повторно определённое имя является ошибкой.

## 4. UTF-8 payload — отдельный codec

`converters/text_to_anum.py` и `converters/anum_to_text.py` кодируют байты UTF-8:

```text
hello
→ [01101000][01100101][01101100][01101100][01101111]
```

Это payload codec, а не dictionary resolution и не десериализация связей.

## 5. Incremental decoder

`IncrementalQuaternaryDecoder` принимает произвольные chunks:

```text
feed(chunk)
feed(chunk)
...
finish()
```

Границы chunks могут проходить между любыми абитами и внутри комментария. Decoder хранит минимальное состояние:

```text
absolute offset
comment state
recognized tokens
```

Он не пытается объявить raw-подпоследовательность «законченной формой», потому что критерий завершения зависит от context и не является частью raw grammar.

Инвариант:

```text
batch parse == incremental parse
```

включая абсолютные offsets токенов.

## 6. Deterministic raw serialization

`serialize_quaternary_anum` выдаёт канонический compact body:

```text
[01]][
```

или контейнер с header:

```text
# anum-format: quaternary
[01]][
```

Комментарии и пробелы не входят в каноническое представление.

Для raw-слоя:

```text
parse(serialize(parse(A)))
```

сохраняет последовательность абитов.

Это transport round-trip. Structural inverse serialization описывается отдельно и существует только для принятых denoting subsets.

## 7. Цитирование

Цитирование реализовано реальными абитами протокола, а не Python-обёрткой `Quote`.

```text
quote(A) := [ A ]
```

Пример:

```text
A          = ][
quote(A)   = [][]
quote²(A)  = [[][]]
```

В `quote` context снимается ровно один внешний уровень:

```text
project(quote²(A), quote) = quote(A)
project(quote(A), quote)  = A
```

Если quote-context получает raw payload без внешней оболочки, payload сохраняется без root-проекции.

Поскольку context указан явно, одинаковая последовательность абитов может иметь разные projection semantics без скрытой неоднозначности parser-а.

## 8. Граница L2/L3 и root boundary projection

Совпадение glyph `[` и `]` с квадратной формой L2 не означает автоматического тождества.

L2 v0.2 гарантирует, что context pronouns не используют квадратные скобки:

```text
◁  start context role
▷  end context role
↑  context ascent
```

Корневая L2-система содержит:

```text
([) : (♀∞)
(]) : (∞♂)
(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)
[1] : (⟼)
[0] : (↛)
```

Поэтому принятый L3 v0.2 boundary subset в **root context**:

```text
[  -> ♀∞
]  -> ∞♂
[] -> 1
][ -> 0
```

`[] -> 1` и `][ -> 0` не являются абсолютным rewriting rule. Quote context работает с оболочкой как с raw-данными, а relative context пока не имеет принятой denotation.

Старая experimental ориентация issue #61 `[] -> 0`, `][ -> 1` относилась к прежней полюсной записи и больше не является активной L3-семантикой.

`[[` и `]]` остаются валидными raw carriers и root `boundary-form` без `protocol_value`.

## 9. Принятый минимальный structural-denoting subset

Исходные read-only заметки фиксируют два свойства:

1. ачисло — последовательность абитов, неявно начинающаяся от `∞`;
2. последовательность `∞ab` / `(∞ ⟼ a) ⟼ b` сама не содержит `a ⟼ b`, но при десериализации описывает связь `a ⟼ b`.

В v0.2 это правило принимается только для минимального случая, где оба `a` и `b` уже являются однозначно определёнными direct protocol atoms `0` или `1`:

```text
0  -> Anchor(protocol:0)
1  -> Anchor(protocol:1)

00 -> 0 ⟼ 0
01 -> 0 ⟼ 1
10 -> 1 ⟼ 0
11 -> 1 ⟼ 1
```

Structural result использует [`anum-denotation/v0.2`](../../contracts/anum-denotation-v0.2.json): физические `LinkId` отсутствуют, node identity локальна описанию, materialization не выполняется.

Accepted root boundary aliases дают те же anchor denotations:

```text
][ -> den(0)
[] -> den(1)
```

Но inverse serialization канонична, а не source-preserving:

```text
den(][) -> 0
den([]) -> 1
```

Для single-pair denotation inverse равна конкатенации двух canonical protocol atoms.

Не входят в этот subset и остаются неструктурными:

```text
010 и любые более длинные direct sequences
[0], [01], [][] и другие recursive bracket compositions в root context
[[ и ]]
relative denotation
```

Recursive bracket grammar — отдельный dependency gate #95. Неразрешённый carrier должен оставаться typed `RAW`, а не получать эвристическую денотацию.

## 10. Граница L3/L4

L3 не реализует память.

Reference contract:

```text
load(A) не создаёт den(A)
find(A) не создаёт den(A)
realize(A) может явно материализовать den(A)
```

Для L2 действует аналогичный invariant:

```text
interpret(F) не выполняет realize(F)
```

`core/anum_memory.py` остаётся test-double L4-инвариантов.

`core/anum_pair_denotation.py` не читает и не мутирует память: он только строит storage-neutral `AnumDenotation`.

```text

```

`core/anum_protocol.py` остаётся единственным contextual projection path. Pair denotation вызывается после него и не создаёт второй raw parser.

## 12. CLI

```bash
python -m converters.anum_cli parse file.anum
python -m converters.anum_cli validate file.anum --context root
python -m converters.anum_cli project file.anum --context root
python -m converters.anum_cli project file.anum --context quote
python -m converters.anum_cli normalize file.anum
python -m converters.anum_cli quote file.anum
python -m converters.anum_cli unquote quoted.anum
```

L3 CLI не содержит `realize`: materialization относится к L4.
