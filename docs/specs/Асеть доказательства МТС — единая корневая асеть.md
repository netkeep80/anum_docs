# Асеть доказательства МТС — единая корневая асеть

Статус: текущая каноническая спецификация доказательного авторитета поверх принятой МТС версии 0.11.
Владельцы: #999, #1066, #1087, #1102, #1109, #1113, #1114, #1057, #1064. Переход к семантическому циклу допускается только через #995.
Исторический документ `docs/specs/Асеть доказательства МТС.md` остаётся журналом развития. Английская терминология мигрирует отдельно по #1049.

```text
accepted MTS = v0.11
active semantic candidate = NONE
```

## 1. Главный закон

Доказательный авторитет принадлежит одной корневой достижимой асети связей МТС.

```text
proof authority = one rooted reachable MTS proof Anet
```

Массивы, отображения, множества, внешние объекты, графические модели, обменные форматы и текст являются только рабочими или представительными проекциями. Принадлежность доказательству определяется корневой топологией МТС и достижимым замыканием его обоснования.

## 2. Общая внешняя форма

```text
ProofOccurrence = Claim ⟼ Support
```

Первая координата — точная доказываемая связь. Вторая — топология МТС, из которой доверенная проверка восстанавливает закон доказательства. Названия выше только поясняют роли и не вводят фундаментальные типы МТС.

Запрещено придавать доказательный авторитет внешнему признаку вида шага, узлу объектной модели или порядку программных проверок.

```text
ProofStepKind
StructuralProofNode
IdentityProofNode
ProjectionNode
kind
```

## 3. Принятое корневое структурное применение

```text
Occurrence = Claim ⟼ ApplicationV1
ApplicationV1 = StructuralDerivationRule ⟼ ExactSequence(dependency ProofOccurrences)
```

Структурное применение остаётся относительным к точной Теории.

```text
Theory ⟼ StructuralRule
Theory ⟼ StructuralDerivationRule
```

Успешная проверка производного доказательства не разрешает создавать новое примитивное допущение производного правила. Точная ревизия Теории остаётся неизменной.

## 4. Полная подстановка и локальные роли

Для одного примитивного правила действует одна полная подстановка ролей, одновременно удовлетворяющая всем его посылкам и заключению.

```text
rho_local : LocalRole -> Link
missing/conflicting binding -> reject
repeated Role               -> same exact value
grounded subtree            -> exact identity
```

#1093/#1100 установили, что примитивному правилу не требуется владеть невидимыми ролями более широкого обобщённого контекста. Вместо общего словаря используются локальные словари и принятое отображение ролей, представленное связями МТС.

```text
mu : LocalRole -> GlobalRole
```

Поэтому прежний аргумент в пользу отдельного носителя полного набора значений для каждого корневого применения опровергнут.

## 5. Принятое рекурсивное тождество связи

```text
Occurrence = IdentityClaim(left,right) ⟼ ExactSequence(child ProofOccurrences)
IdentityClaim(left,right) = left ⟼ right
```

Проверка восстанавливает рекурсивные обязательства только из топологии связей, замыкается на корень и отвергает недоказанные циклы.

```text
intrinsic identity != Theory-specific primitive admission
```

Нельзя создавать искусственное примитивное правило Теории только ради унификации программного интерфейса.

## 6. Принятый K1 — смешанное корневое доказательство

```text
MIXED_ROOTED_PROOF_ANET_DEPENDENCY = SUPPORTED
```

Корневое структурное применение может использовать корректно проверяемое рекурсивное тождество связи как обычную зависимость при точном совпадении требуемой доказываемой связи.

Для каждого достижимого вхождения, не являющегося объявленным допущением цели, K1 независимо проверяет допустимые законы и применяет закрытую классификацию.

```text
0 valid interpretations -> invalid-proof-occurrence
1 valid interpretation  -> accept exact Claim
>1 interpretations      -> ambiguous-proof-support
```

Порядок программных проверок не является семантикой.

## 7. Достижимость и авторитет

Только достижимое замыкание вхождений, реально принятых тем же механизмом K1, образует доказательный авторитет.

```text
reachable validated proof-support closure from rooted target
=
proof membership authority
```

Недостижимое доказательное вхождение, внешнее свидетельство, кэш, отображение или случайная связь между двумя вхождениями ничего не доказывают.

```text
raw Memory reachability
!=
K1-validated ProofOccurrence closure
```

## 8. Принятый K1d2 — неоднородное обобщённое доказательство

K1d2 устранил необходимость искусственно расширять каждое примитивное правило до общего словаря ролей.

```text
Global RoleDictionary = Dglobal
Local primitive RoleDictionary = Dlocal
mu : Dlocal -> Dglobal
```

Каждый обобщённый примитивный узел сохраняет точное локальное правило, локальный словарь ролей, точное отображение ролей и упорядоченные зависимости.

```text
HETEROGENEOUS_GENERIC_PROOF_ANET = SUPPORTED
LOCAL_ROLE_OBSERVABILITY = SUPPORTED
MAPPED_GLOBAL_PRIMITIVE_ADMISSION = NOT REQUIRED
K1D2_SECURITY_CORPUS = GREEN
```

Целевое производное правило не становится примитивным авторитетом Теории.

## 9. Принятый K1d3 — связь обобщённого доказательства с открытым конкретным экземпляром

K1d3 связывает один принятый обобщённый сертификат с одним независимо проверяемым открытым корневым доказательством.

```text
Generic Proof Anet
  <->
Concrete OPEN Rooted Proof Anet
```

Полная глобальная подстановка не передаётся как доверенное внешнее отображение и не требует отдельного носителя. Она восстанавливается из конкретных доказываемых связей, полных локальных подстановок, точных отображений ролей и попарного соответствия топологии.

```text
HETEROGENEOUS_GENERIC_OPEN_ROOTED_INSTANCE_BINDING = SUPPORTED
GLOBAL_ROLE_INSTANCE_OBSERVABILITY = SUPPORTED
EXPLICIT_RHO_AUTHORITY = NOT REQUIRED
ROOTED_K1_SEMANTICS = UNCHANGED
K1D3_SECURITY_CORPUS = GREEN
```

## 10. Принятый K1d4 — топологическая разрядка допущений

K1d4 заменяет только достижимые открытые листья-допущения и доказывает, что независимо корректное закрытое корневое доказательство является точной заменой допущений данного открытого экземпляра.

```text
AcceptedGenericOpenInstance
+
IndependentlyAcceptedClosedRootedProof
+
ExactTopologyDerivedGraftCorrespondence
=
TrustedClosedGenericInstance
```

Доверенный вход K1d4 не содержит внешнего списка соответствий допущений доказательствам, признака вида доказательства, внешней подстановки или отдельного носителя разрядки.

При замене допущения K1d4 сравнивает только точную доказываемую связь. Закон предоставленного доказательства уже независимо выбран K1.

```text
TOPOLOGY_DERIVED_ASSUMPTION_DISCHARGE = SUPPORTED
CLOSED_ROOTED_GENERIC_INSTANCE = SUPPORTED
EXPLICIT_DISCHARGE_CARRIER_AUTHORITY = NOT REQUIRED
PROOF_LAW_NEUTRAL_DISCHARGE = SUPPORTED
ROOTED_K1_SEMANTICS = UNCHANGED
```

## 12. Текущее состояние T4 после точного повторного прогона #1112

Теорема:

```text
(A ⟼ L) = (B ⟼ L)
-------------------
A = B
```

имеет независимые статусы:

```text
STRUCTURE  = SUPPORTED
PROOF_ANET = GAP(GENERIC_PROOF_SUBANET_PROVENANCE:invalid-generic-occurrence)
REUSE      = NOT TESTED
```

#1112 установил:

```text
identity pole sub-Anet already exists/replays
K1d4 can consume it
T4 generic provenance still rejects at invalid-generic-occurrence
```

Следовательно оставшийся разрыв находится не в истинности поддоказательства и не в разрядке допущений, а в общем законе происхождения и повторного использования уже доказанного подфрагмента.

## 13. Одобренный K1e — проекция уже проверенного поддоказательства

#1113 после самопроверки и глобального обзора #1114 одобряет вариант A.

Первый этап должен принимать существующую одно-посылочную структурную схему, закрытое доказательство посылки и только из самой доказываемой связи посылки выводить полную подстановку ролей. После этого заключение схемы сопоставляется только с теми вхождениями, которые реально входят в проверенное K1-замыкание родительского доказательства.

```text
MTS-native one-premise ProjectionSchema
+
closed K1-valid premise ProofOccurrence
+
complete role substitution inferred only from premise Claim
+
K1-validated reachable ProofOccurrence closure
->
exact already-existing unique matching ProofOccurrence
```

K1e не создаёт новый закон доказательства и не материализует новое доказательное вхождение.

Нулевой авторитет имеют:

```text
schema admission
host projectedOccurrence
host rho / Map
ambient Parent -> Child Link
raw pole closure
```

Результат обязан быть точным уже существующим вхождением из проверенного замыкания.

```text
0 matches  -> projection-not-found
1 match    -> return exact existing ProofOccurrence
>1 matches -> ambiguous-projection
```

Все роли схемы должны быть полностью выведены из единственной посылки до проверки заключения.

## 14. Общий внутренний механизм K1 для K1e

K1e не должен строить второй обходчик доказательств. Требуется один внутренний механизм проверки закрытого вхождения, использующий те же законы и ту же классификацию, что и принятый K1.

```text
closed ProofOccurrence
-> independently attempt accepted K1 laws
-> 0/1/>1 selection
-> exact Claim + exact validated occurrence closure
```

Состояние каждой попытки изолировано до единственного выбора.

```text
failed candidate    -> contributes no validated closure
ambiguous selection -> contributes no validated closure
unique selected law -> contributes only that law's validated closure
```

Отдельный внешний обработчик допущений не вводится. Открытые допущения целевого корневого доказательства остаются структурно распознаваемыми в существующей оболочке K1.

Существующие наружные результаты двух принятых проверок не должны менять смысл диагностических полей ради K1e.

```text
replayRecursiveLinkIdentityProofAset
replayStructuralRootedProofAset
```
