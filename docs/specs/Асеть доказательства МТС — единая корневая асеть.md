# Асеть доказательства МТС — единая корневая асеть

Статус: текущая каноническая спецификация доказательного авторитета поверх принятой МТС `v0.11`.
Владельцы: #999, #1066, #1087, #1102, #1109, #1113, #1114, #1057, #1064. Переход к семантическому циклу допускается только через #995.
Исторический документ `docs/specs/Асеть доказательства МТС.md` остаётся журналом развития. Имя текущего файла сохраняет историческое `Асеть`; новая английская терминология использует `Anet` согласно #1049.

```text
accepted MTS = v0.11
active semantic candidate = NONE
```

## 1. Главный закон

```text
proof authority = one rooted reachable MTS proof Anet
```

Массивы, отображения, множества, внешние объекты, графические модели, обменные форматы и текст являются только рабочими или представительными проекциями. Принадлежность доказательству определяется корневой топологией МТС и достижимым замыканием его обоснования.

## 2. Общая внешняя форма

```text
ProofOccurrence = Claim ⟼ Support
```

Первая координата — точная доказываемая связь. Вторая — топология МТС, из которой доверенная проверка восстанавливает закон доказательства. Названия в записи выше поясняют роли и не являются фундаментальными типами МТС.

Запрещён внешний авторитет вида `ProofStepKind`, `StructuralProofNode`, `IdentityProofNode`, `ProjectionNode` или признака `kind`. Если смысл вхождения нельзя восстановить из связей, такая форма не входит в доказательный авторитет.

## 3. Принятое корневое структурное применение V1

```text
Occurrence = Claim ⟼ ApplicationV1
ApplicationV1 = StructuralDerivationRule ⟼ ExactSequence(dependency ProofOccurrences)
```

Структурное применение остаётся относительным к точной Теории:

```text
Theory ⟼ StructuralRule
Theory ⟼ StructuralDerivationRule
```

Успешная проверка производного доказательства не разрешает создавать `Theory ⟼ DerivedDR`; точная ревизия Теории остаётся неизменной.

## 4. Полная структурная подстановка ρ и локальные роли

Для одного примитивного `StructuralDerivationRule` действует одна полная подстановка `rho_local : LocalRole -> Link`, одновременно удовлетворяющая всем его посылкам и заключению. Для каждой роли именно локального `RoleDictionary` примитивного правила требуется ровно одно значение.

```text
missing/conflicting binding -> reject
repeated Role               -> same exact value
grounded subtree            -> exact identity
```

#1093/#1100 установили, что примитивному правилу не требуется владеть невидимыми ролями более широкого generic-контекста. Вместо общего словаря используются локальные словари и принятое MTS-native отображение:

```text
mu : LocalRole -> GlobalRole
```

Поэтому старый shared-dictionary аргумент в пользу отдельного `Act`/explicit-rho carrier для корневого применения опровергнут.

## 5. Принятое рекурсивное тождество связи

```text
Occurrence = IdentityClaim(left,right) ⟼ ExactSequence(child ProofOccurrences)
IdentityClaim(left,right) = left ⟼ right
```

Проверка восстанавливает рекурсивные обязательства из топологии связей и остаётся замкнутой на корень и запрещающей недоказанные циклы.

```text
intrinsic identity != Theory-specific primitive admission
```

Нельзя создавать искусственное `Theory ⟼ IdentityRule` только ради унификации программного интерфейса.

## 6. Принятый K1 — смешанное корневое доказательство

```text
MIXED_ROOTED_PROOF_ANET_DEPENDENCY = SUPPORTED
```

Корневое структурное применение может использовать корректно проверяемое рекурсивное тождество связи как обычную зависимость при точном совпадении требуемого `Claim`.

Для каждого не-assumption `ProofOccurrence` K1 независимо проверяет допустимые законы и затем применяет fail-closed классификацию:

```text
0 valid interpretations -> invalid-proof-occurrence
1 valid interpretation  -> accept exact Claim
>1 interpretations      -> ambiguous-proof-support
```

Порядок программных проверок не является семантикой.

## 7. Достижимость и доказательный авторитет

```text
reachable validated proof-support closure from rooted target
=
proof membership authority
```

Недостижимое доказательное вхождение, внешнее свидетельство, host cache, host Map/Set или случайная связь между двумя proof occurrences ничего не доказывают.

Важно различать:

```text
raw Memory reachability
!=
K1-validated ProofOccurrence closure
```

Для будущего повторного использования поддоказательств учитываются только exact `ProofOccurrences`, реально принятые тем же K1 candidate-law replay.

## 8. Принятый K1d2 — heterogeneous generic proof Anet

K1d2 устранил необходимость искусственно расширять каждое примитивное правило до общего словаря ролей.

```text
Global RoleDictionary = Dglobal
Local primitive RoleDictionary = Dlocal
mu : Dlocal -> Dglobal
```

Каждый generic primitive node сохраняет:

```text
exact LocalPrimitiveDR
exact local RoleDictionary
exact MTS-native mu
ordered dependency occurrences
```

Принятые свойства:

```text
HETEROGENEOUS_GENERIC_PROOF_ANET = SUPPORTED
LOCAL_ROLE_OBSERVABILITY = SUPPORTED
MAPPED_GLOBAL_PRIMITIVE_ADMISSION = NOT REQUIRED
K1D2_SECURITY_CORPUS = GREEN
```

Generic target Rule/DR не становится primitive Theory authority.

## 9. Принятый K1d3 — generic ↔ concrete OPEN rooted instance

K1d3 связывает один принятый heterogeneous generic certificate с одним независимо K1-valid concrete OPEN rooted proof.

```text
Generic Proof Anet
  <->
Concrete OPEN Rooted Proof Anet
```

Полная глобальная подстановка не передаётся как trusted host rho и не требует отдельного carrier. Она восстанавливается из:

```text
concrete primitive Claims
+
complete local substitutions
+
exact mu mappings
+
lockstep generic/concrete correspondence
```

Принятые свойства:

```text
HETEROGENEOUS_GENERIC_OPEN_ROOTED_INSTANCE_BINDING = SUPPORTED
GLOBAL_ROLE_INSTANCE_OBSERVABILITY = SUPPORTED
EXPLICIT_RHO_AUTHORITY = NOT REQUIRED
ROOTED_K1_SEMANTICS = UNCHANGED
K1D3_SECURITY_CORPUS = GREEN
```

## 10. Принятый K1d4 — topology-derived OPEN → CLOSED discharge

K1d4 разряжает только reachable open assumption leaves и доказывает, что independently valid CLOSED rooted proof является точной graft-заменой assumptions данного OPEN instance.

Нормативная формула:

```text
AcceptedGenericOpenInstance
+
IndependentlyAcceptedClosedRootedProof
+
ExactTopologyDerivedGraftCorrespondence
=
TrustedClosedGenericInstance
```

Trusted K1d4 input не содержит:

```text
host assumption->proof authority
proof kind
host rho
Act
explicit trusted discharge map
```

На assumption replacement K1d4 сверяет только exact `Claim`; закон supplied proof уже независимо выбран K1.

Принятые свойства:

```text
TOPOLOGY_DERIVED_ASSUMPTION_DISCHARGE = SUPPORTED
CLOSED_ROOTED_GENERIC_INSTANCE = SUPPORTED
EXPLICIT_DISCHARGE_CARRIER_AUTHORITY = NOT REQUIRED
PROOF_LAW_NEUTRAL_DISCHARGE = SUPPORTED
ROOTED_K1_SEMANTICS = UNCHANGED
```

## 12. Текущее состояние T4 после exact rerun #1112

Теорема:

```text
(A ⟼ L) = (B ⟼ L)
-------------------
A = B
```

имеет текущее независимое состояние:

```text
STRUCTURE  = SUPPORTED
PROOF_ANET = GAP(GENERIC_PROOF_SUBANET_PROVENANCE:invalid-generic-occurrence)
REUSE      = NOT TESTED
```

#1112 установил три важных факта:

```text
1. recursive identity proof родительского равенства уже содержит exact proof occurrence для pole identity;
2. это projected occurrence независимо K1-valid;
3. K1d4 способен использовать его как law-neutral assumption replacement.
```

Следовательно remaining gap находится не в proof truth и не в discharge, а в generic provenance/reuse relation:

```text
reusable schema
+
validated parent ProofOccurrence
->
exact validated sub-Anet already inside that proof
```

## 13. Одобренный K1e — topology-derived proof-subAnet projection

#1113 после self-review и global review #1114 одобряет Variant A.

Цель первого slice:

```text
MTS-native one-premise ProjectionSchema
+
closed K1-valid premise ProofOccurrence
+
complete role substitution inferred only from premise Claim
+
K1-validated reachable ProofOccurrence closure
->
exact already-existing unique matching ProofOccurrence
```

K1e не создаёт новый proof occurrence и не добавляет новый K1 proof law.

Строго:

```text
schema admission = zero K1e authority
host projectedOccurrence = zero authority
host rho/Map = zero authority
ambient Parent->Child Link = zero authority
raw pole closure = zero authority
```

Projection result должен быть exact existing `ProofOccurrence`, уже входящим в validated closure родительского доказательства.

First-slice selection:

```text
0 matches  -> projection-not-found
1 match    -> return exact existing ProofOccurrence
>1 matches -> ambiguous-projection
```

Все schema Roles должны быть полностью выведены из единственного premise template до проверки conclusion template. Conclusion-only неизвестные роли запрещены.

## 14. Общий K1 core для K1e

K1e не должен строить второй identity/structural walker.

Нужен один внутренний callback-free CLOSED occurrence replay surface, использующий тот же candidate-law механизм, что и accepted rooted K1:

```text
closed ProofOccurrence
-> independently attempt accepted K1 laws
-> 0/1/>1 selection
-> exact Claim + exact validated occurrence closure
```

Кандидатное состояние транзакционно:

```text
failed candidate    -> contributes no validated closure
ambiguous selection -> contributes no validated closure
unique selected law -> contributes only that law's validated closure
```

Существующие наружные result contracts `replayRecursiveLinkIdentityProofAset` и `replayStructuralRootedProofAset` не должны молча менять diagnostic semantics ради K1e.
