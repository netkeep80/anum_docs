# МТС следующего цикла — смысл только в рекурсии и уникальность акорня

Статус: **исследовательский результат**, владелец #670, родитель #657.

Принятое машинное состояние не меняется:

```text
current  = MTS v0.9
previous = MTS v0.8
runtime  = TypeScript only
```

Документ уточняет уже исследованные F2/F3. Новую принятую аксиоматику и runtime semantics он не вводит.

## 1. Главный принцип

Рабочая формулировка МТС:

```text
в МТС смысл возникает только в рекурсии;
смысл есть связь смыслов;
только полная рекурсия даёт онтологический корень асети связей.
```

Здесь рекурсия — зависимость смысла от смысла, а не порядок вызовов программы. Исполнительная рекурсия относится к #668.

Различаем:

```text
полная рекурсия
односторонняя/частичная рекурсия
взаимная рекурсия
исполнительная рекурсия
```

## 2. Смысл не является внешней меткой

Для формы:

```text
X = A ⟼ B
```

имя `X` не является semantic ID. Смысловое различие не создают также runtime/storage ID, source occurrence, адрес памяти или порядок создания.

Различие может опираться только на структуру уже различённых смыслов и положение самой связи в рекурсивной зависимости.

Поэтому «смысл есть связь смыслов» означает: смысл связи определяется связями её смысловых полюсов и способом рекурсивного самовведения, а не добавляется извне.

## 3. Обычная связь даёт только производный смысл

Форма:

```text
X = A ⟼ B
```

может иметь самостоятельное различие только если `A` и `B` уже укоренены.

В F2 это:

```text
PAIR(F,G)
```

при конечном основании `F` и `G`.

Следовательно нерекурсивная пара не является первичным источником смысла: она получает производный смысл из уже различённых полюсов.

## 4. Полная рекурсия

Полная рекурсия:

```text
X = X ⟼ X
```

замыкает оба внутренних полюса на одно внешнее единство `X`.

Её особенность:

```text
нет внешнего смыслового полюса,
который требовал бы предварительного основания.
```

Поэтому F2 допускает конечную форму:

```text
ROOT
```

без внешней зависимости. В этом точном смысле полная рекурсия даёт онтологический корень.

## 5. Односторонняя рекурсия

Формы:

```text
X = X ⟼ A
Y = A ⟼ Y
```

рекурсивны, но один полюс остаётся внешним.

В F2 им соответствуют:

```text
START(F)
END(F)
```

и `F` должно уже иметь конечное основание.

Следовательно односторонняя рекурсия может давать производный самостоятельный смысл, но не первичный корень.

## 6. Взаимная рекурсия

Например:

```text
X = Y ⟼ R
Y = X ⟼ R
```

или:

```text
X = Y ⟼ R
Y = R ⟼ X
```

не дают конечного независимого основания `X/Y`: различие каждого требует различия другого.

Получается пустая круговая зависимость:

```text
X различим через Y
Y различим через X
```

Поэтому наличие цикла или графовой асимметрии само по себе не создаёт смысловую индивидуальность. Это согласуется с F2-классом `UNDERGROUNDED`.

## 7. Точная версия «смысл только в рекурсии»

Фраза не означает:

```text
любая циклическая система автоматически имеет смысл.
```

Точнее:

```text
самостоятельное различие смысла в МТС требует рекурсивного
самовведения с конечным основанием различия;
обычная связь получает только производный смысл из уже
укоренённых полюсов.
```

Рекурсия необходима как механизм самовведения, но не всякая рекурсия достаточна для укоренения.

## 8. Иерархия оснований

```text
X = X ⟼ X
  -> ROOT
  -> первичное основание

X = X ⟼ A
X = A ⟼ X
  -> START(F) / END(F)
  -> производное основание при укоренённом A

X = A ⟼ B
  -> PAIR(F,G)
  -> производное основание при укоренённых A,B

чистая взаимная рекурсия
  -> основания нет без внешнего укоренения
```

Это порядок доказательства различия, не история создания связей.

## 9. Уникальность акорня: ограничение теоремы

Исследуем:

```text
X = X ⟼ X  =>  X = R
```

Из одного fixed-point equation это **не следует**.

Произвольная внешняя модель циклических объектов может представить:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

как два разных технических узла и различить их внешними ID.

Но F2/F3 запрещают имя или технический ID как источник смыслового различия.

## 10. Теорема внутри основания F2

Для обеих форм:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

F2 даёт одну конечную форму доказательства:

```text
ROOT
```

Имена `X/Y` нейтральны к согласованному переименованию и не создают индивидуальность.

Поэтому:

```text
Σ ⊢ X ⇓ ROOT
Σ ⊢ Y ⇓ ROOT
----------------
rho(X) ≈ rho(Y)
```

где `≈` — метаотношение совпадения укоренённых форм.

Если `R` — каноническое имя этого класса, то:

```text
X = X ⟼ X  =>  X ≈ R
```

То есть два полных самозамыкания не дают два онтологических корня.

## 11. Почему это не runtime canonicalization

Доказательство не должно быть правилом реализации:

```text
if selfStart && selfEnd then return rootSingleton
```

Оно следует из трёх принципов F2/F3:

```text
1. связанное имя не является semantic ID;
2. полная рекурсия имеет единственную конечную форму ROOT;
3. совпадение форм минимально и нейтрально к переименованию.
```

Runtime canonicalization может только отражать уже установленное смысловое тождество.

## 12. Почему ROOT не схлопывает O и C

F2 различает:

```text
ROOT
START(ROOT)
END(ROOT)
```

Положение самоссылки различно. Минимальное отношение сворачивания не разрешает круговой вывод:

```text
ROOT ≈ START(ROOT)
```

только потому, что обе формы рекурсивны.

Поэтому уникальность полного корня не означает схлопывание всех рекурсивных смыслов в `R`.

## 13. Контекст `:` + `↑`

Кандидат #658:

```text
R: ↑ ⟼ ↑
O: ↑ ⟼ R
C: R ⟼ ↑
```

делает различие полной и односторонней рекурсии явным.

В:

```text
R: ↑ ⟼ ↑
```

оба полюса возвращаются к текущему внешнему единству, внешнего смыслового аргумента нет.

В:

```text
O: ↑ ⟼ R
C: R ⟼ ↑
```

один полюс уже зависит от укоренённого `R`.

Контекст не создаёт новую теорему уникальности, а явным образом записывает её структурную геометрию.

## 14. Groundedness не равно смыслу

F2 `groundedness` — технический критерий конечного доказательства различия, а не замена понятия смысла.

Корректное разделение:

```text
рекурсивное основание смысла
  -> содержательный принцип МТС

конечное укоренение F2
  -> проверка, что различие не держится
     на пустой круговой зависимости
```

## 15. Контрпримерный корпус

Полная рекурсия:

```text
R = R ⟼ R
```

даёт `ROOT`.

Односторонние формы:

```text
X = X ⟼ R
Y = R ⟼ Y
```

дают `START(ROOT)` и `END(ROOT)` — производные смыслы, не новые корни.

Чистая взаимная рекурсия:

```text
X = Y ⟼ R
Y = X ⟼ R
```

не имеет конечного основания `X/Y` только из этого цикла.

Перекрёстная форма:

```text
X = Y ⟼ Y
Y = X ⟼ X
```

также имеет циклическую структуру, но не первичное конечное различие.

Два полных самозамыкания:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

дают:

```text
rho(X) ≈ ROOT
rho(Y) ≈ ROOT
rho(X) ≈ rho(Y)
```

## 16. Граница результата

Этот срез не утверждает, что F2 — единственно возможное метаоснование МТС.

Он утверждает:

```text
в текущей исследовательской дисциплине F2 уникальность
полного рекурсивного корня выводима;
из одного fixed-point equation без запрета внешних ID
и без конечного основания она не выводима.
```

Теорема относится к смысловому основанию МТС, а не к произвольной теории циклических графов.

## 17. Итог #670

```text
1. Самостоятельный смысл требует рекурсивного самовведения.
2. Обычная связь получает производный смысл из укоренённых полюсов.
3. Односторонняя рекурсия требует укоренённого внешнего полюса.
4. Чистая взаимная рекурсия без внешнего основания не создаёт
   индивидуальность сама по себе.
5. Полная рекурсия X=X⟼X не требует внешнего смыслового основания
   и даёт первичную форму ROOT.
6. Все полные самозамыкания имеют один ROOT-класс;
   онтологический акорень единственен по semantic identity.
7. Исполнительная рекурсия в доказательстве не участвует.
```

## 19. Критерий опровержения

Результат пересматривается, если найдена форма, которая одновременно:

```text
1. не использует внешние ID/имена/occurrence как различие;
2. имеет конечное рекурсивное основание;
3. полностью саморекурсивна по обоим полюсам;
4. не совпадает с ROOT по минимальному отношению F2.
```

Или если показан первичный самостоятельный смысл без рекурсивного самовведения.

До такого контрпримера результат согласован с F2/F3 и пригоден как вход для #658/#659.
