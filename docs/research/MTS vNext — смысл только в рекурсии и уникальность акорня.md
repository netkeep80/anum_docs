# МТС следующего цикла — смысл только в рекурсии и уникальность акорня

Статус: **исследовательский результат**, владелец #670, родительский план #657.

Принятое машинное состояние не меняется:

```text
current  = MTS v0.9
previous = MTS v0.8
runtime  = TypeScript only
```

Этот документ не вводит новую принятую аксиоматику. Он уточняет смысл уже исследованных F2/F3 и формулирует критерий, по которому рекурсивная форма получает самостоятельное смысловое основание.

## 1. Главная формулировка

Рабочий принцип МТС:

```text
в МТС смысл возникает только в рекурсии;
смысл есть связь смыслов;
только полная рекурсия даёт онтологический корень асети связей.
```

Здесь слово «рекурсия» относится прежде всего к рекурсивной зависимости смысла от смысла, а не к порядку исполнения программы.

Поэтому отдельно различаются:

```text
рекурсивное основание смысла
частичная/односторонняя рекурсия
взаимная рекурсия
полная рекурсия
исполнительная рекурсия
```

Исполнительная рекурсия относится к #668 и не используется как онтологическое доказательство.

## 2. Что значит «смысл есть связь смыслов»

Связь МТС не получает самостоятельный смысл из:

```text
имени
runtime ID
storage ID
source occurrence
порядка создания
адреса в памяти
```

Если связанная форма записана как:

```text
X = A ⟼ B
```

то различие `X` может быть обосновано только различием его полюсов и способом рекурсивного связывания этих полюсов с самой связью.

Следовательно смысл не добавляется к связи извне как метка. Он определяется структурой связей уже различённых смыслов и рекурсивным положением самой связи в этой структуре.

## 3. Почему нерекурсивная запись сама по себе недостаточна

Форма:

```text
X = A ⟼ B
```

не даёт самостоятельного основания `X`, если `A` и `B` сами не имеют уже обоснованного смысла.

Если `A` и `B` укоренены, эта форма может получить производный смысл как связь двух уже различённых смыслов.

Значит обычная пара не является первичным источником смысла. Она наследует различимость от уже укоренённых полюсов.

Это соответствует F2-форме:

```text
PAIR(F,G)
```

где `F` и `G` должны иметь конечное основание различия.

## 4. Полная рекурсия

Полная рекурсия имеет форму:

```text
X = X ⟼ X
```

Здесь оба внутренних полюса возвращаются к одному внешнему единству `X`.

Критическое отличие от всех остальных случаев:

```text
нет внешнего полюса,
который требовал бы предварительного смыслового основания.
```

Поэтому F2 допускает для такой формы нулевое внешнее основание:

```text
ROOT
```

Полная рекурсия является единственным исследованным случаем, в котором конечное основание различия не зависит от уже различённой внешней формы.

Именно в этом смысле она является онтологическим корнем.

## 5. Односторонняя рекурсия

Формы:

```text
X = X ⟼ A
Y = A ⟼ Y
```

рекурсивны, но не полностью.

Одна внутренняя позиция возвращается к текущей связи, а вторая зависит от внешнего смысла `A`.

В F2 это:

```text
START(F)
END(F)
```

где `F` должно уже иметь конечное основание.

Поэтому односторонняя рекурсия может давать самостоятельный **производный** смысл, но не первичный корень.

Без укоренённого `A` она не получает индивидуальность только из собственной самоссылки.

## 6. Взаимная рекурсия

Рассмотрим:

```text
X = Y ⟼ R
Y = X ⟼ R
```

Несмотря на наличие цикла, `X` и `Y` не имеют конечного независимого основания различия.

Попытка обосновать `X` требует сначала `Y`, а попытка обосновать `Y` требует сначала `X`.

Получается:

```text
X различим через Y
Y различим через X
```

без дополнительного основания.

Поэтому чистая взаимная рекурсия не создаёт две самостоятельные смысловые связи только из факта наличия двух обозначений.

Это уже согласуется с классификацией F2 как `UNDERGROUNDED`.

## 7. Взаимная рекурсия с асимметрией

Даже запись вида:

```text
X = Y ⟼ R
Y = R ⟼ X
```

структурно асимметрична, но одна асимметрия графа не создаёт первичного смыслового различия.

Пока различие `X/Y` опирается только друг на друга, конечного основания нет.

Следовательно:

```text
графовая различимость
!=
смысловая укоренённость
```

## 8. Что именно значит «смысл только в рекурсии»

Эту фразу нельзя понимать как:

```text
любая циклическая система автоматически имеет смысл.
```

Более точная формулировка:

```text
самостоятельное различие смысла в МТС допускается только через
рекурсивно связанную форму, имеющую конечное основание различия;
нерекурсивная связь получает только производный смысл из уже
различённых полюсов.
```

Таким образом, рекурсия необходима как механизм самовведения смысла, но не всякая рекурсия достаточна для укоренения.

## 9. Иерархия форм

Получается следующая классификация:

```text
полная рекурсия
  X = X ⟼ X
  -> первичное основание ROOT

односторонняя рекурсия
  X = X ⟼ A
  X = A ⟼ X
  -> производное основание при укоренённом A

обычная связь
  X = A ⟼ B
  -> производное основание при укоренённых A и B

чистая взаимная рекурсия
  -> не даёт основания без внешнего укоренения
```

Это не временной порядок возникновения сущностей. Это порядок конечного доказательства различия.

## 10. Теорема об уникальности акорня

Исследуем утверждение:

```text
X = X ⟼ X  =>  X = R
```

Сначала важное ограничение.

Из одного только уравнения неподвижной точки это утверждение **не следует**.

Если внешняя модель разрешает произвольные немаркированные циклические объекты, она может технически представить два разных узла:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

и различать их по внешним идентификаторам.

Но такие идентификаторы запрещены как источник смыслового различия в F2/F3.

## 11. Уникальность внутри основания F2

В принятой исследовательской дисциплине F2 обе формы:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

имеют одну и ту же конечную форму доказательства:

```text
ROOT
```

Различие имён `X` и `Y` нейтрально к согласованному переименованию и не создаёт смысловую индивидуальность.

Следовательно обе связанные ссылки получают один класс укоренённой формы.

Поэтому внутри F2 можно сформулировать:

```text
если Σ ⊢ X ⇓ ROOT
и Σ ⊢ Y ⇓ ROOT,
то rho(X) ≈ rho(Y).
```

Если `R` — каноническое имя этого класса, то:

```text
X = X ⟼ X  =>  X ≈ R
```

где `≈` — метаотношение совпадения укоренённых форм, а не новый внутренний знак МТС.

## 12. Почему это не runtime canonicalization

Уникальность акорня не должна реализовываться правилом:

```text
if selfStart && selfEnd then return singletonRootObject
```

Такое правило может быть допустимой оптимизацией реализации, но не доказательством.

Доказательство опирается на три более сильных принципа:

```text
1. имя связанной ссылки не является смысловым ID;
2. полная рекурсия имеет единственную конечную форму ROOT;
3. отношение совпадения форм является минимальным и нейтральным к переименованию.
```

Техническая канонизация может только отражать уже установленное смысловое тождество.

## 13. Почему ROOT не схлопывает O и C

Полная рекурсия:

```text
ROOT
```

отличается от:

```text
START(ROOT)
END(ROOT)
```

Позиция самоссылки структурно различна.

Минимальное отношение сворачивания F2 не разрешает круговое доказательство:

```text
ROOT ≈ START(ROOT)
```

только потому, что обе формы рекурсивны.

Следовательно уникальность полного корня не означает схлопывание всех рекурсивных форм в `R`.

## 14. Контекстная запись делает различие явным

Кандидат #658:

```text
R: ↑ ⟼ ↑
O: ↑ ⟼ R
C: R ⟼ ↑
```

показывает три разных положения текущего внешнего единства внутри внутренней дуальности.

Полная рекурсия:

```text
R: ↑ ⟼ ↑
```

не содержит внешнего смыслового аргумента.

Односторонние формы:

```text
O: ↑ ⟼ R
C: R ⟼ ↑
```

содержат один уже укоренённый внешний полюс `R`.

Поэтому `:` + `↑` не создают новый принцип уникальности, но делают геометрию полной и частичной рекурсии явной.

## 15. Связь с F3

F3 должен сохранять вывод:

```text
semantic identity
!=
runtime occurrence identity
```

Если две записи имеют одну укоренённую форму, два объекта среды исполнения, два имени или два вхождения текста не создают две смысловые связи.

Поэтому два предъявления полной рекурсии не создают два акорня.

## 16. Groundedness не является определением смысла

Термин `groundedness` в F2 — технический критерий конечного доказательства различия.

Его не следует отождествлять со словом «смысл».

Корректнее:

```text
рекурсивное основание смысла
  — содержательный принцип;

конечное укоренение F2
  — технический критерий,
    позволяющий проверить, что различие не держится
    на пустой круговой зависимости.
```

То есть F2 проверяет допустимость рекурсивного основания, но не заменяет само понятие смысла.

## 17. Контрпримерный корпус

### Полная рекурсия

```text
R = R ⟼ R
```

Результат: `ROOT`.

### Односторонняя рекурсия от корня

```text
X = X ⟼ R
Y = R ⟼ Y
```

Результат:

```text
START(ROOT)
END(ROOT)
```

Это производные смыслы, не новые корни.

### Чистая взаимная рекурсия

```text
X = Y ⟼ R
Y = X ⟼ R
```

Результат: нет конечного основания `X/Y` только из этой пары.

### Перекрёстная взаимная рекурсия

```text
X = Y ⟼ Y
Y = X ⟼ X
```

Результат: внешняя циклическая структура есть, но первичного конечного различия нет.

### Два полных самозамыкания

```text
X = X ⟼ X
Y = Y ⟼ Y
```

Результат в F2:

```text
rho(X) ≈ ROOT
rho(Y) ≈ ROOT
rho(X) ≈ rho(Y)
```

Два разных акорня не получаются.

## 18. Что остаётся гипотезой

Этот срез не доказывает, что F2 является единственно возможным метаоснованием МТС.

Он утверждает более узкое:

```text
в уже принятой исследовательской дисциплине F2
уникальность полного рекурсивного корня выводима;
без запрета внешних идентификаторов и без минимального
конечного основания из одного fixed-point equation она не выводима.
```

Это важная граница: теорема относится к смысловому основанию МТС, а не к произвольной теории циклических графов.

## 19. Итоговая формулировка

Предлагаемый точный результат #670:

```text
1. Самостоятельный смысл в МТС требует рекурсивного самовведения.
2. Обычная связь получает производный смысл из уже укоренённых полюсов.
3. Односторонняя рекурсия получает производный смысл только при
   уже укоренённом внешнем полюсе.
4. Чистая взаимная рекурсия без внешнего основания не создаёт
   индивидуальность сама по себе.
5. Полная рекурсия X = X ⟼ X не требует внешнего смыслового основания
   и потому даёт первичную форму ROOT.
6. Все полные самозамыкания нейтральны к имени и имеют одну форму ROOT;
   следовательно онтологический акорень единственен по semantic identity.
7. Исполнительная рекурсия не участвует в этом доказательстве.
```

## 20. Handoff

Для #658:

```text
R: ↑ ⟼ ↑
```

следует проверять как явную контекстную запись единственной формы полного самовведения.

Для #659:

порождение кандидатов должно классифицировать не наличие цикла вообще, а способ конечного рекурсивного основания.

Для #671/#660:

структурные WRITE/READ операции не должны становиться новым источником смысловой индивидуальности.

Для #663:

этот результат является исследовательским уточнением основания; observable machine delta из него автоматически не следует.

## 21. Критерий опровержения

Результат должен быть пересмотрен, если будет предъявлена форма, которая одновременно:

```text
1. не опирается на внешние ID/имена/occurrence;
2. имеет конечное рекурсивное основание различия;
3. является полной саморекурсией обоих полюсов;
4. не совпадает с ROOT по минимальному отношению F2.
```

Или если будет показано, что самостоятельный первичный смысл может быть получен без какого-либо рекурсивного самовведения.

До такого контрпримера #670 считается согласованным с F2/F3 и пригодным как semantic input для #658/#659.
