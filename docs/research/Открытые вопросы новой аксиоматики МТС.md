# Открытые вопросы новой аксиоматики МТС

Статус: рабочее. Фундаментальная идентичность ведётся в #582, общий порядок работ — #588.

## Назначение

Этот регистр собирает нерешённые вопросы текущей аксиоматики. Пока вопрос находится здесь, его нельзя подавать как стабилизированную часть спецификации.

## Общие открытые вопросы

1. Как строго различить позиционное чтение повторных `[]` в формуле, последовательности и сравнении.
2. Как строить, хранить и использовать результат сравнения `(=) : {[]♀ = []♀, ♂[] = ♂[]}`.
3. Каков тип результата `[] = []`: связь, пучок, состояние различимости или производная форма.
4. Как определить `↛` и не смешать несвязь с пустым пучком, отсутствием записи и практическим нулём сериализации.
5. Как связать `0 : [↛]` с четверичной сериализацией отсутствующей связевой формы.
6. Допустимо ли пустое `()` как самостоятельная форма.
7. Как ввести переменные, именованные места и подстановку без первичных внешних атомов.
8. Как выразить все исходящие связи в пучковой нотации без внешнего универсального механизма.
9. Как связать пучковую нотацию с асетью без смешения записи, формулы и остенсивной модели.
10. Как будущий апрувер должен решать систему формул как целое.
11. Как описать операционное удаление в пучковой нотации.
12. Как стабилизировать полную роль `:` как введения различия через формулу.

## F1. Рекурсивная идентичность связи

Эти вопросы принадлежат #582 и должны быть решены до пересмотра единственности акорня, инверсии и натурального счёта.

### 13. Конечное предъявление рекурсивной формы

Рабочий носитель:

```text
P = (V, s, e, p)
```

где:

- `V` — конечное множество связанных переменных предъявления;
- `s : V -> V` задаёт начало;
- `e : V -> V` задаёт конец;
- `p ∈ V` — предъявляемая связь;
- имена и номера элементов `V` не несут смысла.

Эквивалентная запись:

```text
x = s(x) ⟼ e(x)
```

для каждого `x ∈ V`.

Смысл предъявления зависит только от части, достижимой из `p` по `s/e`; недостижимые технические записи не должны менять значение.

Минимальные примеры:

```text
R:
  r = r ⟼ r

O:
  r = r ⟼ r
  o = o ⟼ r

C:
  r = r ⟼ r
  c = r ⟼ c
```

### 14. Равенство предъявлений

Буквальное равенство записей отвергается: переименование связанных переменных не создаёт новую связь.

Рабочий кандидат первого уровня — изоморфизм достижимых конечных ориентированных форм с сохранением выбранной связи и порядка полюсов:

```text
f(p1) = p2
f(s1(x)) = s2(f(x))
f(e1(x)) = e2(f(x))
```

Такое сравнение сохраняет:

- рисунок самоссылки;
- порядок начала и конца;
- конечное совместное использование одной подформы;
- различие `R/O/C`;
- ориентационное различие `O/C`.

Но одного изоморфизма недостаточно: произвольная неукоренённая циклическая форма тоже имеет конечный рисунок.

### 15. Почему обычная бисимуляция не подходит

Для немаркированной коалгебры:

```text
c : X -> X × X
```

универсальное отношение

```text
B = X × X
```

само является бисимуляцией. Для любых `x B y` автоматически:

```text
start(x) B start(y)
end(x) B end(y)
```

Следовательно обычное поведенческое равенство отождествляет все состояния, в частности:

```text
R ~ O ~ C
```

Это несовместимо с МТС.

Вывод:

> тождество МТС должно сохранять точную конечную рекурсивную форму и не может быть обычным немаркированным поведенческим равенством.

### 16. Допустимость распадается на укоренённость и индивидуализацию

Главное уточнение второго шага F1:

```text
Admissible(P)
=
Grounded(P)
∧
Individuated(P)
```

Эти два условия отвечают на разные вопросы.

`Grounded` отвечает:

> откуда вообще берётся право считать различия внутри рекурсивной формы смысловыми?

`Individuated` отвечает:

> какие внутренние переменные действительно различены самой ориентированной рекурсивной структурой относительно уже различённого основания?

Одно условие нельзя заменить другим.

### 17. Рекурсивный блок относительно уже различённой границы

Для анализа сильносвязной рекурсивной компоненты удобно отделить внутренние переменные от уже различённых внешних форм:

```text
B = internal variables
Γ = grounded boundary
s,e : B -> B ∪ Γ
```

Элементы `Γ` считаются уже различёнными результатом предыдущих шагов построения и при анализе блока фиксируются поточечно.

Это не вводит скрытых идентификаторов: граница состоит из уже полученных смысловых классов, а не из адресов или номеров записей.

### 18. Индивидуализация через автоморфизмы относительно границы

Рассматриваются биекции

```text
f : B -> B
```

которые сохраняют порядок полюсов:

```text
f(s(x)) = s(f(x))
f(e(x)) = e(f(x))
```

для внутренних ссылок и фиксируют каждый элемент `Γ`.

Если существует такой автоморфизм, переводящий `x` в `y`, то весь рекурсивный блок относительно уже различённой границы не умеет отличить `x` от `y`.

Рабочее следствие:

```text
x ~aut y
=>
collapse(x,y)
```

Имена, номера и адреса не могут отменить это схлопывание.

### 19. Автоморфизмы не заменяют укоренённость

Критический отрицательный результат:

> жёсткость конечной циклической формы ещё не даёт ей смыслового основания.

Можно построить неукоренённую асимметричную циклическую форму с тривиальной группой автоморфизмов. Её внутренний рисунок различает узлы, но не объясняет, откуда в МТС возникло первичное различие этой замкнутой системы.

Поэтому правило

```text
trivial Aut(B) => admissible
```

отвергается.

Жёсткость может подтверждать индивидуализацию только после доказанной укоренённости.

### 20. Симметричная укоренённая взаимная рекурсия

Пример:

```text
x = y ⟼ R
y = x ⟼ R
```

при фиксированном `R` допускает перестановку:

```text
x <-> y
```

Следовательно `x` и `y` не индивидуализированы и должны попасть в один класс.

После схлопывания:

```text
z = z ⟼ R
```

получается форма одностороннего самозамыкания начала относительно `R`.

Это важный пример того, как более крупная техническая рекурсивная запись может не задавать новую смысловую связь, а канонизироваться к уже известной форме.

### 21. Асимметричная укоренённая взаимная рекурсия

Пример:

```text
x = y ⟼ R
y = R ⟼ x
```

Перестановка `x/y` нарушает порядок полюсов и фиксацию `R`.

Поэтому на первом шаге анализа:

```text
Orbit(x) = {x}
Orbit(y) = {y}
```

То есть структура действительно различает внутренние места относительно уже различённого `R`.

Это ещё не окончательная теорема допустимости всего класса таких форм: сначала должна быть строго определена укоренённость рекурсивного блока.

### 22. Почему схлопывание орбит надо повторять

Одного прохода по автоморфизмам недостаточно.

Существует конечная четырёхузловая форма:

```text
s(0)=0   e(0)=0
s(1)=0   e(1)=1
s(2)=0   e(2)=3
s(3)=0   e(3)=2
```

На первом шаге её орбиты:

```text
{0}, {1}, {2,3}
```

После схлопывания `{2,3}` получается трёхузловой фактор:

```text
s=(0,0,0)
e=(0,1,2)
```

В нём возникает новая симметрия:

```text
{0}, {1,2}
```

После второго схлопывания остаётся двухузловая жёсткая форма.

Следовательно канонизация должна вычислять неподвижную точку, а не только орбиты исходного предъявления.

### 23. Оператор итеративного схлопывания

Рабочий кандидат `QΓ`:

```text
P0 := P
P(n+1) := quotient of Pn by boundary-fixed automorphism orbits
stop when every orbit is singleton
```

На конечном носителе процесс завершается: каждый нетривиальный шаг строго уменьшает число внутренних классов.

Остаётся доказать:

1. полюса корректно определены на факторе;
2. результат не зависит от перечисления переменных;
3. неподвижная точка единственна с точностью до изоморфизма, фиксирующего границу;
4. порядок полюсов не теряется;
5. асимметричные различия не схлопываются случайно;
6. точное отношение этого процесса к наименьшей конгруэнции структурной неразличимости.

### 24. Отдельная задача укоренённости

Схлопывание автоморфизмов решает только задачу внутренней индивидуализации.

Нужен независимый конечный предикат укоренённости.

Минимальные обязательства:

```text
R                       -> допустим как особый начальный случай
O/C relative to R       -> укоренены
ordinary A⟼B            -> укоренена, если A/B уже укоренены
one-sided selfclosure   -> укоренено относительно укоренённого внешнего полюса
closed SCC without Γ    -> не принимается автоматически
```

Самый трудный пункт — первый: нужно определить начальный статус

```text
R = R ⟼ R
```

без кругового обращения к уже готовому тождеству и без технического запрета «второго экземпляра».

Это становится непосредственным мостом из #582 в #583.

### 25. Рабочая канонизация F1

Текущий кандидат:

```text
presentation
-> reachable part
-> grounded-block decomposition
-> iterated boundary-fixed orbit collapse
-> canonical pointed ordered form
```

После этого:

```text
P ≡MTS Q
iff
Canon(P) ≅ Canon(Q)
```

с сохранением выбранной связи, порядка полюсов и уже различённой границы.

Это исследовательская гипотеза, а не новая принятая аксиома.

### 26. Вывод А6 без кругового рассуждения

Требуемая последовательность остаётся:

```text
предъявления
-> укоренённость
-> индивидуализация
-> канонизация
-> ≡MTS
-> классы смысловых форм
-> операция Link на классах
-> свойство тождества по полюсам
```

Нужно доказать корректность:

```text
Link([A],[B]) = [A ⟼ B]
```

относительно выбора представителей.

Только после этого проверяется, является ли

```text
(A ⟼ B) = (C ⟼ D)
<=>
A = C ∧ B = D
```

теоремой полученной модели или требует отдельной аксиомы.

### 27. Смысл как полная каноническая рекурсивная форма

Рабочая гипотеза #581 уточняется:

```text
content(X) := Canon(RecPresentation(X))
```

Кандидат:

```text
semantic identity == complete canonical recursive content
```

В таком чтении для

```text
R = R ⟼ R
```

оба полюса являются той же полной канонической рекурсией. Это даёт строгий путь к исследованию формулировки «связь смыслов / смысл смысла» без введения внешнего атома `Meaning`.

Но этот вывод остаётся гипотезой до модельной проверки #584.

### 28. Корпус опровержений F1

Нужно классифицировать минимум:

```text
переименованный R
вторая физическая запись R
R / O / C / L / U
Loop(O)=O⟼O
Loop(R)=R⟼R
ordinary R⟼O
rooted symmetric mutual block
rooted asymmetric mutual block
ungrounded symmetric cycle
ungrounded rigid asymmetric cycle
larger SCC with grounded boundary

```

Для каждого фиксировать:

```text

```

### 29. Следующий результат F1

До перехода к #583 требуется:

1. строго определить укоренённый рекурсивный блок `B` относительно `Γ`;
2. доказать корректность фактора по орбитам;
3. доказать завершение и каноничность итеративного схлопывания;
4. классифицировать `R/O/C/L/U` и взаимные циклы;
5. найти точный контрпример жёсткой неукоренённой формы и закрепить его как отрицательный вектор;
6. определить начальный статус `R`;
7. решить роль конечного совместного использования подформ;
8. получить конечную процедуру сравнения;
9. передать результат в #583 для аудита единственности акорня и А6.

## Ограничения F1

- не использовать технические идентификаторы как тождество;
- не принимать обычную бисимуляцию;
- не требовать бесконечного раскрытия;
- не считать жёсткость графа достаточной для смысловой допустимости;
- не принимать произвольные неукоренённые циклы;
- не использовать А6 кругово;
- не менять исполняемое ядро и машинные контракты до отдельного решения.
