## 1. Историческая граница на момент F2/F3

На этом этапе машинная линия F1 была завершена и принята как `MTS v0.9`.

```text
then-current  = MTS v0.9
then-previous = MTS v0.8
```

Это не является доказательством F2 или F3. Исполняемое ядро используется только как свидетельство и корпус опровержений.

Закрытый вход F1:

```text
∞ [ ] 1 0 ( ) ⟼ : =

E_g = c_g ⟼ m_g

A_g = ExactSequence(
  c_g,
  E_:,
  ExactSequence(m_start,E_⟼,m_end)
)

T_F1 = T_F1 ⟼ ExactSequence(A_g...)
```

Рекурсивные уравнения смыслов знаков:

```text
m∞ = m∞ ⟼ m∞

m[ = m[ ⟼ m∞
m] = m∞ ⟼ m]
m1 = m[ ⟼ m]
m0 = m] ⟼ m[

m( = m( ⟼ m∞
m) = m∞ ⟼ m)
m⟼ = m( ⟼ m)

m: = m∞ ⟼ m⟼
m= = m= ⟼ m=
```

Знаки `≡`, `♂`, `♀`, `↑`, `{}`, `¬`, `↛` не входят в минимальный F1. Логические стрелки и связки исследовательского текста также не являются внутренним алфавитом.

## 2. Задача F2

F2 не создаёт ещё один язык и не выбирает внешнюю онтологию.

Нужно определить одновременно:

```text
связывание рекурсивных ссылок
конечное основание различия
смысл рекурсивной формы
одновременное удовлетворение уравнений
нейтральность к переименованию
границу равенства и различия
статус недоопределённых систем
```

Ключевое разделение:

```text
одновременность уравнений
!=
временной порядок создания связей

конечная зависимость доказательства различия
!=
порядок существования смыслов
```

Уравнения существуют как одна асеть. Направленным может быть доказательство того, что конкретное различие действительно имеет основание.

## 3. Почему обычного неподвижного решения недостаточно

Если разрешить произвольное экстенсиональное решение системы

```text
R = R ⟼ R
O = O ⟼ R
```

то подстановка

```text
O = R
```

тоже формально удовлетворяет обеим строкам.

Следовательно условие

```text
rho(x) = Link(rho(start(x)),rho(end(x)))
```

само по себе не выбирает требуемое различие `R/O`.

Максимальное поведенческое отождествление немаркированной рекурсии способно схлопнуть `R/O/C` целиком.

Поэтому F2 использует не наибольшее круговое равенство, а **наименьшее конечное отношение, порождённое рекурсивным связыванием и сворачиванием уже обоснованных форм**.

## 4. Связанная ссылка не является смысловым идентификатором

После разрешения F1 каждая рекурсивная строка метауровня имеет вид:

```text
x := a ⟼ b
```

`x`, `a`, `b` — связанные ссылки предъявления.

Имя `x` не является:

```text
semantic ID
runtime ID
storage ID
UUID
source occurrence
history position
```

Различается только роль ссылки:

```text
SELF_START
SELF_END
DEPENDENCY
```

Первая роль означает самоссылку в начале, вторая — самоссылку в конце, третья — ссылку на другую обоснованную форму.

Эта структура сохраняется при согласованном переименовании связанных обозначений.

Поэтому

```text
x = x ⟼ R
```

отличается от

```text
x = R ⟼ x
```

не буквой `x`, а положением самоссылки.

## 5. Четыре метаформы доказательства

Для строгого описания используются четыре сокращения:

```text
ROOT
START(F)
END(F)
PAIR(F,G)
```

Они **не являются новыми сущностями или знаками МТС**.

Это только имена четырёх возможных конечных форм доказательства:

```text
ROOT
  ~= μx.(x ⟼ x)

START(F)
  ~= μx.(x ⟼ F)

END(F)
  ~= μx.(F ⟼ x)

PAIR(F,G)
  ~= F ⟼ G
```

`μ` также является только метанотацией связанной самоссылки. Во внутренний алфавит F1 он не добавляется.

Стирание метаобозначений всегда возвращает обычные связи и рекурсивные ссылки F1.

## 6. Конечное укоренение

Запись

```text
Σ ⊢ x ⇓ F
```

означает:

> в одновременной системе `Σ` связанная ссылка `x` имеет конечное доказательство рекурсивной формы `F`.

### 6.1. Полное самозамыкание

Если:

```text
x = x ⟼ x
```

то допускается:

```text
Σ ⊢ x ⇓ ROOT
```

Здесь нет внешней зависимости, которую требовалось бы сначала различить.

### 6.2. Самозамыкание начала

Если:

```text
x = x ⟼ y
Σ ⊢ y ⇓ F
```

то:

```text
Σ ⊢ x ⇓ START(F)
```

Внешний полюс должен уже иметь конечное основание. Он не получает индивидуальность из ссылки на `x`.

### 6.3. Самозамыкание конца

Если:

```text
x = y ⟼ x
Σ ⊢ y ⇓ F
```

то:

```text
Σ ⊢ x ⇓ END(F)
```

### 6.4. Обычная связь

Если самоссылки `x` в полюсах нет и оба полюса имеют конечное основание:

```text
x = y ⟼ z
Σ ⊢ y ⇓ F
Σ ⊢ z ⇓ G
```

то:

```text
Σ ⊢ x ⇓ PAIR(F,G)
```

Эта строка не утверждает существование нового экземпляра связи. Она только получает прямую форму `F ⟼ G`.

Совпадение такой формы с уже рекурсивно сворачиваемой формой решается отношением следующего раздела. Общий вывод об отсутствии экземплярности остаётся задачей #583.

## 7. Конечная глубина не является историей создания

Глубину доказательства удобно обозначать метауровнем:

```text
d(ROOT) = 0

d(START(F)) = 1 + d(F)
d(END(F))   = 1 + d(F)

d(PAIR(F,G)) = 1 + max(d(F),d(G))
```

Число `d` не входит в МТС.

Оно лишь свидетельствует, что различие не основано на бесконечной цепочке вида:

```text
X отличается благодаря Y
Y отличается благодаря X
```

при отсутствии иного основания.

Все уравнения `Σ` остаются одновременными. Конечная зависимость доказательства не превращается в историю материализации.

## 8. Чистая взаимная рекурсия не создаёт индивидуальность

Система

```text
R = R ⟼ R
X = Y ⟼ R
Y = X ⟼ R
```

имеет очевидную внешнюю двухузловую запись, но ни для `X`, ни для `Y` нельзя построить конечное доказательство по правилам F2.

Поэтому она не получает две смысловые связи только из факта наличия двух связанных обозначений.

То же относится к ориентированно асимметричной записи:

```text
R = R ⟼ R
X = Y ⟼ R
Y = R ⟼ X
```

Внешняя структурная жёсткость такой записи не создаёт первичного различия.

Автоморфизмы и графовая жёсткость остаются возможными внешними проверками, но не источником смысла внутри МТС.

## 9. Наименьшее отношение сворачивания и разворачивания

Обозначим на метауровне:

```text
F ≈ G
```

Это не внутренний знак `=` МТС, а отношение доказуемого совпадения укоренённых форм.

Оно является **наименьшим отношением с конечными доказательствами**, содержащим:

```text
alpha-renaming binder-ов

ROOT ≈ ROOT ⟼ ROOT

START(F) ≈ START(F) ⟼ F

END(F) ≈ F ⟼ END(F)

F1 ≈ F2 and G1 ≈ G2
  =>
(F1 ⟼ G1) ≈ (F2 ⟼ G2)
```

Критическое слово — `наименьшее`.

Нельзя использовать круговое правило:

```text
предположим F ≈ G
и из этого же предположения выведем F ≈ G
```

Поэтому схлопнутое решение неподвижной точки не получает автоматически:

```text
ROOT ≈ START(ROOT)
```

Для такого вывода нет конечной порождающей цепочки.

При этом сворачивание уже известной рекурсивной формы допустимо:

```text
START(ROOT)
≈
START(ROOT) ⟼ ROOT
```

Это даёт интерфейс для #583: обычная запись тех же полюсов может оказаться развёрткой уже существующей рекурсивной формы, не создавая второй смысловой связи.

## 10. Одновременное удовлетворение

Пусть `rho(x)` — укоренённая форма, полученная конечным доказательством для связанной ссылки `x`.

Это не таблица объектов исполнения. `rho` — метазапись результата связывания.

Уравнение

```text
x = a ⟼ b
```

удовлетворено тогда, когда существует конечное доказательство:

```text
rho(x) ≈ rho(a) ⟼ rho(b)
```

Система `Σ` имеет укоренённое одновременное решение, если:

```text
1. каждая связанная ссылка имеет конечное доказательство укоренения;
2. каждое уравнение удовлетворено;
3. все доказательства одной ссылки согласованы по ≈;
4. результат не меняется при согласованном переименовании;
5. физическое имя или позиция не создают различие.
```

Все пять условий относятся к одной системе целиком.

## 11. Неопределённость и противоречие

F2 не объявляет любую конечную систему разрешимой.

Классификация:

```text
GROUNDED
  все ссылки имеют конечное согласованное решение

UNDERGROUNDED
  хотя бы одна ссылка не имеет конечного grounding-доказательства

AMBIGUOUS
  одна ссылка имеет два конечных grounding-вывода,
  которые не связаны ≈

INCONSISTENT
  grounding существует,
  но все уравнения одновременно не удовлетворяются
```

Названия состояний в блоке — только машинные метки исследовательского уровня.

Для минимального смыслового ядра F1 получается состояние `GROUNDED`.

Абсолютная непротиворечивость всей МТС здесь не утверждается. Независимые внешние модели и контрмодели принадлежат #584.

## 12. Решение минимальных смыслов F1

Правила дают конечную цепочку доказательств, но не временную историю создания.

### 12.1. Полный акорень

Две разные физические записи:

```text
m∞ = m∞ ⟼ m∞
m= = m= ⟼ m=
```

дают одну и ту же метаформу:

```text
rho(m∞) = ROOT
rho(m=) = ROOT
```

Имена связанных обозначений исчезают из результата укоренения.

F2 пока фиксирует нейтральный к переименованию результат связывания. Теоремную формулировку «существует ровно одна смысловая корневая связь» классифицирует #583.

### 12.2. Открывающие формы

```text
m[ = m[ ⟼ m∞
m( = m( ⟼ m∞
```

дают:

```text
rho(m[) = START(ROOT)
rho(m() = START(ROOT)
```

### 12.3. Закрывающие формы

```text
m] = m∞ ⟼ m]
m) = m∞ ⟼ m)
```

дают:

```text
rho(m]) = END(ROOT)
rho(m)) = END(ROOT)
```

### 12.4. Связность и несвязность

После укоренения открывающей и закрывающей форм:

```text
rho(m1) = PAIR(START(ROOT),END(ROOT))
rho(m⟼) = PAIR(START(ROOT),END(ROOT))

rho(m0) = PAIR(END(ROOT),START(ROOT))
```

### 12.5. Двоеточие

После укоренения смысла формальной связи:

```text
rho(m:) = PAIR(ROOT,rho(m⟼))
```

Таким образом ожидаемая корневая проекция получается без технических идентификаторов и без предположения готового равенства упорядоченных пар:

```text
m∞, m= -> R
m[, m( -> O
m], m) -> C
m1, m⟼ -> L
m0 -> U
m: -> R ⟼ L
```

`R/O/C/L/U` в последнем блоке — только привычные имена уже выведенных форм.

## 13. Почему `R`, `O`, `C` не схлопываются

Укоренённые формы различаются способом связанной рекурсии:

```text
ROOT
START(ROOT)
END(ROOT)
```

Чтобы получить

```text
ROOT ≈ START(ROOT)
```

или

```text
ROOT ≈ END(ROOT)
```

пришлось бы импортировать внешнее равенство, допустить круговое доказательство самого себя или использовать максимальное поведенческое отождествление.

Ни один такой шаг не входит в наименьшее отношение F2.

Различие `O/C` дополнительно сохраняет упорядоченную сторону самоссылки.

Это объясняет требуемый корневой базис без объекта-идентификатора и без внешней метки типа связи.

## 14. Обязательные проверочные случаи

### Переименование акорня

```text
x = x ⟼ x
y = y ⟼ y
```

Обе строки дают `ROOT`; имя не создаёт различие.

### Повтор одностороннего самозамыкания

```text
x = x ⟼ R
y = y ⟼ R
```

Обе строки дают `START(ROOT)`.

### Обычная развёртка рекурсивной формы

После:

```text
O = O ⟼ R
```

форма

```text
O ⟼ R
```

связана с `O` одним конечным доказательством сворачивания и разворачивания.

F2 не называет это общей теоремой отсутствия экземплярности; точное смысловое следствие выводит #583.

### Петля над акорнем

```text
Loop(R) = R ⟼ R
```

лежит в том же классе сворачивания и разворачивания, что `ROOT`.

### Петля над различённой формой

```text
Loop(O) = O ⟼ O
```

не является развёрткой:

```text
O = O ⟼ R
```

и потому не получает совпадение с `O` только из слова «петля».

### Симметричный взаимный цикл

```text
X = Y ⟼ R
Y = X ⟼ R
```

не имеет конечного укоренения.

### Асимметричный взаимный цикл

```text
X = Y ⟼ R
Y = R ⟼ X
```

также не имеет конечного укоренения. Внешняя структурная жёсткость не заменяет основание различия.

### Недостижимый технический мусор

Добавление физической записи, не участвующей в укоренении нужной связанной ссылки, не меняет её форму.

### Повтор значения в последовательности

Три позиции с одним `L` используют одну укоренённую форму `L`. Позиционная множественность принадлежит структурам последовательности и истории, а не смысловому тождеству.

## 15. Роль внутреннего `=`

Метаотношение `≈` не является знаком `=` из F1.

В F1 знак `=` уже имеет специализированное контекстное чтение через локальные представители.

F2 делает более низкоуровневую работу:

```text
binder
-> grounded recursive form
-> finite fold/unfold comparison
```

После этого правило знака `=` сравнивает уже разрешённые локальные представители в конкретном контексте.

Нельзя использовать внутренний `=` как скрытый инструмент для построения самого `rho`.

## 16. Статус закона тождества по полюсам

Принятый машинный инвариант:

```text
(A ⟼ B) = (C ⟼ D)
iff
A = C and B = D
```

не является исходным правилом укоренения F2.

На этом шаге установлено только:

```text
если grounded subforms имеют finite ≈ proof,
то congruence даёт finite ≈ proof для их связей.
```

Обратное направление и общий вывод об отсутствии экземплярности не закладываются аксиомой.

Их точная классификация:

```text
unique full selfclosure
one-sided uniqueness
same-pole ordinary Link identity
```

передаётся #583.

Так устраняется круг:

```text
pair identity
-> recursive identity
-> pair identity
```

## 17. Смысл без внешней функции значения

Для связанной ссылки `x` F2 не добавляет отдельный объект значения.

Рабочее чтение:

```text
semantic content of x
=
its grounded recursive form up to finite ≈ proof
```

Это метаописание, а не новая внутренняя функция.

Для акорня:

```text
ROOT ≈ ROOT ⟼ ROOT
```

оба полюса возвращают ту же полную рекурсивную определённость.

Поэтому выражение «связь смыслов / смысл смысла» получает внутреннее основание в рекурсивной форме, а не во внешнем атоме значения.

## 18. Нотационные контексты не исчезают

Укоренение применяется после разрешения контекста F1.

Нужно сохранять различие:

```text
FORMAL `⟼`
QUATERNARY `1`
ROOT `L`
```

Их смыслы могут разрешаться в одну укоренённую форму связности, но словарные входы и роли употребления различны структурно.

То же относится к:

```text
∞ и =
[ и (
] и )
```

Совпадение `rho(m_g)` не уничтожает носитель, словарный вход, контекст или структуру истории.

## 19. Отношение к исполнению

Исполняемая MTS v0.9 содержит совместимое наблюдаемое поведение:

```text
ensureRoot
startSelfClosed
endSelfClosed
ensure ordinary Link
read/replay != materialize
```

Но методы TypeScript не являются правилами F2.

Направление зависимости обратное:

```text
F2 rule
-> machine behavior can be checked against it
```

а не:

```text
Memory.ensure exists
-> therefore F2 is true
```

## 20. Детерминированность минимального F1

## 25. F3: нормализация конечных укоренённых форм

F3 не добавляет новый тип смыслового объекта. Он использует уже установленное F2 чтение:

```text
semantic content of x
=
its grounded recursive form up to finite ≈ proof
```

Чтобы не подменять это чтение скрытым тождеством объектов, введём только метаоперацию нормализации `N`. Она не входит в язык МТС и не является канонизатором исполнения.

Для конечных форм:

```text
N(ROOT) = ROOT

N(START(F)) = START(N(F))
N(END(F))   = END(N(F))
```

Для обычной пары сначала нормализуются оба полюса:

```text
f = N(F)
g = N(G)
```

затем применяется ровно одно из конечных сворачиваний F2:

```text
N(PAIR(F,G)) = ROOT,
  если f есть ROOT и g есть ROOT

N(PAIR(F,G)) = f,
  если f имеет вид START(g)

N(PAIR(F,G)) = g,
  если g имеет вид END(f)

N(PAIR(F,G)) = PAIR(f,g)
  во всех остальных случаях
```

Это не новые правила тождества. Это ориентация уже имеющихся правил сворачивания и разворачивания F2 в сторону более короткой конечной метаформы.

### 25.1. Детерминированность

После рекурсивной нормализации полюсов верхний шаг всегда конечен.

Два односторонних сворачивания не могут одновременно конкурировать на конечной форме. Для этого потребовалось бы одновременно:

```text
f = START(g)
g = END(f)
```

что дало бы строгий рост конечного размера в обе стороны. Конечная форма не может быть строго больше самой себя через такую пару вложений.

`ROOT` также синтаксически отличен на метауровне от `START(...)` и `END(...)`.

Поэтому `N(F)` определена однозначно для каждой конечно укоренённой формы.

### 25.2. Завершимость

Рекурсивные вызовы применяются только к собственным конечным подформам.

Верхнее сворачивание, когда оно происходит, удаляет один слой `PAIR`. Поэтому нормализация не может породить бесконечную цепочку.

Это доказательство завершимости относится к конечным формам укоренения F2 и не является утверждением о произвольных бесконечных графах.

## 26. Теорема нормальной формы

Для конечно укоренённых форм выполняется:

```text
F ≈ G
тогда и только тогда, когда
N(F) и N(G) буквально совпадают как alpha-neutral метаформы.
```

Здесь «буквально совпадают» относится к конечной форме доказательства после стирания имён связанных ссылок. Это не тождество исходных токенов и не тождество физических объектов.

Под `≈` здесь используется ровно отношение доказуемого совпадения F2: конечная цепочка порождающих шагов сворачивания или разворачивания и конгруэнтности.

### 26.1. Сохранение нормальной формы каждым порождающим шагом

Для полного самозамыкания:

```text
N(ROOT) = ROOT
N(PAIR(ROOT,ROOT)) = ROOT
```

Для начала:

```text
N(START(F))
=
START(N(F))
=
N(PAIR(START(F),F))
```

Для конца аналогично:

```text
N(END(F))
=
END(N(F))
=
N(PAIR(F,END(F)))
```

Конгруэнтность сохраняет результат, потому что нормализация пары зависит только от уже нормализованных полюсов.

Следовательно каждый конечный порождающий шаг сохраняет `N`:

```text
F ≈ G
=>
N(F) совпадает с N(G).
```

### 26.2. Каждая форма совпадает со своей нормальной формой

Структурная индукция по конечной форме даёт:

```text
F ≈ N(F)
```

Для `ROOT`, `START` и `END` это следует из индукционного предположения для вложенной формы и конгруэнтности.

Для `PAIR` после нормализации полюсов либо остаётся нормальная пара, либо применяется ровно одно разрешённое сворачивание F2.

Поэтому при совпадении `N(F)` и `N(G)` существует конечная цепочка:

```text
F ≈ N(F) ≈ N(G) ≈ G
```

Тем самым нормальная форма полностью характеризует наименьшее конечное отношение `≈`.

## 27. Теорема разложения обычной связи по полюсам

Теперь можно получить обратную часть, которую F2 намеренно не предполагал.

Для конечно укоренённых форм:

```text
PAIR(A,B) ≈ PAIR(C,D)
```

выполняется тогда и только тогда, когда одновременно:

```text
A ≈ C
B ≈ D
```

Обратное направление уже следует из конгруэнтности F2. Новым является прямое направление.

Пусть:

```text
a = N(A)
b = N(B)
c = N(C)
d = N(D)
```

Из теоремы нормальной формы следует совпадение результатов нормализации двух пар. Возможны только четыре верхних случая.

### 27.1. Нормальная форма `ROOT`

Пара сворачивается в `ROOT` только при:

```text
a = ROOT
b = ROOT
```

То же обязано выполняться для `c,d`, поэтому соответствующие полюса совпадают по `≈`.

### 27.2. Нормальная форма `START(H)`

Пара сворачивается в `START(H)` только в нормализованной конфигурации:

```text
START(H) ⟼ H
```

Поэтому обе сравниваемые пары имеют одинаковые нормальные начало и конец.

### 27.3. Нормальная форма `END(H)`

Аналогично единственная верхняя конфигурация:

```text
H ⟼ END(H)
```

задаёт оба нормальных полюса.

### 27.4. Несворачиваемая `PAIR(a,b)`

Если верхнее сворачивание невозможно, совпадение нормальных пар требует совпадения их первого и второго компонентов соответственно.

Таким образом F3 получает тождество по упорядоченным полюсам без предположения готового тождества пар:

```text
(A ⟼ B) и (C ⟼ D) имеют одно укоренённое смысловое содержание
тогда и только тогда, когда
A и C имеют одно укоренённое смысловое содержание
и
B и D имеют одно укоренённое смысловое содержание.
```

Это именно результат, который нельзя было использовать как предпосылку F2.

## 28. Теорема отсутствия экземплярности

F2 уже исключил отдельный объект значения и задал смысл связанной ссылки её укоренённой рекурсивной формой с точностью до конечного `≈`.

F3 теперь показал, что у каждого такого класса есть одна конечная нормальная форма доказательства.

Отсюда следует:

> Если две связанные записи не несут рекурсивно выраженного различия и их укоренённые формы совпадают по `≈`, то внутри укоренённой семантики МТС они не задают две смысловые связи.

Иначе потребовалась бы дополнительная координата вида:

```text
instance id
object identity
storage row
source occurrence
hidden tag
```

но ни одна такая координата не входит в смысловое содержание F2.

Это не дополнительная аксиома «запретить экземпляры». Это следствие исчерпывающего F2-описания смыслового содержания и теоремы нормальной формы.

Квалификация существенна: внешняя модель может прикрепить к одной форме несколько технических дескрипторов. Тогда она представляет несколько физических предъявлений одной смысловой связи, а не расширяет внутреннюю семантику МТС новым невыраженным различием.

## 29. Индуктивная формулировка индивидуальности

Тот же результат можно прочитать как индукцию по конечной глубине укоренения.

### 29.1. База `ROOT`

`ROOT` не содержит внешнего полюса, а имя связанной ссылки исчезает при укоренении.

Поэтому две полные самоссылки:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

имеют одну нормальную форму `ROOT`.

Никакого дополнительного различия внутри рекурсивной формы нет.

### 29.2. `START(F)` и `END(F)`

Если внешний `F` уже индивидуирован по индукционному предположению, то форма:

```text
START(F)
```

не содержит ещё одной координаты, способной различить две связанные ссылки с тем же внешним полюсом.

То же относится к `END(F)`.

### 29.3. `PAIR(F,G)`

Если оба упорядоченных полюса уже индивидуированы, теорема разложения показывает, что обычная связь определяется именно этой упорядоченной парой укоренённых смыслов.

Отдельная метка экземпляра не появляется ни на одном шаге индукции.

Именно здесь конечная зависимость доказательства различия используется как структура индукции, но не превращается во временной порядок создания связей.

## 30. Следствия F3

### 30.1. Единственность полного акорня

Для любых конечно укоренённых:

```text
X = X ⟼ X
Y = Y ⟼ Y
```

получается:

```text
rho(X) ≈ ROOT
rho(Y) ≈ ROOT
```

следовательно существует одна смысловая полностью самозамкнутая связь.

В корневой нотации:

```text
X и Y обозначают R = ∞
```

Это смысловая единственность. Она не запрещает несколько физических строк или технических дескрипторов, если внешний слой по какой-либо причине их допускает.

### 30.2. Единственность одностороннего самозамыкания

Для фиксированной укоренённой формы `F`:

```text
x = x ⟼ F
y = y ⟼ F
```

обе записи имеют `START(N(F))` как одну нормальную форму.

Аналогично:

```text
x = F ⟼ x
y = F ⟼ y
```

дают одну `END(N(F))`.

Следовательно имя связанной ссылки не создаёт семейство экземпляров одностороннего самозамыкания.

### 30.3. Обычная связь с теми же полюсами

Если:

```text
A ≈ C
B ≈ D
```

то связи:

```text
A ⟼ B
C ⟼ D
```

имеют одно смысловое содержание.

И наоборот, если укоренённые обычные связи совпадают, теорема разложения требует совпадения соответствующих полюсов по `≈`.

### 30.4. Нейтральность псевдонимов

Разные имена связанных ссылок, локальные псевдонимы и согласованное переименование не входят в `N`.

Следовательно переименование не может создать или уничтожить смысловую связь.

## 31. Граница петли и самозамыкания

F3 подтверждает важное различие на конкретных нормальных формах.

Для акорня:

```text
N(PAIR(ROOT,ROOT)) = ROOT
```

поэтому:

```text
Loop(R) = R ⟼ R
```

есть развёртка самого полного самозамыкания.

Для открывающей формы:

```text
N(O) = START(ROOT)
```

но:

```text
N(PAIR(O,O))
=
PAIR(START(ROOT),START(ROOT))
```

и верхнее сворачивание здесь невозможно.

Поэтому:

```text
Loop(O) = O ⟼ O
```

не совпадает с:

```text
O = O ⟼ R
```

Слово «петля» не является правилом тождества; решает точная рекурсивная форма.

## 32. Употребление, история и хранилище не являются смысловыми экземплярами

Теорема отсутствия экземплярности не запрещает множественность вообще. Она только локализует её на правильном уровне.

Три употребления одного `L`:

```text
L L L
```

имеют одну смысловую форму `L`.

Три позиции возникают из явно представленной структуры:

```text
ExactSequence
occurrence
history
provenance
```

а не из трёх смысловых копий `L`.

Аналогично две физические строки или два технических дескриптора могут представлять одно смысловое содержание. Их техническое различие не входит в `rho`, `≈` или `N`.

Следовательно:

```text
semantic multiplicity
!=
occurrence multiplicity
!=
storage multiplicity
```

F3 устраняет первую множественность при одинаковой укоренённой форме; две последние остаются допустимыми только как явно представленные структуры соответствующего уровня.

## 33. Контекстные предъявления не схлопываются как записи

F1 уже различает:

```text
FORMAL `⟼`
QUATERNARY `1`
ROOT `L`
```

Их значения могут иметь одну нормальную укоренённую форму связности.

Теорема отсутствия экземплярности означает только, что это не три смысловых экземпляра `L`.

Она не уничтожает явно представленные различия:

```text
Entry
use-role
context
carrier
source occurrence
history
```

если эти различия заданы связевой структурой F1 или производной теорией.

Таким образом одна смысловая связь может иметь несколько структурно различённых предъявлений и ролей без скрытого тождества объектов.

## 35. Область действия и запреты F3

Теоремы F3 относятся к **конечно укоренённым** системам F2.

Для состояния `UNDERGROUNDED` отсутствие укоренения не означает доказанное несуществование. В частности сохраняется принцип:

```text
не найдено
!=
не существует
```

И сохраняется граница:

```text
find / verify / replay
!=
materialize / write
```

F3 также не утверждает, что произвольный граф с физическими идентификаторами автоматически является асетью МТС.

Внешний граф может иметь сколько угодно узлов и быть даже жёстким по автоморфизмам. Пока различие не получило конечное основание в рекурсивной форме связи, тождество графового узла не становится смысловой индивидуальностью.

## 36. Проверка минимального F1 после F3

Из решения F2 и теоремы отсутствия экземплярности F3 теперь следует:

```text
m∞ и m=   -> одна semantic Link R
m[ и m(   -> одна semantic Link O
m] и m)   -> одна semantic Link C
m1 и m⟼   -> одна semantic Link L
m0        -> U
m:        -> R ⟼ L
```

При этом соответствующие словарные записи и контекстные роли остаются различёнными там, где F1 их явно представляет.

Это объясняет корневую проекцию без технических идентификаторов и без заранее принятого закона тождества по упорядоченным полюсам.


Это утверждение относится к внутренней укоренённой семантике МТС, а не к количеству её физических предъявлений.

## 38. Передача результата дальше

После F3 следующая зависимость имеет вид:

```text
#583 complete
  ↓
#585 internal root inversion / symmetry
#584 independent external models and countermodels
  ↓
#586 occurrence/counting/history consequences
```

#584 может теперь проверять теорему отсутствия экземплярности во внешних моделях, но не переопределять её.

#585 может использовать доказанные единственность `R/O/C` и тождество по упорядоченным полюсам, не импортируя канонизацию исполнения.

#586 получает точную границу:

```text
semantic Link identity
!=
occurrence multiplicity
```

и поэтому должен строить счёт и историю через явную структуру употреблений, а не через размножение смысловых связей.

## 39. F4-B: внутренняя остенсивная реверсия

F4-B исследует не физическую симметрию и не внешнее преобразование графа, а реверсию самой рекурсивной формы уравнения.

Метаобозначение `J` используется только в доказательстве и не добавляется в алфавит МТС.

Для конечно укоренённых форм определим:

```text
J(ROOT) = ROOT

J(START(F)) = END(J(F))
J(END(F))   = START(J(F))

J(PAIR(F,G)) = PAIR(J(G),J(F))
```

Последняя строка принципиальна: при реверсии обычной связи меняется внешний порядок полюсов и одновременно рекурсивно реверсируются их смыслы.

Это антигомоморфное продолжение, а не простая перестановка полюсов уже готовой связи.

## 40. Почему гомоморфное продолжение не работает

Можно было бы попробовать менять только ориентацию самоссылки, а обычную пару продолжать покомпонентно:

```text
H(ROOT) = ROOT
H(START(F)) = END(H(F))
H(END(F))   = START(H(F))
H(PAIR(F,G)) = PAIR(H(F),H(G))
```

Но эта попытка не согласована с уже доказанным отношением F2.

Порождающее сворачивание начала имеет вид:

```text
START(F) ≈ PAIR(START(F),F)
```

После такого покомпонентного преобразования получилось бы требование:

```text
END(H(F))
≈
PAIR(END(H(F)),H(F))
```

А действительное сворачивание конца F2 имеет противоположный порядок:

```text
END(H(F))
≈
PAIR(H(F),END(H(F)))
```

По теореме F3 о тождестве по упорядоченным полюсам эти две пары в общем случае не совпадают.

Уже при корневом аргументе нормальные формы различны:

```text
PAIR(END(ROOT),ROOT)
!= normal-form class of
PAIR(ROOT,END(ROOT))
```

Следовательно покомпонентное продолжение не задаёт операцию на смысловых классах F2.

Отрицательный результат важен: обмен `O/C` сам по себе ещё не определяет корректную инверсию всей рекурсивной семантики.

## 41. Согласованность антигомоморфной реверсии с F2

Для полного самозамыкания порождающее правило сохраняется:

```text
ROOT ≈ PAIR(ROOT,ROOT)

J(ROOT) = ROOT
J(PAIR(ROOT,ROOT)) = PAIR(ROOT,ROOT)
```

Сворачивание начала переходит ровно в сворачивание конца:

```text
START(F) ≈ PAIR(START(F),F)

↓ J

END(J(F)) ≈ PAIR(J(F),END(J(F)))
```

Сворачивание конца переходит ровно в сворачивание начала:

```text
END(F) ≈ PAIR(F,END(F))

↓ J

START(J(F)) ≈ PAIR(START(J(F)),J(F))
```

Конгруэнтность также сохраняется: эквивалентные полюса после реверсии остаются эквивалентными, а их порядок меняется одинаково с обеих сторон.

По индукции по конечному доказательству F2 получаем:

```text
F ≈ G
=>
J(F) ≈ J(G)
```

Поэтому `J` корректно определена на смысловом содержании, а не зависит от выбранной развёртки одной и той же рекурсивной формы.

## 42. Инволютивность

Повторная реверсия возвращает исходную конечную метаформу.

Для полного самозамыкания это непосредственно:

```text
J(J(ROOT)) = ROOT
```

Для односторонних форм:

```text
J(J(START(F)))
= J(END(J(F)))
= START(J(J(F)))

J(J(END(F)))
= J(START(J(F)))
= END(J(J(F)))
```

Для обычной пары:

```text
J(J(PAIR(F,G)))
= J(PAIR(J(G),J(F)))
= PAIR(J(J(F)),J(J(G)))
```

Структурная индукция даёт:

```text
J(J(F)) = F
```

Здесь равенство относится к конечной нейтральной к переименованию метаформе. Следовательно на классах `≈` реверсия также является инволюцией.

Никакой внешний идентификатор для этого доказательства не используется.

## 43. Совместимость с нормальными формами F3

Реверсия переводит нормальную форму в нормальную форму.

Если несворачиваемая пара после реверсии стала бы сворачиваемой, обратная реверсия дала бы одно из запрещённых сворачиваний уже в исходной паре.

Поэтому:

```text
N(J(F)) = J(N(F))
```

с точностью до буквального совпадения конечных нейтральных к переименованию метаформ.

Это даёт второй способ увидеть, что операция не зависит от физического предъявления или выбранной развёртки.

## 44. Действие на корневой базис

После F3 корневые формы имеют вид:

```text
R = ROOT
O = START(ROOT)
C = END(ROOT)
L = PAIR(O,C)
U = PAIR(C,O)
```

Реверсия акорня:

```text
J(R)
= J(ROOT)
= ROOT
= R
```

Поэтому:

```text
J(R) = R
```

Открывающая и закрывающая формы меняются местами:

```text
J(O)
= J(START(ROOT))
= END(ROOT)
= C

J(C)
= J(END(ROOT))
= START(ROOT)
= O
```

Следовательно:

```text
J(O) = C
J(C) = O
```

Для связности внешний порядок тоже реверсируется:

```text
J(L)
= J(PAIR(O,C))
= PAIR(J(C),J(O))
= PAIR(O,C)
= L
```

Для несвязности аналогично:

```text
J(U)
= J(PAIR(C,O))
= PAIR(J(O),J(C))
= PAIR(C,O)
= U
```

Итог:

```text
J(R) = R
J(O) = C
J(C) = O
J(L) = L
J(U) = U
```

Таким образом внутренняя рекурсивная реверсия **не** обменивает `L` и `U`.

## 45. Простая перестановка полюсов — другая операция

Для явно предъявленной обычной связи можно отдельно рассматривать перестановку её упорядоченных полюсов:

```text
P(PAIR(F,G)) = PAIR(G,F)
```

Это метаоперация над явной обычной парой.

Для корневых обычных связей она даёт:

```text
P(L) = U
P(U) = L
```

Но `P` нельзя молча отождествлять с `J`.

Рекурсивная форма `O` имеет допустимую развёртку:

```text
O ≈ PAIR(O,R)
```

Простая перестановка этой развёртки дала бы:

```text
PAIR(R,O)
```

а остенсивная реверсия даёт:

```text
J(O) = C
```

Причём:

```text
C ≈ PAIR(R,C)
```

По F3 пары `PAIR(R,O)` и `PAIR(R,C)` различны, поскольку `O` и `C` имеют разные нормальные формы.

Следовательно перестановка полюсов выбранной развёртки не является корректным определением рекурсивной реверсии смыслового класса.

Точная классификация:

```text
J = recursive equation reversal
P = pole swap of an explicit ordinary pair
```

Операция навигационного обращения пути, логическое отрицание и роль несвязности `U` остаются отдельными понятиями.

## 46. Почему формула `L ↔ U` всё же возникает

Если после внутренней реверсии обычной пары дополнительно переставить её полюса, то на обычных парах получается покомпонентное преобразование:

```text
P(J(PAIR(F,G)))
=
PAIR(J(F),J(G))
```

Для `L` это действительно даёт:

```text
L = PAIR(O,C)

P(J(L))
= P(L)
= U
```

Но это композиция двух различных действий.

Она не доказывает:

```text
J(L) = U
```

и не даёт права расширять покомпонентную формулу на самозамкнутые смысловые классы, где раздел 40 уже показал нарушение правил F2.

Тем самым старое интуитивное сопоставление `L/U` сохраняется как симметрия упорядоченных полюсов, но не как остенсивная рекурсивная инверсия.

## 47. Граница примитивности корневых уравнений

Результат F4-B является теоремой о преобразовании конечно укоренённых форм.

Из существования `O` можно построить метаформу:

```text
J(O) = C
```

Но это само по себе не утверждает, что исходная одновременная система обязана содержать связанную ссылку, предъявляющую `C`.

Нужно различать:

```text
semantic form transformation
!=
existence of a binding clause in the same axiom-aset
```

В текущем F1 форма `C` существует потому, что её собственная рекурсивная строка уже входит в закрытый axiom-aset.

F4-B доказывает отношение симметрии между уже укоренёнными `O` и `C`, но не удаляет ни одну строку F1.

Аналогично формы `L` и `U` композиционно определяются упорядоченными полюсами, однако словарные входы и значения знаков F1 требуют своих явно заданных структур предъявления.

Поэтому текущая классификация такова:

```text
R/O/C/L/U symmetry relations
  THEOREM of grounded forms

existence of the corresponding F1 sign-meaning clauses
  remains part of the closed F1 axiom-aset

removal of any accepted F1 clause
  NOT JUSTIFIED by F4-B
```

Возможная будущая минимизация аксиом потребует отдельного семантического релиза и явного принципа замкнутости относительно реверсии. В #585 такой принцип не добавляется.

## 48. Действие на значения знаков F1

Реверсия действует на смысловое содержание, а не на сам знак или словарный вход.

Для уже разрешённых смыслов получается:

```text
J(rho(m∞)) = R
J(rho(m=)) = R

J(rho(m[)) = C
J(rho(m()) = C

J(rho(m])) = O
J(rho(m))) = O

J(rho(m1)) = L
J(rho(m⟼)) = L
J(rho(m0)) = U
```

Это не таблица замены символов. Например разные контексты `[` и `(` сохраняют свои структурные роли, хотя их смысловые формы обе переходят в класс `C`.

Особенно показательно двоеточие:

```text
rho(m:) = PAIR(R,L)

J(rho(m:))
= PAIR(J(L),J(R))
= PAIR(L,R)
```

Нормальная форма `PAIR(L,R)` не совпадает ни с одним из десяти уже перечисленных смыслов F1.

Следовательно замкнутость корневого базиса под `J` не означает замкнутость всего множества значений знаков F1.

Это ещё одна причина не вводить `Inv` как внутренний знак или готовую таблицу символов.

## 49. Следствия для несвязности, навигации и истории

Поскольку:

```text
J(U) = U
```

несвязность не является синонимом инверсии, отрицания или обращения.

Поскольку:

```text
P(L) = U
```

отношение `L/U` выражает отдельную симметрию упорядоченных полюсов.

Для #450 это означает, что обращение пути нельзя определять ссылкой на `J` без отдельной семантики последовательности и порядка употреблений.

Для #586 это означает, что счёт и история не должны получать знак или направление из смешения `U` с инверсией. Позиционная множественность остаётся отдельной структурой.

Логическое отрицание также не выводится из F4-B.

## 51. Критерий завершения F4-B

Для #585 выполнено:

```text
internal recursive reversal defined without external model
compatibility with finite F2 fold/unfold proved
homomorphic false route rejected
J(R)=R proved
J(O)=C and J(C)=O proved
exact L/U action proved: both fixed by J
pole swap L<->U separated from J
involution proved on all finitely grounded forms
primitive-vs-derived boundary classified
sign-level closure explicitly rejected
path converse / negation / U kept distinct
runtime and contracts unchanged
```

Центральный вывод можно записать так:

```text
recursive reversal
=
reverse the outer Link
+
recursively reverse both pole meanings
```

И именно поэтому:

```text
O <-> C
but
L -> L
U -> U
```

а обмен:

```text
L <-> U
```

принадлежит простой перестановке полюсов, а не той же рекурсивной операции.

## 52. Передача результата после F4-B

Следующий независимый внешний контроль остаётся в #584.

Он может проверить, существуют ли удобные математические модели, в которых антиинволюция `J` реализуется без потери различий F2/F3.

Но такая модель не определяет `J`: внутренняя операция уже выведена из правил рекурсивной формы.

#586 получает от F4-B точные ограничения:

```text
semantic inversion != occurrence reversal
J(U) = U
P(L) = U
```

и должен строить счёт, позицию и историю без смешения этих трёх уровней.
