# Открытые вопросы новой аксиоматики МТС

Статус: рабочий исследовательский регистр. Текущий владелец фундаментального шага — #582, общий порядок — #588.

## 1. Текущая граница

Машинная линия F1 завершена и принята как MTS v0.9.

Текущий принятый срез:

```text
current  = MTS v0.9
previous = MTS v0.8
```

Это не является доказательством F2/F3. Исполняемое ядро используется только как свидетельство и корпус опровержений.

Закрытый вход F1:

```text
∞ [ ] 1 0 ( ) ⟼ : =

E_g = c_g ⟼ m_g

A_g = ExactSequence(
  c_g,
  E_:,
  ExactSequence(m_start,E_⟼,m_end)
)

T_F1 = T_F1 ⟼ ExactSequence(A_g...)
```

Рекурсивные уравнения смыслов знаков:

```text
m∞ = m∞ ⟼ m∞

m[ = m[ ⟼ m∞
m] = m∞ ⟼ m]
m1 = m[ ⟼ m]
m0 = m] ⟼ m[

m( = m( ⟼ m∞
m) = m∞ ⟼ m)
m⟼ = m( ⟼ m)

m: = m∞ ⟼ m⟼
m= = m= ⟼ m=
```

Знаки `≡`, `♂`, `♀`, `↑`, `{}`, `¬`, `↛` не входят в минимальный F1. Логические стрелки и связки исследовательского текста также не являются внутренним алфавитом.

## 2. Что F2 должен определить

F2 не создаёт ещё один язык и не выбирает внешнюю онтологию.

Нужно определить одновременно:

```text
связывание рекурсивных ссылок
конечное основание различия
смысл рекурсивной формы
одновременное удовлетворение уравнений
нейтральность к переименованию
границу равенства и различия
статус недоопределённых систем
```

Ключевое разделение:

```text
одновременность уравнений
!=
временной порядок создания связей

конечная зависимость доказательства различия
!=
порядок существования смыслов
```

Уравнения существуют как одна асеть. Направленным может быть доказательство того, что конкретное различие действительно имеет основание.

## 3. Почему обычный неподвижный пункт недостаточен

Если разрешить произвольное экстенсиональное решение системы

```text
R = R ⟼ R
O = O ⟼ R
```

то решение с

```text
O = R
```

формально тоже удовлетворяет обеим строкам после подстановки.

Следовательно простое условие

```text
rho(x) = Link(rho(start(x)),rho(end(x)))
```

не выбирает требуемое различие `R/O`.

Ещё хуже, максимальное поведенческое отождествление немаркированной рекурсии способно схлопнуть `R/O/C` целиком.

Поэтому F2 использует не наибольшее круговое равенство, а **наименьшее конечное отношение, порождённое рекурсивным связыванием и сворачиванием уже обоснованных форм**.

## 4. Связанная ссылка не является смысловым идентификатором

После разрешения F1 каждая рекурсивная строка метауровня имеет вид:

```text
x := a ⟼ b
```

`x`, `a`, `b` здесь — связанные ссылки предъявления.

Имя `x` не является:

```text
semantic ID
runtime ID
storage ID
UUID
source occurrence
history position
```

Различается только роль в связывании:

```text
SELF_START   — ссылка на тот же binder в начале
SELF_END     — ссылка на тот же binder в конце
DEPENDENCY   — ссылка на другую уже обоснованную форму
```

Эта роль сохраняется при согласованном переименовании binder-ов.

В частности:

```text
x = x ⟼ R
```

отличается от

```text
x = R ⟼ x
```

не буквой `x`, а положением самоссылки.

## 5. Метаформы доказательства

Для строгого описания grounding используются четыре метасокращения:

```text
ROOT
START(F)
END(F)
PAIR(F,G)
```

Они **не являются новыми сущностями или знаками МТС**.

Это только имена четырёх возможных конечных форм доказательства:

```text
ROOT
  ~= μx.(x ⟼ x)

START(F)
  ~= μx.(x ⟼ F)

END(F)
  ~= μx.(F ⟼ x)

PAIR(F,G)
  ~= F ⟼ G
```

`μ` также является только метанотацией связанной самоссылки. Во внутренний алфавит F1 он не добавляется.

Стирание метаобозначений всегда возвращает обычные связи и рекурсивные ссылки F1.

## 6. Конечное grounding-отношение

Запись

```text
Σ ⊢ x ⇓ F
```

означает:

> в одновременной системе `Σ` связанная ссылка `x` имеет конечное доказательство рекурсивной формы `F`.

### 6.1. Полное самозамыкание

Если уравнение `x` содержит ту же связанную ссылку в обоих полюсах:

```text
x = x ⟼ x
```

то допускается:

```text
Σ ⊢ x ⇓ ROOT
```

Здесь нет внешней зависимости, которую надо было бы сначала различить.

### 6.2. Самозамыкание начала

Если:

```text
x = x ⟼ y
Σ ⊢ y ⇓ F
```

то:

```text
Σ ⊢ x ⇓ START(F)
```

Внешний полюс должен уже иметь конечное основание. Он не получает индивидуальность из ссылки на `x`.

### 6.3. Самозамыкание конца

Если:

```text
x = y ⟼ x
Σ ⊢ y ⇓ F
```

то:

```text
Σ ⊢ x ⇓ END(F)
```

### 6.4. Обычная связь

Если самоссылки `x` в полюсах нет и оба полюса имеют конечное основание:

```text
x = y ⟼ z
Σ ⊢ y ⇓ F
Σ ⊢ z ⇓ G
```

то:

```text
Σ ⊢ x ⇓ PAIR(F,G)
```

Эта строка не утверждает существование «нового экземпляра» связи. Она только получает прямую форму `F ⟼ G`. Вопрос, совпадает ли она с уже рекурсивно сворачиваемой формой, решается отношением из следующего раздела и затем исследуется как общий no-instance результат в #583.

## 7. Grounding не является последовательным созданием

Глубина доказательства может быть записана метауровнем:

```text
d(ROOT) = 0

d(START(F)) = 1 + d(F)
d(END(F))   = 1 + d(F)

d(PAIR(F,G)) = 1 + max(d(F),d(G))
```

Число `d` не входит в МТС.

Оно лишь свидетельствует, что различие не основано на бесконечной цепочке вида:

```text
X отличается благодаря Y
Y отличается благодаря X
```

при отсутствии другого основания.

Все уравнения `Σ` остаются одновременными. Доказательство может иметь конечную зависимость, не превращая её в историю материализации.

## 8. Чистая взаимная рекурсия не создаёт индивидуальность

Система:

```text
R = R ⟼ R
X = Y ⟼ R
Y = X ⟼ R
```

имеет очевидную внешнюю двухузловую запись, но ни для `X`, ни для `Y` нельзя построить конечное доказательство по правилам F2.

Поэтому она не получает две смысловые связи только из факта наличия двух binder-ов.

То же относится к ориентированно асимметричной записи:

```text
R = R ⟼ R
X = Y ⟼ R
Y = R ⟼ X
```

Ранее исследовавшаяся гипотеза об автоморфизмах могла различить эти места как внешний конечный рисунок. F2 отвергает такой критерий как источник смысла: **жёсткость неукоренённой рекурсивной записи не создаёт первичного различия**.

Возможная внешняя модель такой системы исследуется отдельно, но она не является grounded solution МТС.

## 9. Наименьшее fold/unfold-отношение

Обозначим на метауровне:

```text
F ≈ G
```

не внутреннее `=` МТС, а отношение доказуемого совпадения grounded-форм.

Оно является **наименьшим отношением с конечными доказательствами**, которое содержит:

```text
alpha-renaming binder-ов

ROOT ≈ ROOT ⟼ ROOT

START(F) ≈ START(F) ⟼ F

END(F) ≈ F ⟼ END(F)

F1 ≈ F2 and G1 ≈ G2
  =>
(F1 ⟼ G1) ≈ (F2 ⟼ G2)
```

Критическое слово — `наименьшее`.

Нельзя использовать правило:

```text
предположим F ≈ G
и из этого же предположения выведем F ≈ G
```

как доказательство.

Поэтому collapsed fixed-point model не получает автоматически:

```text
ROOT ≈ START(ROOT)
```

Для такого вывода нет конечной порождающей цепочки.

При этом сворачивание уже известной рекурсивной формы допустимо:

```text
START(ROOT)
≈
START(ROOT) ⟼ ROOT
```

Это даёт точный интерфейс для #583: обычная запись той же пары полюсов может оказаться развёрткой уже существующей рекурсивной формы, не создавая второй semantic Link.

## 10. Одновременное удовлетворение

Пусть `rho(x)` — grounded-форма, полученная конечным доказательством для связанной ссылки `x`.

Это не таблица runtime-объектов. `rho` — метазапись результата связывания.

Уравнение

```text
x = a ⟼ b
```

удовлетворено тогда, когда существует конечное доказательство:

```text
rho(x) ≈ rho(a) ⟼ rho(b)
```

Система `Σ` имеет grounded simultaneous solution, если:

```text
1. каждая связанная ссылка имеет конечное grounding-доказательство;
2. каждое уравнение удовлетворено;
3. все grounding-доказательства для одной ссылки согласованы по ≈;
4. результат не меняется при согласованном alpha-renaming;
5. никакая ссылка не получает различие только из физического имени или occurrence.
```

Все пять условий относятся к одной системе целиком.

## 11. Неопределённость и противоречие

F2 не объявляет любую конечную систему разрешимой.

Точная классификация:

```text
GROUNDED
  все ссылки имеют конечное согласованное решение

UNDERGROUNDED
  хотя бы одна ссылка не имеет конечного grounding-доказательства

AMBIGUOUS
  одна ссылка имеет два конечных grounding-вывода,
  которые не связаны ≈

INCONSISTENT
  grounding существует,
  но все уравнения одновременно не удовлетворяются
```

Для минимального F1 смыслового ядра получается `GROUNDED`.

Абсолютная непротиворечивость всей МТС здесь не утверждается. Независимые внешние модели и контрмодели принадлежат #584.

## 12. Решение минимальных смыслов F1

Правила дают конечную цепочку доказательств, но не временную историю создания.

### 12.1. Полный акорень

Две разные физические записи смыслов знаков:

```text
m∞ = m∞ ⟼ m∞
m= = m= ⟼ m=
```

дают одну и ту же метаформу:

```text
rho(m∞) = ROOT
rho(m=) = ROOT
```

Binder names исчезают из результата grounding.

F2 пока фиксирует этот alpha-neutral результат связывания. Теоремную формулировку «существует ровно одна semantic root Link» классифицирует #583.

### 12.2. Открывающие формы

```text
m[ = m[ ⟼ m∞
m( = m( ⟼ m∞
```

дают:

```text
rho(m[) = START(ROOT)
rho(m() = START(ROOT)
```

### 12.3. Закрывающие формы

```text
m] = m∞ ⟼ m]
m) = m∞ ⟼ m)
```

дают:

```text
rho(m]) = END(ROOT)
rho(m)) = END(ROOT)
```

### 12.4. Связность и несвязность

После grounding открывающей и закрывающей форм:

```text
rho(m1) = PAIR(START(ROOT),END(ROOT))
rho(m⟼) = PAIR(START(ROOT),END(ROOT))

rho(m0) = PAIR(END(ROOT),START(ROOT))
```

### 12.5. Двоеточие

После grounding смысла формальной связи:

```text
rho(m:) = PAIR(ROOT,rho(m⟼))
```

Таким образом ожидаемая корневая проекция получается без технических ID и без предположения готового равенства упорядоченных пар:

```text
m∞, m= -> R
m[, m( -> O
m], m) -> C
m1, m⟼ -> L
m0 -> U
m: -> R ⟼ L
```

`R/O/C/L/U` в последнем блоке — только привычные имена уже выведенных форм.

## 13. Почему `R`, `O`, `C` не схлопываются

Grounded-формы различаются способом связанной рекурсии:

```text
ROOT
START(ROOT)
END(ROOT)
```

Чтобы получить

```text
ROOT ≈ START(ROOT)
```

или

```text
ROOT ≈ END(ROOT)
```

нужно было бы либо:

```text
импортировать внешнее равенство;
допустить круговое доказательство самого себя;
использовать максимальное поведенческое отождествление.
```

Ни один такой шаг не входит в наименьшее F2-отношение.

Различие `O/C` дополнительно сохраняет упорядоченную сторону самоссылки.

Это объясняет требуемый root basis без объекта-ID и без внешней метки «тип связи».

## 14. Случаи, которые обязан выдерживать F2

### Переименование акорня

```text
x = x ⟼ x
y = y ⟼ y
```

Обе строки дают `ROOT`; имя не создаёт различие.

### Повтор одностороннего самозамыкания

```text
x = x ⟼ R
y = y ⟼ R
```

Обе строки дают `START(ROOT)`.

### Обычная развёртка уже рекурсивной формы

После:

```text
O = O ⟼ R
```

форма:

```text
O ⟼ R
```

связана с `O` одним fold/unfold-доказательством.

F2 не называет это общей теоремой no-instance; #583 должен вывести точный semantic consequence.

### Петля над акорнем

```text
Loop(R) = R ⟼ R
```

лежит в том же fold/unfold-классе, что `ROOT`.

### Петля над различённой формой

```text
Loop(O) = O ⟼ O
```

не является развёрткой:

```text
O = O ⟼ R
```

и потому не получает совпадение с `O` только из слова «петля».

### Симметричный взаимный цикл

```text
X = Y ⟼ R
Y = X ⟼ R
```

не имеет конечного grounding.

### Асимметричный взаимный цикл

```text
X = Y ⟼ R
Y = R ⟼ X
```

также не имеет конечного grounding. Внешняя структурная жёсткость не заменяет основание различия.

### Недостижимый технический мусор

Добавление физической записи, не участвующей в grounding нужной связанной ссылки, не меняет её форму.

### Повтор значения в последовательности

Три позиции с одним `L` используют одну grounded-форму `L`. Позиционная множественность принадлежит ExactSequence/history, а не F2 identity.

## 15. Роль внутреннего `=`

Метаотношение `≈` не является знаком `=` из F1.

В F1 знак `=` уже имеет специализированное контекстное чтение через локальные representatives.

F2 делает более низкоуровневую работу:

```text
binder
-> grounded recursive form
-> finite fold/unfold comparison
```

После этого FORMAL-правило `=` может сравнивать уже разрешённые representatives в конкретном контексте.

Нельзя использовать FORMAL `=` как скрытый инструмент для построения самого `rho`.

## 16. Статус закона тождества по полюсам

Принятый машинный инвариант:

```text
(A ⟼ B) = (C ⟼ D)
iff
A = C and B = D
```

не является исходным правилом grounding F2.

На этом шаге установлено только:

```text
если grounded subforms имеют finite ≈ proof,
то congruence даёт finite ≈ proof для их связей.
```

Обратное направление и общий no-instance вывод не закладываются аксиомой.

Их точная классификация:

```text
unique full selfclosure
one-sided uniqueness
same-pole ordinary Link identity
```

передаётся #583.

Так устраняется круг:

```text
pair identity
-> recursive identity
-> pair identity
```

## 17. Смысл без внешней функции Meaning

Для связанной ссылки `x` F2 не добавляет отдельный объект значения.

Рабочее чтение:

```text
semantic content of x
=
its grounded recursive form up to finite ≈ proof
```

Это метаописание, а не новая внутренняя функция.

Для акорня:

```text
ROOT ≈ ROOT ⟼ ROOT
```

оба полюса возвращают ту же полную рекурсивную определённость.

Поэтому выражение «связь смыслов / смысл смысла» получает внутреннее основание в рекурсивной форме, а не во внешнем атоме `Meaning`.

## 18. Нотационные контексты не исчезают

Grounding работает после F1 context resolution.

Нужно сохранять различие:

```text
FORMAL `⟼`
QUATERNARY `1`
ROOT `L`
```

Их смыслы могут разрешаться в одну grounded-форму связности, но Entries и use-roles различны структурно.

То же относится к:

```text
∞ и =
[ и (
] и )
```

Совпадение `rho(m_g)` не уничтожает carrier, Entry, context или history structure.

## 19. Отношение к исполнению

Исполняемая MTS v0.9 содержит совместимое наблюдаемое поведение:

```text
ensureRoot
startSelfClosed
endSelfClosed
ensure ordinary Link
read/replay != materialize
```

Но методы TypeScript не являются правилами F2.

Направление зависимости обратное:

```text
F2 rule
-> machine behavior can be checked against it
```

а не:

```text
Memory.ensure exists
-> therefore F2 is true
```

## 20. Детерминированность минимального F1

Для смысловых уравнений минимального F1:

```text
каждая ссылка имеет одну binding-clause;
вид самоссылки этой clause однозначен;
каждая несамоссылочная зависимость имеет конечное grounding;
```

Отсюда по конечной глубине grounding следует единственность `rho(x)` с точностью до `≈`.

Это локальное утверждение о закрытом F1 corpus.

Оно не означает:

```text
всякая будущая система МТС имеет решение;
всякое решение единственно;
МТС абсолютно непротиворечива.
```

## 21. Точный handoff в F3

F2 передаёт #583:

```text
1. alpha-neutral bound references;
2. four finite grounding rules;
3. prohibition of circularly bootstrapped distinction;
4. grounded recursive forms ROOT/START/END/PAIR as meta proof shapes;
5. least finite fold/unfold relation ≈;
6. simultaneous satisfaction criterion;
7. grounded/undergrounded/ambiguous/inconsistent classification;
8. exact grounded solution of all ten F1 sign meanings;
9. distinction between semantic content and carrier/use/occurrence;
10. ordered-pole identity left as a theorem boundary.
```

Теперь #583 может не кругово исследовать:

```text
нет рекурсивно выраженного различия
=>
нет двух semantic Links
```

и отдельно вывести или отвергнуть:

```text
unique full selfclosure
one-sided uniqueness
same-pole ordinary identity
```

## 22. Что остаётся открытым после F2

Не решаются этим шагом:

```text
общая теорема no-instance                 #583
единственность акорня                     #583
полный закон identity по полюсам          #583
независимая внешняя модель                #584
метатеоретические следствия                #585
история/позиционная множественность       #586
derived logic and inversion                later
```

Из старого исследовательского регистра также остаются будущими задачами:

- строгая семантика `↛`;
- тип и дальнейшее использование результата сравнения;
- переменные и подстановка;
- универсальное перечисление входящих/исходящих связей;
- пучковая операционная семантика;
- связь derived notation с асетью без смешения уровней.

## 23. Отвергнутые пути

Не являются фундаментом F2:

```text
runtime/storage identity
graph node identity
plain graph rigidity
automorphism quotient as definition
maximal unlabeled bisimulation
greatest fixed-point equality
source occurrence identity
sequential object creation
host callback / parser mode
```

Автоморфизмы, графы, коалгебры и иные внешние аппараты могут позже использоваться только как независимые модели или контрмодели #584.
