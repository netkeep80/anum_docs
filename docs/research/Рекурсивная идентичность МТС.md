# Рекурсивная идентичность МТС

> Статус: **foundational research** для #582 / F1 roadmap #588. Этот документ не меняет accepted MTS v0.8, contracts, conformance или runtime автоматически.

## 1. Задача

Текущая МТС утверждает одновременно:

```text
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

и:

```text
(A ⟼ B) = (C ⟼ D)
⇔
A = C ∧ B = D.
```

При этом technical ID, address, allocation event или object instance **не являются semantic identity**.

Поэтому фундаментальный вопрос нельзя свести к сравнению указателей:

> что именно является полной рекурсивной формой Link и когда две такие формы представляют одну semantic Link?

Цель этого research slice — дать минимальный mathematical carrier, набор candidate equivalences и falsification corpus до каких-либо изменений runtime.

---

## 2. Recursive presentation

Первый конечный carrier-кандидат:

```text
P = (V, s, e, p)
```

где:

- `V` — конечное множество binder variables / presentation nodes;
- `s : V -> V` — start reference;
- `e : V -> V` — end reference;
- `p ∈ V` — предъявляемая связь;
- имена/номера элементов `V` не имеют semantic meaning.

Эквивалентная notation:

```text
x = s(x) ⟼ e(x)
```

для каждого `x ∈ V`, с отдельно указанным `presented=x`.

### 2.1. Достижимая часть

Для semantic presentation учитывается только подграф, достижимый из `p` по `s/e`:

```text
Reach(P) = least S:
  p ∈ S
  x ∈ S => s(x), e(x) ∈ S.
```

Недостижимые binder variables являются мусором presentation и не должны менять предъявляемую semantic form.

### 2.2. Базовые presentations

Акорень:

```text
R:
  r = r ⟼ r
  presented = r
```

Одностороннее start-selfclosure:

```text
O:
  r = r ⟼ r
  o = o ⟼ r
  presented = o
```

Одностороннее end-selfclosure:

```text
C:
  r = r ⟼ r
  c = r ⟼ c
  presented = c
```

Производные формы:

```text
L:
  r = r ⟼ r
  o = o ⟼ r
  c = r ⟼ c
  l = o ⟼ c
  presented = l

U:
  r = r ⟼ r
  o = o ⟼ r
  c = r ⟼ c
  u = c ⟼ o
  presented = u
```

Имена `r/o/c/l/u` здесь — только binders.

## 3. Candidate A: syntactic equality

```text
P =synt Q
```

если совпадают literal variable names и equations.

Это заведомо слишком сильная equivalence:

```text
r = r ⟼ r
```

и

```text
x = x ⟼ x
```

должны предъявлять один `R`, но syntactically различны.

**Результат:** REJECT как semantic identity; допустима только как equality конкретной записи.

---

## 4. Candidate B: pointed ordered graph isomorphism

Для достижимых частей presentations определить:

```text
P ≅ord Q
```

если существует биекция:

```text
f : Reach(P) -> Reach(Q)
```

такая, что:

```text
f(p_P) = p_Q
f(s_P(x)) = s_Q(f(x))
f(e_P(x)) = e_Q(f(x))
```

для каждого `x ∈ Reach(P)`.

Это equality modulo alpha-renaming с сохранением:

- designated presented node;
- ordered start/end poles;
- finite sharing;
- cycles;
- exact self-reference pattern.

### 4.1. Положительные проверки

Две renamed presentations акорня изоморфны:

```text
r=r⟼r
x=x⟼x
```

следовательно могут представлять один semantic `R` без instance identity.

`R` и `O` не изоморфны:

- reachable carrier `R` имеет 1 node;
- reachable carrier `O` имеет 2 nodes.

`O` и `C` не изоморфны как **ordered** graphs:

```text
O: s(o)=o, e(o)=r
C: s(c)=r, e(c)=c.
```

Перестановка start/end не разрешена definition of isomorphism.

`L` и `U` также различимы порядком уже различённых `O/C`.

### 4.2. Важное ограничение

Plain pointed graph isomorphism ещё **не достаточно** для МТС.

Причина: оно способно индивидуализировать произвольный конечный cyclic presentation только его внутренней graph shape, даже если этот цикл никак не укоренён в уже различённом `R`.

Например presentation:

```text
x = y ⟼ y
y = x ⟼ x
presented = x
```

имеет вполне определённый finite graph-isomorphism class, но current MTS запрещает получать semantic distinction из произвольного ID-only / ungrounded cycle.

Следовательно, semantic model требует не только quotient, но и **admissibility/rootedness predicate**.

## 5. Root-grounded admissibility

Рабочий candidate:

```text
Admissible(P)
```

должен означать, что recursive presentation получает различимость из canonical full selfclosure `R`, а не из заранее назначенных binder identities.

Минимальные требования:

1. `R` admissible сам по себе;
2. `O/C` admissible, потому что их единственный внешний различённый pole ведёт к `R`;
3. ordinary `b⟼e` admissible, если `b/e` уже admissible/distinguished;
4. one-sided selfclosure admissible, если несамозамкнутый pole уже admissible/distinguished;
5. closed SCC, не имеющая structural grounding в `R`, не получает semantic identity только из binder labels;
6. technical renaming не влияет на admissibility.

### 5.1. Почему простой reachability-to-R ещё не окончательное определение

Фраза «из каждого node есть path к `R`» полезна, но её недостаточно принять без проверки:

- у `R` path к себе тривиален;
- one-sided selfclosure работает;
- ordinary rooted networks работают;
- но larger recursive systems могут содержать SCC, из которой часть poles rooted, а часть recursive.

Нужно определить admissibility индуктивно/коиндуктивно так, чтобы не использовать semantic identity, которую мы как раз пытаемся определить.

Это отдельное proof obligation внутри #582.

## 6. Candidate C: infinite unfolding

Можно развернуть finite presentation в бесконечное ordered binary tree:

```text
Unfold(P,p).
```

Преимущество: binder names исчезают.

Недостатки:

1. finite sharing теряется;
2. конечный cyclic carrier превращается в бесконечный объект;
3. разные finite sharing presentations могут иметь одинаковое unfolding;
4. implementation equality не должна требовать infinite expansion;
5. главный вопрос МТС — именно identity recursive finite form, а не только observational tree.

**Статус:** comparison candidate, но не принимать как semantic equality без separate theorem.

## 7. Candidate D: обычная coalgebraic bisimulation для `F(X)=X×X`

Это критический negative result.

Если рассматривать Link только как coalgebra:

```text
c : X -> X × X
c(x) = (start(x), end(x)),
```

без дополнительных observations/labels, то стандартная behavioral equivalence слишком груба.

### 7.1. Universal relation является bisimulation

Пусть:

```text
B = X × X.
```

Для любых `x B y` автоматически:

```text
start(x) B start(y)
end(x)   B end(y),
```

потому что `B` содержит все пары.

Следовательно universal relation — bisimulation.

Значит все states behavioral-equivalent:

```text
x ~bisim y
```

для любых `x,y`.

Эквивалентно: для functor `F(X)=X×X` singleton carrier является final coalgebra; голая behavioral semantics не различает `R/O/C/...`.

### 7.2. Следствие для МТС

Обычная bisimulation **не может** быть `≡MTS`, потому что она схлопывает как минимум:

```text
R ~ O ~ C.
```

Это не implementation detail, а фундаментальная граница:

> МТС требует intensional identity recursive form, сохраняющей exact finite self-reference/sharing structure, а не только unlabeled coalgebraic behavior.

**Результат:** REJECT plain bisimulation как semantic equality МТС.

Это не исключает coalgebraic методов вообще; возможны richer functors/observations или coalgebra на другом carrier, но они должны воспроизводить MTS distinctions, а не вводиться по аналогии.

## 8. Candidate E: MTS equivalence как admissible ordered recursive-form isomorphism

Первый сильный рабочий candidate:

```text
P ≡MTS Q
iff
Admissible(P)
∧ Admissible(Q)
∧ P ≅ord Q
```

после удаления unreachable presentation garbage.

Это пока **hypothesis**, не accepted definition.

Она удовлетворяет важным требованиям:

- binder renaming invisible;
- no semantic UUID;
- exact self-reference preserved;
- ordered poles preserved;
- finite sharing preserved;
- `R/O/C/L/U` различимы;
- equality finite/decidable через graph isomorphism для данного bounded carrier;
- ungrounded cycles могут быть rejected predicate `Admissible` до quotient.

Главный нерешённый вопрос — exact definition `Admissible` и compatibility с constructor/A6.

## 9. Constructor problem

Если semantic Link есть equivalence class presentation, нужно определить operation:

```text
Link([A], [B]) = [?].
```

Для ordinary already-distinguished poles естественный presentation construction:

1. взять representatives `P_A`, `P_B`;
2. alpha-rename binders, чтобы carriers не конфликтовали;
3. сохранить intentional sharing, если `A=B` или общие semantic subforms должны быть одним node/class;
4. добавить fresh presented node `x`:

```text
x = a ⟼ b;
```

5. canonicalize / quotient.

Нужно доказать **well-definedness**:

```text
A ≡MTS A'
B ≡MTS B'
=>
Link(A,B) ≡MTS Link(A',B').
```

Без этого A6 нельзя считать формально обоснованной на quotient.

### 9.1. Selfclosure constructors — отдельный случай

Формы:

```text
S = S ⟼ e
E = b ⟼ E
R = R ⟼ R
```

не являются обычным `Link(A,B)` над двумя заранее существующими semantic operands: binder `self` входит в определение создаваемой формы.

Поэтому mathematical presentation должен явно различать:

```text
ordinary linking of existing forms
```

и

```text
recursive binder construction / fixed-point presentation.
```

Это различие необходимо также для inversion #585/#454.

## 10. A6 и circularity

Accepted A6:

```text
(A⟼B)=(C⟼D)
⇔ A=C ∧ B=D
```

должна стать theorem/property semantic constructor, а не скрытым определением через host pointers.

Требуемая последовательность:

```text
presentation syntax
-> admissibility
-> ≡MTS
-> semantic classes
-> well-defined ordinary Link constructor
-> pair extensionality theorem A6.
```

Нельзя использовать A6 для определения equality `A/B`, а затем эту equality использовать для доказательства самой A6.

## 12. Первые выводы

На текущем research slice уже можно зафиксировать два результата.

### R1. Plain bisimulation отвергается

Для unlabeled `X -> X×X` universal relation является bisimulation, поэтому behavioral equivalence схлопывает все states и несовместима с `R/O/C` distinction.

### R2. Одного graph isomorphism недостаточно

Pointed ordered finite graph isomorphism хорошо моделирует alpha-neutral exact recursive form, но без отдельного rooted-admissibility condition способен приписать semantic identity произвольным ungrounded cycles.

Следовательно минимальная форма искомой семантики выглядит не как один quotient, а как:

```text
recursive presentation
-> rooted/admissible validation
-> exact ordered recursive-form quotient
-> semantic Link.
```

Это хорошо согласуется с уже принятой инженерной границей:

```text
physical graph
-> rooted structural validation/canonicalization
-> semantic MTS network.
```

## 13. Связь с «смыслом»

Рабочая foundation hypothesis #581:

> значение связи несёт её полная рекурсивная форма; external semantic atom не требуется.

Если `≡MTS` определяет именно полную форму, естественный строгий candidate:

```text
semantic content(X) := [RecPresentation(X)]≡MTS.
```

Тогда identity и content не являются двумя независимыми полями:

```text
semantic identity == complete recursive content.
```

Для акорня:

```text
R = R ⟼ R
```

оба poles являются той же полной рекурсией. В этом точном смысле дальнейший F3 challenge может исследовать чтение:

```text
R = Link(full recursion, full recursion)
```

как «связь рекурсий / связь смыслов / смысл смысла» без добавления `Meaning` в ontology.

В F1 это пока не theorem, а constraint на будущую model interpretation: никакой meaning-function не должна зависеть от binder names, IDs или внешней object identity.
