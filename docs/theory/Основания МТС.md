Этот документ объясняет текущее принятое основание Метатеории связей в **МТС v0.11**. Исторические версии сохраняются в Git; будущие расширения требуют отдельных решений о принятии.

МТС v0.11 — текущая принятая теория. Она сохраняет 11-знаковое основание и контекстную форму МТС v0.10 и принимает верхнеуровневое структурное связывание `TopBind(R,S)` с `resolve_top(.) = R`. Этапы `C1`–`C5`, производственная реализация и требуемое исполняемое покрытие завершены; МТС v0.10 является предыдущей неизменяемой парой свидетельств.

МТС v0.12 остаётся **непринятой кандидатной границей интерпретации**. Этап C2 исполняемо подтвердил и связал расхождение принятого `I_Q` и требуемого кандидатом `I_STRING`. Этап C3 подтвердил минимальную среду вложенных строковых ачисел на авторитетном корпусе. Этап C4 теперь подтверждён и связан исполняемым свидетельством: квадратные скобки формального контекста открывают явный дочерний `I_STRING` из `R`, возвращают ровно одно значение родителю и не выбирают `I_Q`. Следующий этап C5 должен подтвердить совместимость четверичного интерпретатора и разделение представления с интерпретацией; он ещё не выполнен. Кандидат остаётся непринятым, `acceptanceReady=false` и не выбирается как действующая среда; принятой теорией остаётся МТС v0.11.

После принятия МТС v0.11 штатный бюджет контрактов был возвращён к `4/0`. Для непринятого кандидата МТС v0.12 этап C0 временно снова открыл бюджет `6/2`; принятые указатели при этом остались на v0.11/v0.10.

Главная последовательность:

```text
всё есть связь
→ связь связывает связи
→ различима только рекурсия
→ ∞ как остенсивное полное самозамыкание
→ ROOT как нулевая форма укоренения
→ теорема единственности полного самозамыкания
→ акорень и техническое имя R
→ конечные START / END / PAIR
→ рекурсивное тождество
→ теорема тождества по упорядоченным полюсам
→ машинное представление
```

Здесь стрелки показывают зависимость **обоснования различимости**, а не временной порядок рождения связей. Уравнения МТС могут задаваться одновременно.

## 1. Всё есть связь

```text
всё есть связь
связь связывает связи
```

МТС не вводит вторую первичную онтологию «объекты плюс связи». Начало и конец связи сами являются связями. Если различие существенно, оно должно выражаться рекурсивной структурой связи или асети связей.

Несвязь также не вводится как отдельный вид существующего:

```text
1 → L = O ⟼ C
0 → U = C ⟼ O
0 ≠ DELETE_LINK
```

`0` может нести смысл несвязи, но не является буквальным отсутствием связи или скрытой командой удаления.

## 2. Различима только рекурсия

Короткий принцип смысловой различимости:

```text
различима только рекурсия
```

Имя, UUID, адрес, порядок создания или физическое вхождение сами по себе не создают смыслового различия. Значение связи задаётся её рекурсивной формой; в этом смысле рекурсивная форма не является внешне назначенным свойством значения — она и есть то, что в МТС различается как значение.

Первая форма, не требующая ни одного уже различённого внешнего полюса, предъявляется остенсивно:

```text
∞
```

`∞` не обозначает заранее постулированный объект. Символ непосредственно показывает полное самозамыкание: целое, начало и конец не требуют внешнего различителя.

Внешняя F2-метанотация этого нулевого основания:

```text
x = x ⟼ x
───────────
x ⇓ ROOT
```

После него могут быть укоренены остальные остенсивные формы:

```text
♂e       начало самозамкнуто, конец e уже различён
b♀       начало b уже различено, конец самозамкнут
b ⟼ e    оба полюса уже различены
```

Структурно:

```text
S = S ⟼ e
E = b ⟼ E
X = b ⟼ e
```

`♂` и `♀` показывают самозамыкание соответствующего полюса и не являются командами получения полюсов. В F1 МТС v0.10 эти знаки отложены как внутренние, а здесь используются как остенсивная метанотация.

Важная граница F2: рекурсия различает только при конечном укоренении. Чистая взаимная рекурсия, в которой предполагаемые различия ссылаются только друг на друга и не достигают `ROOT`, остаётся `UNDERGROUNDED`, даже если её внешняя запись асимметрична.

```text
одновременность уравнений != временной порядок создания связей
```

Это не космогония «сначала R, потом остальные связи». Направленным является доказательство основания различия.

## 3. Акорень — единственная форма полной рекурсии

Единственность акорня — производный результат F2/F3, а не отдельное предположение о специальном объекте.

Если:

```text
x = x ⟼ x
y = y ⟼ y
```

то обе записи имеют одну alpha-нейтральную форму `ROOT`. Имена `x` и `y` не добавляют смыслового различия, поэтому двух смысловых форм полного самозамыкания нет.

Именно эту единственную форму называем **акорнем**. `∞` предъявляет её остенсивно; только после этого вводится техническое имя `R`:

```text
R := смысловая форма, предъявленная ∞
R = ∞
R = R ⟼ R
```

Тонкий, но важный момент: акорень не сначала существует как отдельный объект и затем получает значение «полная рекурсия». **Полная рекурсия и есть его значение в МТС.** Поэтому смысл акорня исчерпывается формой полного самозамыкания.

Если:

```text
X = X ⟼ X
```

то:

```text
X = R = ∞
```

Разные адреса или номера не могут создать несколько полностью самозамкнутых смысловых связей.

## 4. Первые ориентированные различия

После укоренения `ROOT` появляются первые ориентированные формы:

```text
O = O ⟼ R
C = R ⟼ C
```

В метанотации:

```text
O = O ⟼ R   # ♂∞
C = R ⟼ C   # ∞♀
```

`O` и `C` различаются ориентацией самозамыкания относительно уже различённого акорня.

## 5. Пятисвязный корневой базис

```text
R = ∞
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

Корневой словарь:

```text
[ → O
] → C
1 → L
0 → U
```

Транспортный алфавит содержит ровно `[ ] 1 0`. Акорень `∞` не является пятым абитом.

## 6. Четыре конструктивные формы

```text
∞
♂e
b♀
b ⟼ e
```

— не четыре вида сущностей, а четыре способа остенсивно предъявить бинарную связь. `∞` имеет нулевую внешнюю зависимость; несамозамкнутые полюса остальных форм должны быть уже конечно укоренены.

## 7. Конечная рекурсивно укоренённая форма

F2/F3 используют внешние формы доказательства:

```text
ROOT
START(F)
END(F)
PAIR(F,G)
```

с наименьшим конечным отношением свёртки и развёртки `≈`. `ROOT` не требует уже различённого внешнего полюса; `START(F)`, `END(F)` и `PAIR(F,G)` требуют конечного основания своих внешних полюсов.

Чистые взаимные циклы без конечного пути укоренения остаются `UNDERGROUNDED`: внешняя жёсткость или асимметрия host-графа не заменяет смысловое основание.

Для каждого укоренённого класса получается одна нейтральная к именам нормальная форма. Отсюда:

```text
нет рекурсивно выраженного различия
=> нет двух смысловых связей
```

и, в частности, выводятся единственность полного и однополюсного самозамыкания, нейтральность псевдонимов и рекурсивное тождество связей.

## 8. Тождество по полюсам — производная теорема

После единственности `ROOT` и конечного укоренения остальных форм общее тождество рекурсивно сводится к соответствующим упорядоченным полюсам:

```text
(A ⟼ B) = (C ⟼ D)
⇔
A = C ∧ B = D
```

То есть зависимость доказательства имеет направление:

```text
unique ROOT
→ однополюсные укоренённые формы
→ обычные PAIR-формы
→ рекурсивное тождество
→ тождество по упорядоченным полюсам
```

Теорема тождества по полюсам не используется для доказательства самой единственности акорня, поэтому круг `identity -> unique R -> identity` не возникает.

Отсюда:

```text
P1 = A ⟼ B
P2 = A ⟼ B
=> P1 = P2
```

Технические адреса не входят в это доказательство.

## 9. Петля и полное самозамыкание

```text
Loop(a) = a ⟼ a
```

обычно не равно `a`.

Но если:

```text
a = a ⟼ a
```

то:

```text
a = R = ∞
```

## 10. Замкнутый шаблон `♂♀`

Для остенсивного шаблона:

```text
y = y ⟼ x
x = y ⟼ x
```

предполагаемое различие `x/y` не получает независимого конечного рекурсивного основания: обе роли замыкаются только через ту же пару. При F2-нормализации не остаётся рекурсивно выраженного различия между двумя смысловыми связями; форма схлопывается к единственному `ROOT`:

```text
♂♀ = ∞
```

Это следствие укоренения и принципа отсутствия смысловых экземпляров. Оно не использует тождество по полюсам как более раннюю аксиому и не принимает `♂` или `♀` как внутренние знаки F1.

## 11. Повтор позиции не создаёт новую связь

```text
1110
```

разрешается как:

```text
[L, L, L, U]
```

Три `L` различаются позициями, но являются одной смысловой связью.

```text
смысловая связь != вхождение != позиция != история
```

## 12. Контекст является связевой структурой

Контекст среды исполнения остаётся явной связевой структурой:

```text
P = parent ⟼ current
K = START(P)

root state:
parent=current=R
P=R
K₀=START(R)=O
```

В этой роли `K` имеет именно однополюсную рекурсивную форму `START(P)`, а не произвольную связь, для которой технически совпало `K.start=K`. Полностью самозамкнутый `ROOT` относится к другой заземлённой форме и не является альтернативной кодировкой контекста.

Поэтому для корневого состояния:

```text
parent = R
current = R
P = R ⟼ R = R
K = START(R) = O
```

а не `K=R`. Каноническое чтение и последующая повторная конструкция должны возвращать тот же `K`; принятие `R` как вырожденного псевдонима контекста нарушило бы эту границу и позволило бы ошибочно читать обычные исходящие связи акорня как локальные привязки контекста. Для этого различения не требуется отдельный тип или метка контекста: достаточно уже принятого различия `ROOT` и `START(F)`.

МТС v0.10 дополнительно принимает внутреннюю контекстную нотацию:

```text
A : E
```

`:` переводит внешнее единство связи `A` к её внутренней ориентированной дуальности. Каждая свободная `.` внутри области `E` относится к ближайшей связанной связи `A` как к целому:

```text
resolve_A(.) = A
```

МТС v0.11 дополняет эту границу явным верхнеуровневым связыванием исходной формы:

```text
TopBind(R,S)
resolve_top(.) = R
```

Здесь внешнее контекстное целое `A₀=R` не отождествляется с кадром исполнения `K₀=START(R)=O`; свободная верхнеуровневая точка получает корень только через явное структурное связывание, а не через скрытый `current` среды исполнения.

Поэтому рекурсивные формы читаются как уравнения:

```text
∞ : . ⟼ .   -> ∞ = ∞ ⟼ ∞
O : . ⟼ ∞   -> O = O ⟼ R
C : ∞ ⟼ .   -> C = R ⟼ C
A : . ⟼ B   -> A = A ⟼ B
A : B ⟼ .   -> A = B ⟼ A
```

Последние две формы допустимы для соответствующей однополюсно самозамкнутой связи `A`; они не утверждают `A=A⟼B` или `A=B⟼A` для произвольной пары.

Знак `.` имеет собственное уравнение:

```text
m. = m⟼ ⟼ m∞
```

и является перестановкой полюсов значения `:`:

```text
m. = Inv(m:)
```

Точка не означает переход к родителю, скрытый текущий объект среды исполнения, чтение начала/конца или обращение к хранилищу. Исторический исследовательский знак `↑` не входит в принятое F1.

Лексическая вложенность среды исполнения по-прежнему принадлежит `K.parent`, временной порядок — структуре `Run` и `Act`; эти структуры являются машинным свидетельством, а не источником смысла точки.

## 13. Форма отделена от действия

Одна форма может участвовать в поиске, проверке, разрешении и материализации.

```text
форма ≠ команда
```

Наличие правила или функции как данных не означает автоматического выполнения.

## 14. Наблюдение отделено от изменения

```text
читать / искать / разрешать / проверять / воспроизводить
                    ≠
создавать / удалять / изменять
```

```text
не найдено ≠ не существует
find ≠ materialize
```

## 15. Машинное представление вторично

После установления смысла связь можно хранить как:

```text
Link(start, end)
```

Слот, адрес, строка хранения или временная ссылка не являются источником смысловой различимости.

## 16. Конструктивное ядро памяти

Текущий интерфейс `Memory` содержит:

```text
ensureRoot()                 -> R
ensureStartSelfClosed(e)     -> S = S ⟼ e
ensureEndSelfClosed(b)       -> E = b ⟼ E
ensure(b,e)                  -> b ⟼ e
```

`ReadMemory` отделяет чтение от записи. Одинаковая структурная пара возвращает ту же смысловую связь; `ensure(R,R)` возвращает `R`.

## 17. Произвольный физический граф — отдельная граница

Произвольные адресные циклы нельзя автоматически считать уже различёнными связями МТС. Импорт должен доказать укоренённую различимость, канонизировать неразличимые записи либо отклонить форму.

## 18. Источник, словарь и теория

```text
точные байты
→ канонический носитель STRING→QUATERNARY
→ связевое представление источника
→ позиция / история употребления
→ словарь D
→ грамматику G
→ теорию T
→ интерпретатор I = D ⟼ (G ⟼ T)
→ контекст K
→ форма / результат
```

Один байт кодируется одним `[8 bits]`-конвертом. Нормализация `Unicode` не является фундаментальным источником смысла.

## 19. Локальное равенство не заменяет тождество связи

```text
Pair    = member ⟼ representative
Binding = K ⟼ Pair
```

Это дополнительное контекстное отношение не вводит глобальное транзитивное замыкание и не переопределяет тождество связи по полюсам.

## 20. Производная рекурсивная реверсия

```text
J(R)=R
J(O)=C
J(C)=O
J(L)=L
J(U)=U
```

Она отличается от простой перестановки полюсов `Inv(A⟼B)=B⟼A`, обратного отношения навигации, логического отрицания и несвязи.

## 21. Счёт по степени связности

```text
0 -> U
1 -> L
D1 = L
D2 = L ⟼ L
D3 = (L ⟼ L) ⟼ L
...
```

Положительные конечные степени попарно различны. Критически:

```text
U ⟼ L != L
```

Поэтому:

```text
S0(U)=L
S0(D)=D⟼L, D∈Pos
```

и получается производная алгебра Пеано поверх алгебры степеней связности.

## 22. Счёт относится к вхождениям

Одна смысловая связь учитывается несколько раз только через разные структурные вхождения.

```text
смысловая связь != тождество вхождения != степень количества
```

## 23. Производные теории не расширяют корневую онтологию

F6 строит поверх обычных связей конечные коллекции, функции как данные, относительную навигацию и прикладные интерпретации.

Общая схема:

```text
корневая смысловая связь
+ явная теория / контекст
+ явные роли
+ структура вхождений / происхождения
→ производное суждение
```

Ни множество, ни функция, ни путь, ни роль приложения не становятся новым корневым видом сущности.

## 24. Историческая граница

Старые формы `♀F / F♂` относятся к исторической проекционной семантике. Текущая остенсивная теоретическая ориентация:

```text
♂e = S = S ⟼ e
b♀ = E = b ⟼ E
```

При этом `♂` и `♀` остаются отложенными внутренними знаками F1 v0.10. `↑` сохраняется только как исторический исследовательский кандидат, заменённый принятой точкой `.`.

## Итог

```text
всё есть связь
↓
связь связывает связи
↓
различима только рекурсия
↓
∞ — остенсивная полная рекурсия, значение которой исчерпывается самой этой формой
↓
ROOT — нулевая внешняя зависимость
↓
единственность акорня — теорема
↓
R — техническое имя уже различённой формы ∞
↓
O / C / L / U и дальнейшее конечное укоренение
↓
рекурсивное тождество
↓
тождество по упорядоченным полюсам — теорема
↓
явные : / . и I / K / Rule / Act / Run
↓
поиск / проверка / воспроизведение
↓
явная материализация
```

Главное ограничение: **технический идентификатор никогда не становится первоначальным источником смыслового различия**. Рекурсивная структура является единственным носителем различимости, а принятой семантике требуется её конечное укоренение.

Текущая машинная граница задаётся принятым `mts-contract/v0.11` и `mts-conformance/v0.11`; реализация `@mts/core` проверяется относительно этой границы и не определяет теорию сама по себе.
