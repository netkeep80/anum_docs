## Теорема FND-01

**Статус:** текущая теорема; нативная классификация: нет.
**Происхождение:** `historical-restated`.  
**Волна:** `A`.

**Исходная формулировка (исторический v0.14 evidence, не FORMAL v0.15):**
~~~text
One Link ontology and one abstract Link-forming primitive induce exactly four local self-incidence structural cases; after an oriented Context these are ROOT, START_K, END_K and PAIR.
~~~

  - `x : Link`
- **FORMAL-область экзистенциальных свидетелей:**
  - `startWitness : Link`
  - `finishWitness : Link`
  - `pairWitness : Link`
- **Не являются внешними FORMAL-предпосылками:**
  - `FND-02 as premise`

  - `Grounded:x`
- **Источник FORMAL:** [`ts/test/v015-fnd01-formal-statement-b18.test.ts`](../../ts/test/v015-fnd01-formal-statement-b18.test.ts).

**Область действия:**
~~~text
Local four-case self-incidence classification plus grounded realizability witnesses. The classifier itself is proposition-level; Context orientation only names the one-sided cases after classification.
~~~

**Исключения:**
~~~text
No host enum, codec digit, host handle equality, Memory canonical-map identity, or four-opcode implementation may serve as classification authority. External proof must separate the four proposition-level combinations from implementation decidability. FND-01 does not include arbitrary-Link pole extensionality: ordered-pole identity is the separate FND-13 theorem on its explicit finite Grounded normalization domain. Context orientation only names the two one-sided cases after the structural partition exists.
~~~
