МТС v0.11 является текущей принятой системой. Она сохраняет внутренний знак `.`, контекстное связывание через `A:E` и остальные обязательства МТС v0.10 и принимает верхнеуровневое структурное связывание `TopBind(R,S)` с `resolve_top(.) = R`. Этапы `C1`–`C5`, производственная реализация и требуемое исполняемое покрытие завершены; МТС v0.10 сохраняется как предыдущая неизменяемая пара свидетельств.

Этап `C6-B2` завершён: старейшая активная пара МТС v0.9 удалена, а временный бюджет контрактов `6/2` возвращён к штатному `4/0`. Активное дерево содержит только текущую v0.11 и предыдущую v0.10; более ранние принятые выпуски, включая v0.9, сохраняются как исторические свидетельства в Git и `cutover/`.

Исторические версии сохраняются в Git и не определяют текущую семантику автоматически.

## Как читать пункты А0–А20

Идентификаторы `А0`–`А20` сохраняются как стабильные номера нормативных пунктов. Буква `А` в исторической нумерации **не означает**, что каждый пункт является независимой аксиомой.

В этом документе статус основания указывается явно:

```text
ПОСТУЛАТ / ОНТОЛОГИЯ
ОПРЕДЕЛЕНИЕ / ФОРМА
ПРИНЦИП РАЗЛИЧИМОСТИ
ПРОИЗВОДНАЯ ТЕОРЕМА
ПРОИЗВОДНОЕ СТРУКТУРНОЕ СЛЕДСТВИЕ
РЕАЛИЗАЦИОННОЕ ОГРАНИЧЕНИЕ
```

Это устраняет круговую трактовку, при которой единственность акорня и тождество по полюсам одновременно считались бы и аксиомами, и результатами F2/F3.

## А0. Онтологическая замкнутость

**Статус: ПОСТУЛАТ / ОНТОЛОГИЯ + структурное определение связи.**

```text
всё есть связь
связь связывает связи
```

Начало и конец связи сами являются связями. Отдельного первичного слоя «объектов», «узлов» или технических идентификаторов за связями не вводится.

Любое семантически существенное различие должно быть выражаемо связью или сетью связей.

```text
1 → L = O ⟼ C
0 → U = C ⟼ O
0 ≠ DELETE_LINK
```

Несвязь не вводится как вторая первичная сущность.

## А1. Рекурсия — единственный источник различимости

**Статус: ПРИНЦИП РАЗЛИЧИМОСТИ + правило конечного укоренения F2.**

Короткая формулировка:

```text
различима только рекурсия
```

Смысловое различие существует только тогда, когда оно выражено рекурсивной структурой связей. Имя, UUID, адрес, строка хранения, порядок создания или отдельное физическое вхождение сами по себе различия не создают.

При этом принятая F2-семантика требует **конечного укоренения** различия. Одной круговой зависимости различий друг от друга недостаточно.

Первая форма не нуждается ни в одном уже различённом внешнем полюсе и предъявляется остенсивно:

```text
∞
```

`∞` здесь не является именем заранее данного объекта. Символ непосредственно показывает полное самозамыкание: начало, конец и целое замкнуты в одной рекурсивной форме.

На метауровне F2 это соответствует нулевой по внешним зависимостям форме:

```text
x = x ⟼ x
───────────
x ⇓ ROOT
```

Дальнейшие остенсивные формы:

```text
♂e       начало самозамкнуто, конец e уже различён
b♀       начало b уже различено, конец самозамкнут
b ⟼ e    оба полюса уже различены
```

и их структурные проекции:

```text
S = S ⟼ e
E = b ⟼ E
X = b ⟼ e
```

Несамозамкнутый полюс должен иметь конечное рекурсивное основание. Чистая взаимная рекурсия, в которой различия только ссылаются друг на друга и не достигают `ROOT`, остаётся `UNDERGROUNDED`, даже если внешняя запись графически асимметрична.

`♂` и `♀` здесь — остенсивная метанотация; в F1 v0.10 они отложены как внутренние знаки.

Важно:

```text
одновременность уравнений
!=
временной порядок создания связей
```

Направленным является доказательство основания различия, а не история возникновения смыслов.

## А2. Единственность акорня

**Статус: ПРОИЗВОДНАЯ ТЕОРЕМА F2/F3, не независимая аксиома.**

Пусть две связанные записи предъявляют полное самозамыкание:

```text
x = x ⟼ x
y = y ⟼ y
```

Обе имеют одну alpha-нейтральную укоренённую форму `ROOT`. Имена `x` и `y` не несут смыслового тождества, а рекурсивно выраженного различия между этими предъявлениями нет.

Следовательно существует одна смысловая форма полного самозамыкания.

Эту форму называем **акорнем**. Остенсивно она предъявляется знаком `∞`, а техническое имя `R` вводится уже после различения и доказательства единственности:

```text
R := смысловая форма, предъявленная ∞
R = ∞
R = R ⟼ R
```

Если:

```text
X = X ⟼ X
```

то:

```text
X = R = ∞
```

Технический идентификатор не создаёт второй полностью самозамкнутый смысловой корень.

## А3. Однополюсное самозамыкание различает ориентацию

**Статус: ПРОИЗВОДНАЯ ТЕОРЕМА после укоренения внешнего полюса.**

```text
♂e = S = S ⟼ e
b♀ = E = b ⟼ E
```

Для фиксированного уже различённого внешнего полюса соответствующая форма единственна. Ориентация `start/end` входит в рекурсивную структуру и потому может нести различие.

## А4. Бинарность и направленность

**Статус: ОПРЕДЕЛЕНИЕ / структурное обязательство связи.**

```text
X = b ⟼ e
```

Полная связь имеет два упорядоченных различённых полюса. В общем случае:

```text
b ⟼ e ≠ e ⟼ b
```

## А5. Пятисвязный корневой базис

**Статус: ПРОИЗВОДНЫЙ БАЗИС / именование уже укоренённых форм.**

После введения технического имени `R` для единственной формы `∞`:

```text
R = ∞
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

Корневой словарь:

```text
∞ → R
[ → O
] → C
1 → L
0 → U
```

`[ ] 1 0` — ровно четыре абита; `∞` не является пятым.

## А6. Тождество связи определяется полюсами

**Статус: ПРОИЗВОДНАЯ ТЕОРЕМА F2/F3, не независимая аксиома.**

После укоренения сравниваемых форм тождество связи рекурсивно сводится к тождеству соответствующих упорядоченных полюсов; базой является единственная форма `ROOT`.

Для полной связи:

```text
(A ⟼ B) = (C ⟼ D)
⇔
A = C ∧ B = D
```

Технические ссылки, адреса и номера операций не входят в смысловое тождество.

Эта теорема находится **ниже** единственности акорня в dependency graph и поэтому не используется для доказательства самой единственности `R`.

## А7. Различимость распространяется от корня

**Статус: ПРОИЗВОДНОЕ СТРУКТУРНОЕ СЛЕДСТВИЕ F2.**

```text
∞ / ROOT
→ R
→ O / C
→ L / U
→ связи с уже различёнными полюсами
→ дальнейшая асеть
```

Стрелки здесь обозначают конечную зависимость доказательства различимости, а не временной порядок существования или материализации связей.

## А8. Петля отличается от полного самозамыкания

**Статус: ПРОИЗВОДНОЕ СТРУКТУРНОЕ СЛЕДСТВИЕ.**

```text
Loop(a) = a ⟼ a
```

обычно не равно `a`. Но если:

```text
a = a ⟼ a
```

то `a = R = ∞`.

Замкнутый остенсивный шаблон `♂♀` также схлопывается в `∞`, потому что его предполагаемые различия не получают независимого рекурсивного основания.

### Конечная левая итерация

```text
a¹ = a
aⁿ⁺¹ = aⁿ ⟼ a,  n >= 1
```

`n` принадлежит метаязыку и не является внутренним числом МТС.

## А9. Роли выражаются связями

Тип, теория, правило, контекст или роль не являются скрытыми полями примитивной связи.

```text
T ⟼ Rule
```

выражает допуск правила связевой структурой.

## А10. Форма отделена от действия

```text
форма ≠ команда
```

Поиск, проверка, разрешение и материализация — разные акты. Наличие правила или функции как данных не означает выполнения.

## А11. Контекст явен

Контекст среды исполнения выражается связями:

```text
P = parent ⟼ current
K = K ⟼ P
I ⟼ K
```

Внутренняя контекстная форма, принятая в МТС v0.10:

```text
A : E
```

обозначает переход от внешнего единства `A` к его внутренней ориентированной дуальности. Свободная точка в `E` связывается ближайшим таким контекстом:

```text
resolve_A(.) = A
```

МТС v0.11 принимает верхнеуровневое структурное связывание исходной формы:

```text
TopBind(R,S)
resolve_top(.) = R
```

При этом верхнеуровневое контекстное целое и frame исполнения не отождествляются:

```text
A₀ = R
K₀ = START(R) = O
A₀ != K₀
```

Верхнеуровневая точка получает `R` через явное структурное связывание, а не через скрытый `current` среды исполнения или неявный исходный префикс `∞`.

Основные рекурсивные обязательства:

```text
∞ : . ⟼ .   -> ∞ = ∞ ⟼ ∞
O : . ⟼ ∞   -> O = O ⟼ R
C : ∞ ⟼ .   -> C = R ⟼ C
A : . ⟼ B   -> A = A ⟼ B
A : B ⟼ .   -> A = B ⟼ A
```

Односторонние общие формы относятся к соответствующей однополюсно самозамкнутой связи `A`, а не к произвольной паре `A,B`. Полная форма `A:.⟼.` совпадает с `A` только для акорня.

Собственное уравнение точки:

```text
m. = m⟼ ⟼ m∞
```

а значение двоеточия сохраняется:

```text
m: = m∞ ⟼ m⟼
```

Следовательно:

```text
m. = Inv(m:)
```

Точка не является переходом к родителю, скрытым `current(K)`, чтением начала/конца или обращением к хранилищу. `↑` остаётся только историческим исследовательским знаком.

Лексическая вложенность исполнения хранится через `K.parent`, временной порядок — через `Run`/`Act`.

## А12. Источник отделён от формы

```text
точные байты
→ STRING→QUATERNARY
→ связевое представление источника
→ история употребления
→ D / G / T
→ форма F
```

Один байт кодируется одним `[8 bits]`-конвертом. Представление, интерпретация и денотация различаются.

## А13. Словарь и история явны

```text
D = D ⟼ (parentScope ⟼ localHistory)
Entry = sourceContent ⟼ form
Definition = D_before ⟼ Entry
```

Различие событий определения хранится в истории, а не в технических экземплярах одной пары.

## А14. Чтение отделено от изменения

```text
читать / искать / разрешать / проверять / воспроизводить
                    ≠
создавать / удалять / изменять
```

```text
не найдено ≠ не существует
find ≠ materialize
```

## А15. Локальное отношение представителей не заменяет теорему тождества

```text
Pair    = member ⟼ representative
Binding = K ⟼ Pair
```

Оно не вводит автоматически глобальную подстановку, транзитивность или конгруэнтность и не переопределяет производную теорему А6.

## А16. Правило требует явного допуска

```text
Rule = DR ⟼ Body
T ⟼ Rule
```

Проверка структурного правила выполняется только чтением.

## А17. Акт, интерпретатор и результат различаются

```text
I — интерпретатор
A — акт
R — результат
```

Различие актов выражается структурой истории, а не номером экземпляра.

## А18. Циклы требуют укоренённой различимости

Самозамыкания, петли, совместное использование и взаимные циклы допустимы, если элементы структурно различены относительно корневого основания.

Чистая взаимная рекурсия, в которой предполагаемые различия имеют только круговое основание друг в друге, не получает смысловую индивидуальность из одной внешней формы записи.

## А19. Физический адрес не является тождеством связи

Оперативный адрес, долговременный адрес, номер записи снимка и смысловая связь — разные уровни. Дубликаты одной структурно неразличимой формы канонизируются либо отклоняются.

## А20. Остенсивность предшествует машине

```text
∞
→ zero-dependency ROOT grounding
→ теорема единственности акорня
→ имя R

♂e / b♀ / b⟼e
→ конечное укоренённое структурное различение
→ рекурсивное тождество
→ теорема тождества по полюсам
→ Link(start,end)
```

Машинный носитель не является источником теории.

# Производные результаты

## F2/F3. Нормализация и отсутствие смысловых экземпляров

Используются конечные формы:

```text
ROOT
START(F)
END(F)
PAIR(F,G)
```

с наименьшим отношением `≈`. Для каждого класса существует одна нейтральная к именам нормальная форма.

Нулевая форма укоренения:

```text
x = x ⟼ x
───────────
x ⇓ ROOT
```

не требует уже различённого внешнего полюса. `START(F)`, `END(F)` и `PAIR(F,G)` требуют конечного основания своих внешних полюсов.

Поэтому:

```text
различима только рекурсия
```

означает в принятой F2-семантике **конечно укоренённую рекурсию**, а не произвольную глобальную жёсткость взаимного цикла.

```text
нет рекурсивно выраженного различия
=> нет двух смысловых связей
```

Отсюда следуют единственность корня и однополюсных форм, тождество полной связи по полюсам и нейтральность псевдонимов.

Именно поэтому А2 и А6 выше классифицированы как теоремы, а не как независимые аксиомы.

## F4. Рекурсивная реверсия

```text
J(R)=R
J(O)=C
J(C)=O
J(L)=L
J(U)=U
```

Она отличается от простой перестановки полюсов `Inv(A⟼B)=B⟼A`, обратного отношения навигации, отрицания и несвязи.

## F5. Счёт по степени связности

```text
0 -> U
1 -> L
D1 = L
D2 = L ⟼ L
D3 = (L ⟼ L) ⟼ L
...
```

Конечные положительные степени попарно различны и не образуют положительных циклов.

```text
U ⟼ L != L
```

Поэтому:

```text
S0(U)=L
S0(D)=D⟼L, D∈Pos
```

Получается производная алгебра Пеано поверх алгебры степеней связности.

`Count` считает явно различённые вхождения, а не смысловые копии связей.

## F6. Производные теории

Коллекции, конечные функции как данные, относительная навигация и прикладные интерпретации строятся поверх обычных связей, явной теории/контекста и структуры вхождений/происхождения.

Ни множество, ни функция, ни путь, ни прикладная роль не становятся новым корневым видом сущности.

Для чтений открытого мира сохраняется:

```text
не найдено
!= пусто
!= не существует
```

если нет явного свидетельства замкнутости.

## Историческая граница

Старые `♀F / F♂` относятся к исторической проекционной семантике. Остенсивные `♂e / b♀` остаются теоретической метанотацией; `♂`/`♀` отложены как внутренние знаки F1 v0.10. `↑` остаётся историческим исследовательским знаком, заменённым принятой точкой `.`.

## Сжатая система

