# Система аксиом МТС

Этот документ фиксирует компактный нормативный набор обязательств текущего кандидата следующего основания МТС. Объяснения и мотивация находятся в [Основаниях МТС](Основания%20МТС.md).

Следующая версия ещё не принята. Принятые версии 0.2–0.5 остаются воспроизводимой историей.

## А0. Онтологическая замкнутость

```text
всё есть связь
```

Любое семантически существенное различие должно быть представимо связью или сетью связей.

## А1. Единственный акорень

Существует ровно одна полностью самозамкнутая связь — акорень:

```text
∞
∞ = ∞ ⟼ ∞
```

Полное самозамыкание не создаёт семейство различимых связей. Если:

```text
X = X ⟼ X
```

то:

```text
X = ∞
```

Технический адрес, номер записи или временная ссылка построения не могут служить скрытым различителем между несколькими полностью самозамкнутыми связями.

## А2. Четыре остенсивные формы

```text
∞
♂e
b♀
b ⟼ e
```

Структурно:

```text
R = R ⟼ R
S = S ⟼ e
E = b ⟼ E
X = b ⟼ e
```

`♂` и `♀` показывают самозамыкание соответствующего полюса и не являются встроенными командами вычислителя.

## А3. Однополюсное самозамыкание не является типом

Форма:

```text
S = S ⟼ e
```

не означает сама по себе «незавершённость». Аналогично:

```text
E = b ⟼ E
```

не является отдельным онтологическим типом.

Но полное самозамыкание является предельным корневым случаем А1:

```text
X = X ⟼ X
=>
X = ∞
```

Роль обычной связи определяется не специальным типом формы, а её положением и связями с другими связями.

## А4. Бинарность и направленность

Полная связь имеет два упорядоченных полюса:

```text
X = b ⟼ e
```

Обращение порядка в общем случае задаёт другую связь:

```text
b ⟼ e  ↔  e ⟼ b
```

Если оба полюса совпадают, обращение не меняет связь.

## А5. Пятисвязный корень

```text
R = ∞
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

Корневой словарь:

```text
∞ → R
[ → O
] → C
1 → L
0 → U
```

Остенсивно:

```text
O = O ⟼ R ≡ ♂∞
C = R ⟼ C ≡ ∞♀
```

`[ ] 1 0` — корневые абиты; `♂ ♀ ⟼` — знаки формальной нотации форм связи.

## А6. Тождество связи определяется полюсами

Связь полностью определяется своим началом и концом:

```text
(A ⟼ B) = (C ⟼ D)
⇔
A = C ∧ B = D
```

Следовательно:

```text
P1 = A ⟼ B
P2 = A ⟼ B
=> P1 = P2
```

В МТС не существует двух различных связей с одной и той же упорядоченной парой полюсов.

Технические адреса, номера записей, позиции последовательности и акты построения могут различаться, но они не создают дополнительного тождества самой связи.

Для рекурсивных форм нельзя сначала различить технические ссылки, а затем использовать это различие как доказательство различия самих смысловых полюсов. Именно поэтому А1 отдельно фиксирует единственность полностью самозамкнутой связи.

Это необходимо отличать от модели сети дуплетов Теории связей, где ссылка на дуплет и значение пары являются разными уровнями.

## А7. Роли выражаются связями

Примитивная связь имеет только начало и конец. Семантические роли не должны скрываться в обязательных полях типа, стадии или признака аксиомы.

Например допуск правила выражается связью:

```text
T ⟼ Rule
```

## А8. Форма отделена от действия

Остенсивная форма декларативна:

```text
форма ≠ команда
```

Поиск, проверка, разрешение и материализация определяются явным актом и предъявленными свидетельствами.

При этом разные акты получения одной формы не создают несколько экземпляров самой связи.

## А9. Контекст явен

```text
P = parent ⟼ current
K = K ⟼ P
↑ = current(K)
```

Состояние контекста представлено связями. Если меняется его связевая структура, получается другое состояние; повтор той же формы обозначает ту же связь по А6.

Предыдущее состояние не изменяется задним числом.

## А10. Исходная запись отделена от формы

```text
байты
→ каноническое содержимое
→ связевое представление исходной записи
→ разбиение
→ D
→ G / T
→ F
```

Написание знака не является самостоятельным семантическим авторитетом.

Повтор одной и той же разрешённой формы ссылается на ту же связь; различие позиций исходной последовательности хранится самой последовательностью или её связевой историей.

## А11. Словарь и теория явны

Словарь и теория существуют как сети связей.

Пример состояния словаря:

```text
D = D ⟼ (parentScope ⟼ localHistory)
```

Допуск:

```text
G ⟼ Form
T ⟼ Form
T ⟼ Rule
```

## А12. Определение является явным изменением

Добавление определения создаёт новое состояние словаря, если его структура действительно изменилась, и сохраняет прежнее состояние.

Схематично:

```text
Entry       = sourceContent ⟼ form
Definition  = D_before ⟼ Entry
H_after     = H_before ⟼ Definition
D_after     = D_after ⟼ (sameParent ⟼ H_after)
```

По А6 повторное получение уже существующей связи не создаёт её копию.

Знак `:` не означает автоматически равенство или доказанность.

## А13. Чтение отделено от изменения

```text
читать / искать / разрешать / проверять
                    ≠
создавать / удалять / изменять
```

Отсутствие найденной записи связи в конкретной памяти не даёт права создавать её скрыто.

Семантическая однозначность `A ⟼ B` по А6 не означает, что любая конкретная апамять обязана уже содержать физическую запись этой связи.

## А14. Равенство локальных представителей не заменяет А6

Для дополнительных локальных отождествлений могут использоваться явные связи представителей:

```text
Pair    = member ⟼ representative
Binding = K ⟼ Pair
```

```text
Equal_K(a,b)
⇔ rep_K(a) = rep_K(b)
```

Это отдельный контекстный механизм и не переопределяет фундаментальное тождество самой связи по её началу и концу.

Автоматически не следуют глобальная подстановка, транзитивное замыкание или конгруэнтность произвольных выражений.

## А15. Правило вывода требует допуска теорией

Любое дополнительное правило предъявляется явно:

```text
T ⟼ Rule
```

Правило не становится частью равенства только потому, что кажется естественным для реализации.

## А16. Конкретный акт отличен от вычислителя и результата

Следует различать:

```text
I — вычислитель
A — конкретный произошедший акт
R — связь-результат
```

Разные акты могут иметь один и тот же результат. Тождество актов и тождество результирующей связи — разные вопросы.

Акт связывает предъявленные сведения об исходной записи, словаре, теории, контексте, подстановках и результате.

## А17. Последовательность актов хранит происхождение

```text
Run_0 = R
Run_(i+1) = Run_i ⟼ A_i
```

Соседние акты требуют совпадения переходного контекста:

```text
A_i.after = A_(i+1).before
```

Если вся связевая форма двух историй совпадает, по А6 это одна и та же связевая история. Различие происхождения должно выражаться различием самой структуры, а не скрытым номером экземпляра.

Такая последовательность не вводит логическую транзитивность сама по себе.

## А18. Циклы, совместное использование и повтор ссылок допустимы

Асеть может содержать:

- однополюсное самозамыкание;
- взаимные циклы;
- петли формы `a ⟼ a`;
- совместное использование одной связи разными структурами;
- повтор одной связи в последовательности.

Для каждого данного `a` связь `a ⟼ a` единственна по А6. Если сама эта связь совпадает с `a`, то получается полное самозамыкание и по А1:

```text
a = a ⟼ a
=>
a = R = ∞
```

Асеть не содержит несколько различных связей одной пары полюсов и не содержит нескольких полностью самозамкнутых связей.

Древовидное описание ачислом не является универсальным тождеством произвольной асети.

## А19. Физический адрес не является тождеством связи

Различаются:

```text
оперативный адрес записи
долговременный адрес хранения
номер в снимке
смысловая связь
```

Перемещение записи в хранилище не меняет связь. Две физические записи, если они представляют одну пару смысловых полюсов, представляют одну связь МТС.

Физический адрес также не может различить две полностью самозамкнутые формы: после смысловой канонизации такая форма одна — акорень.

## А20. Остенсивная нотация предшествует машинной

Правильный порядок представления:

```text
∞ / ♂e / b♀ / b⟼e
→ структурные уравнения
→ тождество связи по полюсам
→ машинное представление
```

`Link(start,end)` является техническим носителем уже понятой структуры, а не заменой языка МТС.

## Историческая граница

Принятая версия 0.2 использовала обозначения:

```text
♀F / F♂
```

Они относятся к исторической семантике проекций и не определяют текущее самозамыкание.

Текущая ориентация остаётся:

```text
♂e = S = S ⟼ e
b♀ = E = b ⟼ E
```

Эти аксиомы задают текущую границу кандидата. Всё, что выходит за неё, требует отдельного решения, а не молчаливого расширения через код или документацию.
