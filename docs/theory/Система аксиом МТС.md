# Система аксиом МТС

Статус: актуальное, нормативное.

Полный нормативный набор формул хранится в [`tests/mtc_formulas.mtc`](../../tests/mtc_formulas.mtc). Ниже формулы цитируются только рядом с их чтением; отдельный сводный список не поддерживается.

Каждая аксиома имеет формулу формальной нотации МТС. Система формул аксиом решается одновременно и образует корневую библиотеку апрувера.

## A1. Акорень

Формула:

```text
∞ : [] = [] ⟼ []
[] = ∞
∞ = ∞ ⟼ ∞
```

Чтение:

```text
[] — минимальная завершённая форма одной связи
∞ — акорень
акорень несёт смысл смысла
```

связь — единственная форма существования, поэтому акорень является связью полного самозамыкания.

## A2. Пустая круглая форма смысла

Формула:

```text
() : ♀() ⟼ ()♂
```

Чтение:

```text
() — минимальная формальная форма смысла
♀() — начало формальной формы смысла
()♂ — конец формальной формы смысла
```

Смысл не существует отдельно от связи: связь и есть смысл в своей различённой форме.

## A3. Смыслы квадратных абитов

Формулы:

```text
([) : (♀∞)
(]) : (∞♂)
```

Чтение:

```text
([) — смысл левого квадратного абита
(]) — смысл правого квадратного абита
```

В `([)` и `(])` квадратные скобки являются буквальными абитами внутри круглой формальной нотации.

## A4. Связь и несвязь

Формулы:

```text
(⟼) : (♀∞ ⟼ ∞♂)
(↛) : (∞♂ ⟼ ♀∞)
```

Чтение:

```text
(⟼) — смысл связи
(↛) — смысл несвязи
```

Несвязь не существует в натуре. Смысл несвязи выражается связью. Обратное направление связи не является отсутствием связи.

## A5. Квадратные формы абитов

Формулы:

```text
[1] : (⟼)
[0] : (↛)
```

Чтение:

```text
[1] — квадратная форма абита связи
[0] — квадратная форма абита несвязи
0 — абит связи, несущей смысл несвязи
```

Абит 0 не является отсутствием связи в натуре.

## A6. Начало и конец формы связи

Формулы:

```text
♀[] : ♀[] = ♀[] ⟼ []
[]♂ : []♂ = [] ⟼ []♂
```

Чтение:

```text
♀[] — начало формы связи
[]♂ — конец формы связи
```

Полюса формы связи записываются в актуальной ориентации: `♀F` — начало, `F♂` — конец. Старая ориентация `[]♀` и `♂[]` больше не является активной.

## A7. Равенство

Формула:

```text
(=) : {♀[] = ♀[], []♂ = []♂}
(!=) : ¬(=)
```

Чтение:

Равенство фиксирует совпадение форм связей: начало сравнивается с началом (`♀[] = ♀[]`), конец — с концом (`[]♂ = []♂`). Равенство не является простой идентичностью определения. Формы связей являются видами самозамыканий. Рекурсивная процедура сравнения различает формы рекурсий. Равенство не требует бесконечного раскрытия рекурсивных связей.

Повторные `♀[]` и `[]♂` являются разными позиционными вхождениями соответствующей локально заданной формы. Они связаны локальным контекстом формулы равенства, но не являются глобальными текстовыми переменными; сравнение выполняется по смыслу, то есть по форме самозамыкания.

`(!=)` вводится как отрицание равенства `¬(=)` и используется в формулах различимости форм, например `{} != []`.
