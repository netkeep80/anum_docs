# Система аксиом МТС

Этот документ — **нормативный фундамент** Метатеории связей. Он фиксирует принятые постулаты, определения и производные фундаментальные результаты. Мотивация, доказательная интуиция и развёрнутые объяснения находятся в [Основаниях МТС](Основания%20МТС.md).

Текущий выпуск и свидетельство его принятия показываются единственным генерируемым блоком в [README](../../README.md). Предметные законы ачисел, формальной нотации и апамяти принадлежат соответствующим спецификациям и здесь не дублируются.

Номера `А0`–`А20` исторически стабильны. Буква `А` в номере не означает, что каждый пункт является независимой аксиомой: статус каждого положения указан явно.

## А0. Онтологическая замкнутость

**Статус: постулат + определение Связи.**

```text
всё есть Связь
Связь связывает Связи
```

Начало и конец Связи сами являются Связями. Семантически существенное различие должно быть выражено Связью или асетью Связей.

Имя, UUID, адрес, технический экземпляр или физическая строка хранения не вводят вторую первичную сущность.

Несвязь также не является вторым видом существующего:

```text
1 -> L = O ⟼ C
0 -> U = C ⟼ O
0 != DELETE_LINK
```

## А1. Рекурсия — основание различимости

**Статус: принцип различимости + условие конечного укоренения.**

```text
различима только рекурсия
```

Различие имеет смысл, когда выражено рекурсивной структурой Связей. Чистая круговая зависимость предполагаемых различий друг от друга не создаёт различие сама по себе: доказательство различимости должно иметь конечное укоренение.

Первая остенсивная форма не требует уже различённого внешнего полюса:

```text
∞
```

Она предъявляет полное самозамыкание. Во внешней доказательной метанотации:

```text
x = x ⟼ x
───────────
x ⇓ ROOT
```

Для остальных форм несамозамкнутый полюс должен иметь конечное рекурсивное основание.

```text
одновременность уравнений != временной порядок создания Связей
```

Направленным является доказательство различимости, а не космогония появления смыслов.

## А2. Акорень единственен

**Статус: производная теорема F2/F3, не независимая аксиома.**

Если:

```text
x = x ⟼ x
y = y ⟼ y
```

то обе записи имеют одну нейтральную к именам форму `ROOT`. Рекурсивно выраженного различия между ними нет.

Единственная форма полного самозамыкания называется **акорнем**. Знак `∞` предъявляет её остенсивно; после этого вводится техническое имя `R`:

```text
R := смысловая форма, предъявленная ∞
R = ∞
R = R ⟼ R
```

Если:

```text
X = X ⟼ X
```

то:

```text
X = R = ∞
```

## А3. Однополюсное самозамыкание различает ориентацию

**Статус: производная теорема после укоренения внешнего полюса.**

```text
♂e = S = S ⟼ e
b♀ = E = b ⟼ E
```

Для фиксированного уже различённого внешнего полюса соответствующая укоренённая форма единственна.

`♂` и `♀` здесь являются остенсивной метанотацией, а не обязательными внутренними знаками исполнения.

## А4. Бинарность и направленность

**Статус: определение Связи.**

```text
X = b ⟼ e
```

Полная Связь имеет два упорядоченных полюса. В общем случае:

```text
b ⟼ e != e ⟼ b
```

## А5. Пятисвязный корневой базис

**Статус: производный базис укоренённых форм.**

```text
R = ∞
R = R ⟼ R
O = O ⟼ R
C = R ⟼ C
L = O ⟼ C
U = C ⟼ O
```

Корневой транспортный словарь:

```text
∞ -> R
[ -> O
] -> C
1 -> L
0 -> U
```

`[ ] 1 0` — ровно четыре абита. `∞` не является пятым абитом.

## А6. Тождество Связи определяется полюсами

**Статус: производная теорема F2/F3, не независимая аксиома.**

После установления единственности `ROOT` и конечного укоренения остальных форм тождество рекурсивно сводится к соответствующим упорядоченным полюсам:

```text
(A ⟼ B) = (C ⟼ D)
iff
A = C and B = D
```

Технические ссылки, адреса и номера операций в смысловое тождество не входят.

А6 зависит от А2; А6 не используется для доказательства единственности акорня.

## А7. Различимость распространяется от корня

**Статус: производное следствие F2.**

```text
∞ / ROOT
-> R
-> O / C
-> L / U
-> Связи с уже различёнными полюсами
-> дальнейшая асеть
```

Это порядок зависимости доказательства различимости, а не временной порядок существования или материализации.

## А8. Петля отличается от полного самозамыкания

**Статус: производное следствие.**

```text
Loop(a) = a ⟼ a
```

в общем случае не равно `a`.

Если:

```text
a = a ⟼ a
```

то:

```text
a = R = ∞
```

Замкнутый остенсивный шаблон `♂♀` также схлопывается к `ROOT`, если предполагаемое различие его частей не получает независимого конечного основания.

Конечная левая итерация:

```text
a¹ = a
aⁿ⁺¹ = aⁿ ⟼ a, n >= 1
```

использует `n` только как метаязыковую координату.

## А9. Роли выражаются Связями

**Статус: принцип представления.**

Тип, теория, правило, контекст или роль не являются скрытыми полями примитивной Связи.

Например:

```text
T ⟼ Rule
```

выражает допуск правила самой связевой структурой.

## А10. Форма отделена от действия

**Статус: фундаментальная граница эффекта.**

```text
форма != команда
```

Поиск, проверка, разрешение, исполнение и материализация — разные акты. Наличие правила, функции или иной формы как данных не означает её автоматического выполнения.

## А11. Контекст явен и структурен

**Статус: принцип контекстной явности.**

Контекст выражается Связями, а не скрытым состоянием host-среды:

```text
P = parent ⟼ current
K = K ⟼ P
I ⟼ K
```

Структура родительства и структура временного исполнения не обязаны совпадать.

Фундамент требует **явного структурного свидетельства контекста**. Он не назначает лексически ближайший кадр, стек анализатора или изменяемое текущее значение смысловым авторитетом.

Конкретный принятый закон разрешения контекстной точки принадлежит [спецификации формальной нотации](../specs/Формальная%20нотация%20МТС.md#mts-law-explicitKContext).

## А12. Источник отделён от формы

**Статус: принцип разделения представления и смысла.**

Физический источник, его точный носитель, употребление и разрешённая форма являются разными отношениями.

```text
источник
-> точный носитель
-> употребление
-> выбранные словарь / грамматика / теория
-> форма / результат
```

Способ построения точного строкового носителя принадлежит [спецификации ачисел](../specs/Ачисла%20и%20сериализация.md), а полномочие FORMAL-употребления — [спецификации формальной нотации](../specs/Формальная%20нотация%20МТС.md).

## А13. Словарь и история явны

**Статус: принцип структурного происхождения.**

Словарные записи и события определения могут быть выражены Связями:

```text
Entry = sourceContent ⟼ form
Definition = D_before ⟼ Entry
```

Различие событий хранится структурой истории и происхождения, а не техническими экземплярами одной пары.

## А14. Чтение отделено от изменения

**Статус: фундаментальная граница возможностей.**

```text
читать / искать / разрешать / проверять / воспроизводить
!=
создавать / удалять / изменять / материализовать
```

```text
не найдено != не существует
find != materialize
```

Применение этой границы к конкретной памяти описывает [спецификация апамяти](../specs/Апамять%20и%20управление%20сетью%20связей.md), а к точным адресам — [спецификация ачисел](../specs/Ачисла%20и%20сериализация.md).

## А15. Локальное отношение представителей не заменяет А6

**Статус: граница производного контекстного равенства.**

```text
Pair    = member ⟼ representative
Binding = K ⟼ Pair
```

Такое локальное отношение не переопределяет фундаментальное тождество Связи и само по себе не вводит глобальную подстановку, транзитивность или конгруэнтность.

Конкретная текущая FORMAL-семантика `=` описана в [спецификации формальной нотации](../specs/Формальная%20нотация%20МТС.md).

## А16. Правило требует явного допуска

**Статус: принцип смыслового полномочия правила.**

```text
Rule = DR ⟼ Body
T ⟼ Rule
```

Наличие `Rule` как данных не означает его исполнения. Допуск должен быть предъявлен структурно; проверка допуска сама по себе не даёт права записи.

Текущая цепочка полномочий FORMAL-результата принадлежит [спецификации формальной нотации](../specs/Формальная%20нотация%20МТС.md#mts-law-formalResultAuthority).

## А17. Акт, интерпретатор и результат различаются

**Статус: принцип разделения ролей исполнения.**

```text
I — интерпретатор
A — акт
R — результат
```

Эти роли не тождественны. Различие актов и их временной порядок выражаются структурой истории, а не номером технического экземпляра.

## А18. Циклы требуют укоренённой различимости

**Статус: следствие А1/F2.**

Самозамыкания, петли, совместное использование и взаимные циклы допустимы, если участвующие формы различены относительно конечного корневого основания.

Чистая взаимная рекурсия без конечного основания не получает смысловую индивидуальность только из-за асимметрии своей физической записи.

## А19. Физический адрес не является тождеством Связи

**Статус: граница машинного представления.**

Оперативный адрес, долговременный адрес, номер записи, координата пути и смысловая Связь — разные уровни.

Физические дубликаты одной структурно неразличимой формы должны быть канонизированы либо отклонены.

## А20. Остенсивность предшествует машине

**Статус: методологический принцип основания.**

Порядок определения:

```text
∞
-> ROOT
-> теорема единственности акорня
-> имя R

♂e / b♀ / b⟼e
-> конечное укоренённое различение
-> теорема тождества по полюсам
-> Link(start,end) как машинное представление
```

Машинный носитель не является источником теории.

# Производные результаты

## F2/F3. Нормализация и отсутствие смысловых экземпляров

Внешняя доказательная метанотация использует конечные формы:

```text
ROOT
START(F)
END(F)
PAIR(F,G)
```

и наименьшее отношение рекурсивного сопоставления.

`ROOT` не требует уже различённого внешнего полюса. `START(F)`, `END(F)` и `PAIR(F,G)` требуют конечного основания своих внешних полюсов.

Чистая циклическая зависимость, не достигающая `ROOT`, остаётся неукоренённой.

Для каждого укоренённого класса получается одна нейтральная к именам нормальная форма:

```text
нет рекурсивно выраженного различия
=> нет двух смысловых Связей
```

Отсюда следуют единственность полного и однополюсного самозамыкания, нейтральность псевдонимов и рекурсивное тождество.

## F4. Рекурсивная реверсия

Определена производная операция:

```text
J(R)=R
J(O)=C
J(C)=O
J(L)=L
J(U)=U
```

Она отличается от простой перестановки полюсов, обратного отношения навигации, отрицания и несвязи.

## F5. Счёт по степени связности

Производная шкала:

```text
0 -> U
1 -> L
D1 = L
D2 = L ⟼ L
D3 = (L ⟼ L) ⟼ L
...
```

Конечные положительные степени попарно различны. Критическая граница:

```text
U ⟼ L != L
```

Поэтому нулевой переход и положительный successor различаются:

```text
S0(U)=L
S0(D)=D⟼L, D∈Pos
```

## F6. Производные теории

Коллекции, функции как данные, относительная навигация и прикладные интерпретации строятся поверх обычных Связей, явной теории/контекста, ролей и структуры вхождений.

```text
корневая Связь
+ явная теория / контекст
+ явные роли
+ структура вхождений / происхождения
-> производное суждение
```

Ни множество, ни функция, ни путь, ни прикладная роль не становятся новым корневым видом сущности.

Для открытого мира сохраняется:

```text
не найдено
!= пусто
!= не существует
```

если нет отдельного свидетельства замкнутости.

## Историческая граница

Исторические формы и прежние версии нотации доступны через Git. Они не переопределяют текущий фундамент.

`♂` и `♀` сохраняются как остенсивная метанотация; `↑` и другие отложенные знаки не получают исполнения только из факта исторического употребления.

## Сжатая зависимость основания

```text
А0  всё есть Связь
↓
А1  различимость требует конечного рекурсивного основания
↓
А2  единственный ROOT / акорень
↓
А3–А5  ориентированные укоренённые формы и R/O/C/L/U
↓
А6  тождество по упорядоченным полюсам
↓
А7–А20  следствия и границы ролей, контекста, эффектов и машины
↓
F2–F6  производные доказательные и прикладные конструкции
```

Детальная мотивация этой зависимости находится в [Основаниях МТС](Основания%20МТС.md).
